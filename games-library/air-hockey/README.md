# 空气曲棍球（gameKey：`air-hockey`，category 建议：`arcade`）

- 玩法：竖版球台人机对战，拖动下方球拍击球，球饼经摩擦衰减与边界/球拍弹性碰撞；打进上方球门得 1 分，先进 5 球获胜，进球后重新开球。
- 操作：按住并拖动球拍（限本方半场，可甩拍加力）；键盘方向键 / WASD 平移，P 暂停。
- 说明：单文件自包含 H5，零外链；AI 在己方半场迎球击打、失球回防，速度上限低于玩家；战绩（胜/负/连胜）本地保存（`sw.airhockey.v1`）；切后台自动暂停。
