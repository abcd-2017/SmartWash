# 二十一点（gameKey：`blackjack`，category 建议：`cards`）

- 玩法：筹码制 21 点，初始 1000 筹码。下注（最低 10）→ 发牌（各两张，庄家一张暗牌）→ 要牌/停牌/加倍（仅首两张且筹码充足，再抽一张后自动进入庄家回合）。A 可算 1 或 11（软点数标注"软 N"）。玩家天牌 BlackJack 直接结算，3:2 赔付；庄家天牌直接获胜；庄家 AI 低于 17 点补牌、17 点（含软 17）停牌。爆牌立即判负；平局退注。筹码不足最低下注即破产，可重整旗鼓重置 1000（累计重整次数）。
- 操作：点筹码（+10/+50/+100/清空）调整下注 → 发牌 → 要牌/停牌/加倍按钮，全部 ≥44px 高。结算以覆盖层展示本局得失与剩余筹码。
- 说明：筹码、最近下注额、战绩（胜-负）、破产重整次数持久化于 localStorage（键 `sw.blackjack.v1`，全部 try/catch 包裹）；每局重新洗 52 张牌。四种花色与牌背均为原创内联 SVG（红色花色用 `--g-danger`，不依赖字符花色，避免字体 emoji 化渲染差异）。玩法参考经典赌场规则自研实现，未使用任何原型代码。
