# 森林快跑（gameKey：`forest-run`，category 建议：`arcade`）

原创实现的竖屏森林跑酷（玩法参考 `mini-browser-games/forest-dash.html` 的跑酷题材，代码全部自写）。

- 玩法：竖屏无尽跑酷，速度随距离渐增（0.6H→1.0H px/s）；原木 / 岩石需跳跃，低垂枝干需铲滑（低枝从画面顶延伸，跳不过去只能滑）；松果每颗 +15 分（地面列与跳跃弧线两种排布）；得分 = 距离分 + 松果；撞上任何障碍立即结束并结算。
- 操作：点按画布或「跳跃」按钮 / 上滑手势 = 跳跃（落地前 0.14s 预输入缓冲），下滑手势或「铲滑」按钮 = 铲滑；空中下滑触发速降快落；桌面空格 / ↑ 跳、↓ / S 铲；切后台自动暂停。
- 说明：单文件自包含 H5；最高分与最多松果 localStorage（`forest-run-best`，JSON 读写均 try/catch）；相邻两组障碍的间距从上一组最后一个障碍起算（≥0.92 倍当前速度下跳跃滞空距离），组合模板内部间距经可通性校验（双木相邻一跳可过、岩石→低枝留有落地铲滑窗），任何速度下都可通过；主题按 D5 终版裁定由桥唯一控制（无 matchMedia 层与手动切换钮），canvas 全变量取色经 `__gOnTheme → palLoad()` 随推送实时重绘。

## 与原型的机制差异（复刻取舍）

原型 `forest-dash.html` 是 12 径三车道巡游（左右换道 / 矿车 / 磁铁护盾冲刺三补给 / 三选跑者 / 星章与档案码）。本作收敛为单跑道跳跃 + 铲滑双动作：去掉三车道 / 补给 / 跑者与赛段系统，保留「跳 / 铲双动作 + 收集计分 + 速度渐增」核心循环，死亡即时结算 + 最高分持久化。
