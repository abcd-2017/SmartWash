# 切水果（gameKey：`fruit-slice`，category 建议：`arcade`）

- 玩法：水果自底部抛物线飞起，按住滑动划切。每果 +10，一刀多果触发连击（每多 1 果 +5）；切到黑圆炸弹 -1 命并红闪，共 3 命。错过落地不扣命，难度每 10 秒递增。
- 操作：触屏按住滑动切割（支持鼠标拖拽）；P 暂停/继续；空格开始或再来一局。
- 说明：单文件自包含 H5，零外链；canvas 宽度按容器实测计算（dpr 缩放），375px 无横向溢出；localStorage 存最高分与最高连击（`sw.fruitslice.v1`）；炸弹概率 8% 起步、每 10 秒提升，上限 20%。
