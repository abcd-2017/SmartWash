# 猜成语（gameKey：`idiom`，category 建议：`word`）

- 玩法：wordle 规则猜四字成语，六次机会；每题字库由答案字 + 干扰字共 16 字组成，提交后逐字反馈（绿＝字对位对、黄＝字对位错、灰＝无此字），键盘状态跟随历次最好成绩；内置 117 条常见成语带释义。
- 操作：点字库组词填入四个格子，「提交」判定，「退格」修改，「释义提示」可提前看谜底释义。
- 说明：单文件自包含 H5，零外链；反馈采用标准 wordle 双计法（重复字按未匹配槽位计数）；结算展示成语释义，连胜/最佳连胜本地保存（`sw.idiom.v1`）。
