# 星空保卫战（gameKey：`invaders`，category 建议：`arcade`）

- 玩法：太空侵略者复刻，5×8 敌阵整体横移触边下压、越少越快；波次制无限挑战（敌速与弹速逐波提升）；三块可侵蚀掩体、神秘飞碟 +100、敌阵压到防线即失败。
- 操作：手指按住屏幕拖动，飞船平滑跟随、火力全自动（同屏 2 发）；键盘 ←→ 移动、P 暂停。零按钮纯触屏可玩。
- 说明：单文件自包含 H5，零外链；敌阵为像素矩阵双帧动画；localStorage 存最高分与最高波次（`sw.invaders.v1`）；扣命 1.5s 无敌闪烁，切后台自动暂停。
