# 数独（gameKey：`sudoku`，category 建议：`puzzle`）

- 玩法：9×9 数独三档难度（入门 40 提示格 / 进阶 32 / 大师 26），每局现场生成并经解数计数器验证唯一解；冲突数字标红、同数字高亮、支持候选笔记，完成结算用时与按难度最佳纪录。
- 操作：点选格子 → 底部数字键盘填入（同数再点擦除）；笔记模式点数字写/取消候选；暂停可停表。
- 说明：单文件自包含 H5，零外链；生成器经 24 局抽测（三档难度提示格全部命中目标且唯一解）；localStorage 按难度存最佳用时（`sw.sudoku.v1`）；切后台自动暂停计时。
