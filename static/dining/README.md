## 三、导入步骤

1. **封面先入 MinIO**：把 `image/` 里的图上传到 MinIO 的 `dining/covers/` 前缀（对象键 = 文件名）。导入器对「封面对象键」列做 `statObject` 校验，**存储缺失时该行封面不落库**（仅行级警告）。
2. **Web 后台 → 吃啥管理**：文件导入上传 `recipes_merged.csv`，或目录导入选本目录。
3. **幂等**：「唯一标识」列（`hoc_*` / `htc_*`）命中即更新，重复导入不堆重复菜；无该列的旧 CSV 按（菜名, 分类）兜底。
4. **校验**：抽查营养徽标与封面；发起一单试算买菜清单聚合与人均卡路里。

## 四、口径说明

- **一份热量 = 整份热量（HowToCook 口径）?: 热量每100g × 250g**（250g 为份量假设常量，四端一致）。
- 买菜清单按（配料名, 归一单位）聚合求和；无用量配料仅按名去重。
- 营养双口径：`calories_per_100g`（CookLikeHOC 每 100g 营养表）/ `calories_total`（HowToCook 整份估算）。
- 步骤列最长 20000 字；「封面链接」列仅校验 http(s) 格式、**不导入**，故现有 1221 行该列全为空。
