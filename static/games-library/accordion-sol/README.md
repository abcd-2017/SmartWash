# 手风琴纸牌（gameKey：`accordion-sol`，category 建议：`board`）

- 玩法：一行 8-16 张牌；点数或花色相同的牌堆，可向左移动 1 或 3 个位置叠收到目标堆上（叠收后空位闭合、整行压缩），把整行压到目标堆数（1-2 堆）即胜。
- 操作：点一个牌堆选中，可叠收的目标堆会虚线高亮，点目标完成叠收；键盘 Tab+回车 选堆确认、U 撤销、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关为构建期 DFS 求解并嵌入解法的牌行（10→16 张递进，目标堆数 1-2）；存档键 `sw.accordionsol.v1`，到达关卡经 GB 桥上报（desc，附步数）；无桥环境自动降级纯本地。行压缩玩法为合集新增，与接龙 / 配对 / 连收类规则不同。

## 关卡验证

- 每关结构 `{name, cards[8..20 张互异牌码], target(1..3), sol[偶数长: 目标下标,距离 交替], difficulty}`；`sol` 为构建期 DFS 求得的完整叠收序列（`[被移堆下标, 左移距离]` 依次施加）。
- 验证方式：游戏内嵌**独立规则回放器** `accReplay`——按叠收规则逐步重放嵌入解法（每次移动都校验：左移 1/3 位、顶牌同点数或同花色、压缩后下标连续），任何一步非法或终态堆数 > 目标即淘汰该关；加载时同步复核全部关卡（毫秒级），坏关不进关卡表。
- 生成与验证结果：构建期扫描 91 个候选种子、逐关先尝试压缩到 1 堆再放宽到 2 堆，生成 40 关并全部嵌入解法；独立回放复核 **40/40 通过**；jsdom 无头冒烟测试中实际执行叠收（堆数 -1、步数 +1、撤销恢复）全部通过。
