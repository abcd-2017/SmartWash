# 炼金合成（gameKey：`alchemy-tree`，category 建议：`puzzle`）

- 玩法：点选两枚元素按配方合成新物质，层层递进凑出关卡目标（蒸汽/植物/生命/贤者之石等 10 级配方树）；配方表内含干扰项，合成次数越少越好。
- 操作：触屏点两枚元素即试合成（无配方会提示）；键盘 1-9/0 选中元素（选满两枚自动合成）、Z 撤销、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关由包内种子生成器产出，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 每关结构为 `{name, target, stock[], recipes[[a,b,c]], par, difficulty}`；`stock` 为基础元素库存（多重集），`recipes` 为本关解锁配方（只能是内置配方表条目，DB 下发亦强制校验）。
- 生成方式：包内固定种子（20261120）生成器按目标反推配方闭包与最小基础元素集，再注入干扰配方与冗余库存；理论构造保证可解。
- 验证方式：游戏内嵌**独立多重集 BFS 求解器** `fuseBFS`（状态=排序库存键，逐配方展开，节点上限 8 万），加载每关复核可解性并计算最少合成步数；DB 下发关卡逐关过滤，无解关不进关卡表。
- 生成与验证结果：40/40 关可解，BFS 实测最优与关卡 `par` 一致，步数 1→10 递进（一期 1 步入门、二期 2-3 步、三期 6-10 步），库存峰值 12 枚。
