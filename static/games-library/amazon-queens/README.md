# 女皇棋（gameKey：`amazon-queens`，category 建议：`board`）

- 玩法：亚马逊走棋（Game of the Amazons）——每手先像国际象棋后一样移动己方女皇，再从落点向后一样射出一支箭封锁一格（箭格永不可入）；轮到时无路可走判负，棋盘越走越死的地盘博弈。
- 操作：触屏点己方女皇 → 点高亮落点 → 点红色箭靶格；键盘方向键移动光标、Enter 确认、Esc 取消、U 悔棋、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关 = 棋盘 6/7/8/9/10 路 × 双方后数 2-4 × AI 深度 1-3 × 松弛/精准/先后手组合，negamax + α-β + 领地 BFS 估值，到达关卡经 GB 桥上报（desc）。切后台 AI 思考作废、轮次归还玩家。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, size(5-10), queens(1-4), depth(1-3), rand(0-2), first(0/1)}`。
- 验证方式：游戏内嵌独立验证器 `selfTest`——① 40 关配置校验；② **标准锚点用例**（手算固定局面）：空 8x8 中心后走法=27、4x4 角后走法=8、落 (2,2) 后箭靶=10、全走法逐落点合计=72、箭围死单后无路；③ 困毙/全封锁判负局面判定；④ 估值方向性（自由方对被困方必为正分）；⑤ 4 局 AI 自战对拍（深度 1，6x6）：走法全部来自走法生成器、必分胜负、无死循环。
- 生成与验证结果：14/14 项自检通过（含 4/4 局 AI 对拍）；AI 对局时间预算 1s/节点上限 4.5 万，保证低端机不卡顿。
