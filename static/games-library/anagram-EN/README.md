# 字母重排（gameKey：`anagram-EN`，category 建议：`word`）

- 玩法：每关 3 个乱序英文单词，按中文释义提示把乱序字母块排回正确单词；点字母块填入槽位、点槽位退回，填满自动判定，顺序错误计失误；三词全拼对过关，词长 3→8 字母递进。
- 操作：触屏点字母块/槽位；键盘直接敲字母（自动匹配可用块）、Backspace 退格、R 重开；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关由固定种子生成器产关（120 词全覆盖，乱序确定性且必不等于原词）；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, ws:[{w(目标词), hint(中文释义), mix(乱序串)}]}`；词库为内嵌 120 个常用英文词（自撰常用词表，3-8 字母按词长排序）。
- 内嵌独立验证器逐关复核：① 结构完整（w 匹配 `^[A-Z]{3,8}$`、hint 非空、关内词唯一）；② **乱序合法性**——mix 与 w 为同一字母集合的重新排列（排序后相等），且 mix ≠ w（保证是真重排题）；③ 可通关性显然（槽位 + 字母块齐备，退格可反复调整）。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核，异常关会在消息区告警）。
- 内容口径：词表全部为常用英语单词，释义为常用中文义项；判定按目标词字面全串比对（重复字母词如 NOTEBOOK 按位匹配）。
