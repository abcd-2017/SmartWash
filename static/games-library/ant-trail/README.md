# 蚁群寻路（gameKey：`ant-trail`，category 建议：`other`）

- 玩法：蚁巢通道里蚂蚁靠本能直行/右转会原地打转，玩家用有限滴信息素箭头铺出往返通路，引导蚁群把食物全部搬回巢，限步内完成过关。
- 操作：触屏点格子循环放置/擦除信息素箭头（上→右→下→左→擦除），点「出发」开跑、再点暂停/继续；键盘方向键移光标、Enter 放箭头、空格出发/暂停、H 提示、R 重置。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，蚂蚁行为为完全确定性模拟（无随机）。

## 关卡验证

- 内嵌 40 关，每关结构 `{name,w,h,rows,budget,ants,moveLimit,arrows,par,difficulty}`；`rows` 为网格（`#`墙/`.`空/`F`食物/`N`巢），`arrows` 为包内参考解（转弯格+巢口），`moveLimit` 由参考解回放步数 ×(1.34→1.15) 收紧得出。
- 验证方式：游戏内嵌**确定性模拟器** `AT.batch`（蚂蚁规则纯函数：出巢带箭头转向、无箭头直行>右>左>回且避免回头；搬运中按直行>右>左>回沿原路倒回）。生成期逐关断言：① 参考解回放可通关；② **空信息素回放不可通关**（保证箭头必要）；③ 结构校验 `AT.validate`。
- 锚点用例（`window.__validateLevels()` 共 6 条，node 抽取 XC-CORE 复现）：直道觅食 6 步回巢（精确）、断路不可达 delivered=0（精确）、箭头不改直道结果 ticks=6（精确）、第 1 关解回放 ticks=36/57、第 1 关无信息素 delivered=1<总数、40 关全可解。
- 生成与验证结果：40/40 关可解，平均参考解步数随关卡递增，无信息素均不可通关。
