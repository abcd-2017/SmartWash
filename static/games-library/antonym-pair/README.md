# 反义对对（gameKey：`antonym-pair`，category 建议：`word`）

- 玩法：每关 16 张双字反义词卡（8 对，如 大↔小、深↔浅）打乱铺在 4×4 网格，点出互为反义的一对即消除；配错算失误并抖动提示，8 对全消除过关。
- 操作：触屏先点一张再点它的反义词（再点同一张取消）；键盘 1-9 / 0 / QWE TYU 按位置点卡、R 重开；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关由固定种子从 93 对反义词库产关（跨关可复用、关内去重）；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, pairs:[8 对], cards(16 卡随机序，含对编号)}`。
- 内嵌独立验证器逐关复核：① 结构完整（每对两词非空且不同、关内词唯一、卡数=对数×2、每对恰两张卡、卡词都在 pairs 中）；② **反义命中**——每一对必须能在反义词库中正向或反向命中（杜绝误标反义）；③ 可通关性由构造保证（配错可继续选，无时限）。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核，异常关会在消息区告警）。
- 内容口径：93 对反义词均为通行反义双字词（大小、上下、开关、胜败、盈亏等），逐对人工校对为规范反义关系；不含近义误配与多义争议对。
