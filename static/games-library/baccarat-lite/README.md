# 比点荷官（gameKey：`baccarat-lite`，category 建议：`board`）

- 玩法：与荷官玩九点牌（baccarat / punto banco 规则）。6 副牌洗靴，每轮押注「闲 / 庄 / 和」与筹码额（10/20/50）后发牌：闲庄各两张，天牌（8/9）免补，否则按经典第三张牌规则补牌（闲 0-5 补、6-7 免补；庄按闲第三张牌值查表决定）；点数大者胜，押闲/庄 1:1、押和 8:1；给定轮数内筹码 ≥ 目标即过关。
- 操作：点押注区选闲/庄/和、点筹码选额度，按「发牌」；键盘 1/2/3 押闲/庄/和、Q/W/E 选筹码 10/20/50、回车发牌、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关为配置型关卡（轮数 8→16、目标筹码随轮数递增，起始 100）；存档键 `sw.baccaratlite.v1`，到达关卡经 GB 桥上报（desc，附最终筹码）；无桥环境自动降级纯本地。与 21 点（blackjack）的爆牌/要牌规则实质不同。

## 关卡验证

- 每关结构 `{name, rounds(4..40 轮), target(目标筹码), difficulty}`；靴牌 = `mulberry32(关卡种子)` 洗 6×52=312 张。
- 验证方式（结果类关卡可解性为概率语义，故验证规则与机制本身）：
  ① **第三张牌规则全域一致性**：游戏内嵌「权威规则表」与「独立条件引擎」两套编码，加载时对闲家总点 0..7 × 是否补牌 × 第三张牌值 0..9 的**全组合**逐一比对，任何一格不一致即淘汰该关；
  ② **整靴机制模拟**：固定押注策略自动打满该关轮数，校验总点恒在 0..9、筹码收支逐轮自洽（不得为负）、用牌不越靴尾；
  ③ 配置合法性（轮数 / 目标范围）。
- 生成与验证结果：40 关（rounds 8→16，target 196→292）全部通过规则表全域比对（8×2×11 组合）与 150 组种子整靴模拟（**40/40**）；jsdom 无头冒烟测试打完整关并验证押注切换 / 点数显示 / 流转。
