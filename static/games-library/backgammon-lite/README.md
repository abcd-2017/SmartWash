# 双陆棋（gameKey：`backgammon-lite`，category 建议：`board`）

- 玩法：8 子轻量双陆棋，绿子（你）从 24 点向 1 点竞走、从右下家区离盘，红子（电脑）反向；掷双骰按点行进（对子走四步），落点遇对方单子可打上打入区、两子封锁不可落；全部棋子先离盘者胜。
- 操作：点「掷骰」→ 点自己的绿子再点目标点；打入区的子需先按骰点进入；家区选中后点右侧托架（或 B 键）离盘；键盘方向键选点、回车确认、U 悔棋、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；lite 规则：每子 8 枚、走不通的骰点作废（不强制最大用骰）；40 关 = AI 段位 1-6 × 让先（电脑步距+2/电脑-1子/你队前压）组合，AI 全骰序枚举评估，到达关卡经 GB 桥上报（desc）。切后台 AI 思考中断、轮次归还玩家。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, skill(1-6), h(0-3)}`。
- 验证方式：游戏内嵌独立验证器 `selfTest`——① 40 关配置与初始步距校验（玩家步距=111）；② 规则单元测试：两点封锁、单子可吃、骰 6 精确离盘、非最远点禁大骰离盘、最远点可大骰离盘、按骰从打入区进入、入口两点封锁、打子上被打区；③ 3 局全 AI 自战对拍至终局：每手来自走法生成器、己方步距单调不增。
- 生成与验证结果：16/16 项自检通过（含 3/3 局 AI 对拍）。
