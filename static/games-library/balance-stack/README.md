# 跷跷配重（gameKey：`balance-stack`，category 建议：`puzzle`）

- 玩法：把托盘里的全部砝码（4-6 个，重量 1-5）摆上跷跷板的钩位（-4 至 +4，个别钩位锁死），使力矩 Σ 重量×距离 = 0、横梁水平——纯力矩配平，不是两侧重量相等。
- 操作：触屏点托盘砝码选中、再点横梁钩位放置（点已放砝码取下）；键盘 ←/→ 移动光标、1-6 选砝码、Enter 放/收、Z 撤销、H 提示。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, weights(砝码列表), locked(锁死钩位 ≤2), sol(参考解: 每砝码钩位), difficulty}`；钩位 -4..+4 共 9 个。
- 验证方式：游戏内嵌**独立验证器**（重量降序 + 已用钩位掩码的回溯，与构建期参考解的随机顺序回溯相互独立）：搜索「全部砝码放入未锁钩位且 Σ w×p = 0」的分配，带剩余可补偿剪枝，要求存在解；`sol` 参考解本身再做逐项一致性校验（位置未锁、力矩和为零）。后台分片逐关复核，验证失败的关在选关面板禁用。
- 生成与验证结果：40/40 关存在零力矩摆法（构建期与运行时双重回溯复核，参考解 40/40 校验通过）。
