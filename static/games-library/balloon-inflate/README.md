# 吹气控爆（gameKey：`balloon-inflate`，category 建议：`other`）

- 玩法：连点「吹」把气球吹大，价值随口数上涨；每只球有隐藏爆点，气球发抖就是临近爆点的信号——觉得要爆就赶紧「存」进钱罐换新球，爆满 3 只收工。
- 操作：触屏点画布或「吹一口」按钮吹气、「存进钱罐」按钮存分；键盘空格吹气、Enter 存钱。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；分数驱动街机，收工时上报历史最高钱罐分（desc）。

## 上报口径

- `metricValue` = 历史最高钱罐分（存档键 `sw.ballooninflate.v1` 本地 + 账号双写，账号优先）。
- 一轮结束（爆满 3 只）时上报一次；无关卡概念，不使用 `metricExtra`。

## 验证说明

- 爆点序列由 mulberry32 确定性抽样（`drawPop`：4~14），分数驱动无关卡表；内嵌引擎 `BI.selfTest()` 4 项锚点全 PASS（固定种子 20261122 首球爆点=13 的已知输入→已知输出：popK 口以内吹不爆 / 第 popK+1 口必爆换新球 / 存 5 口入罐 5 分 / 连爆 3 只收工）。
