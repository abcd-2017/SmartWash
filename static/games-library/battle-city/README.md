# 坦克大战（gameKey：`battle-city`，category 建议：`arcade`）

- 玩法：13×13 半格战场，驾驶坦克守卫底部基地。击毁砖墙开路、避开钢墙与水面，消灭本关全部敌方坦克过关；敌方坦克分普通 / 快速 / 重甲 / 射手四类从顶部三点分波进攻，会朝基地与玩家推进、随机转向、见隙开火。
- 操作：左下虚拟十字键移动（按住连续行驶，接近格子自动对齐），右下「开火」按钮射击（按住连射）；键盘可用方向键 / WASD + 空格。
- 说明：单文件自包含 H5，素材全部 Canvas 自绘，零外链零素材文件。3 条生命，被毁后原地重生并附 2 秒护盾；基地被敌弹击中即失败。击毁带闪光标记的敌方坦克会掉落道具——护盾（8 秒无敌）或炸弹（清除全场敌军）。关卡由包内 12 关默认与 DB 下发共同驱动，进度与最高分自动保存。
