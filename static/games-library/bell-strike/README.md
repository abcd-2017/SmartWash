# 敲钟节奏（gameKey：`bell-strike`，category 建议：`arcade`）

- 玩法：钟球沿三栏落向钟线，落线瞬间点对应栏敲钟（WebAudio 钟声）：Perfect ≤60ms +150、Good ≤130ms +80、Poor ≤220ms +30，连击叠倍率；空敲断连击、漏敲 -1 钟（共 3 口），敲碎中断。谱面逐谱更密，共 42 谱。
- 操作：触屏点三栏敲钟；键盘 A/S/D 或 1/2/3 对应左中右钟，P 暂停、R 重敲本谱。
- 说明：单文件自包含 H5，零外链、canvas 自绘；42 谱内嵌，逐谱验证密度（峰值平均 2.29 音/s、最小间隔 240ms、同刻 ≤2 口不同栏）可完成；接 GB 桥存档/关卡/成绩上报，无桥降级 localStorage。
