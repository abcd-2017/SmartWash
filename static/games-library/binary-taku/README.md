# 零一谜（gameKey：`binary-taku`，category 建议：`puzzle`）

- 玩法：Takuzu / Binairo——偶数阶盘面上填 0/1：每行每列 0 与 1 数量各半；任何位置不得出现三个相同数字连排；任意两行/两列不完全相同。
- 操作：触屏点空格循环切换 0→1→空；键盘方向键选格、空格/Enter 切换、0/1 直填、U 撤销、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关 = 4/6/8/10 阶 × 提示数递减，离线生成器产关 + 唯一解验证，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, n(4/6/8/10), g[行串 0/1/.]，sol}`。
- 验证方式：游戏内嵌独立验证器 `selfTest`——① 40 关配置校验；② **标准锚点用例**（手排 4 阶 Takuzu 0011/1100/0101/1010）：满格题唯一、挖前两格仍唯一（行均衡+三连规则强制）、空盘有解；③ 规则矩阵：三连识别、不均衡识别；④ **40 关全量复核**：约束传播 + 回溯求解器逐关计数解数（上限 2），全部唯一且首解与 `sol` 一致。
- 生成与验证结果：8/8 项自检通过（含 40/40 关唯一解复核）。**开发期内嵌复核曾抓出离线生成器「重复行剪枝条件恒真」缺陷导致 5 关非唯一，已按 sol 回填提示格修复后全量唯一。** 纯事件驱动（无计时/AI），切后台无需暂停处理。
