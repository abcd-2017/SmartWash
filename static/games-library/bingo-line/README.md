# 宾果连线（gameKey：`bingo-line`，category 建议：`board`）

- 玩法：宾果（Bingo）——5x5 卡片按 B/I/N/G/O 五列各 15 号发牌，点「叫号」从 75 号池逐个开号，找到卡片上对应的格子盖章；横/竖/斜连成线计数，先完成关卡目标条数即胜，叫号次数用完仍未达标即败。
- 操作：触屏点「叫号」再点对应格子；键盘空格叫号、方向键选格、Enter 盖章、R 换卡重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关 = 目标 1-5 条连线 × 叫号上限 18-34 × 中央免费格开关，纯事件驱动（无计时），到达关卡经 GB 桥上报（desc）。

- 内嵌 40 关，每关结构为 `{name, target(1-5), calls(15-40), free(0/1)}`；卡片每局随机生成（B1-15/I16-30/N31-45/G46-60/O61-75）。
- 验证方式：游戏内嵌独立验证器 `selfTest`——① 40 关配置校验；② **标准锚点用例**（数线器与 UI 完全独立）：满卡 12 线（5 横+5 竖+2 斜，手算）、首行+首列 2 线、主对角 1 线、双斜+中行 3 线、空卡 0 线；③ 发牌结构 50 局抽查：列号域、无重复、免费格仅出现在中央；④ 叫号序列：75 个号码全覆盖无重复。
