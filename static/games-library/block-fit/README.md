# 嵌块补形（gameKey：`block-fit`，category 建议：`puzzle`）

- 玩法：盘面是实心铺面缺一块异形缺口，绿色嵌块与缺口同形异向；旋转 / 翻转 / 移动嵌块，对准虚线缺口一次嵌入成型（压到实心块放不进，形状不对算失误）。
- 操作：触屏点盘面移动嵌块、点旋转 / 翻转 / 嵌入按钮；键盘方向键移动、R 旋转、F 翻转、Enter 嵌入、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关由包内种子生成器产出（随机生长多联骨牌 4→8 格），到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 每关结构为 `{name, cols, rows, g[][], p[][], par, difficulty}`；`g` 为缺口格坐标，`p` 为嵌块存储朝向，`par` 为从存储朝向到缺口朝向的最少旋转/翻转次数。
- 生成方式：包内固定种子（20261128）生成器随机生长多联骨牌（4→8 格递进），放进随机位置作缺口；前 10 关恒等朝向（纯放置入门）、中期旋转 1-3 次、后期加翻转。
- 验证方式：游戏内嵌**独立验证器**（朝向群 BFS `solveOps`：旋转/翻转变换 ≤8 状态，求到缺口朝向的最少操作数）加载每关复核可成型性；DB 下发关卡逐关过滤，不可成型关不进关卡表。
- 生成与验证结果：40/40 关可成型，BFS 实测最少变换与关卡 `par` 一致（par 0×10 / 1-3×30），盘面 6×6→9×9、嵌块 4→8 格递进。
