# 突破棋（gameKey：`breakthrough`，category 建议：`board`）

- 玩法：8×8 突破棋，绿方（你）向上、红方（电脑）向下推进；每子每步向前或斜前一格，直前只能进空格、斜前可吃子；任一子抵达对面底线、或对方全军覆没/无着可走即胜。
- 操作：点自己的绿子再点目标格；键盘方向键移动光标、回车选子/走子、Esc 取消、U 悔棋、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关段位赛 = AI 段位 1-6 × 让子（标准阵/你队前压/电脑-4子/电脑单排/电脑先手）组合，negamax+α-β 引擎，到达关卡经 GB 桥上报（desc）。切后台 AI 思考中断、轮次归还玩家。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, skill(1-6), h(0-3), first(0/1)}`；h 为让子档。
- 验证方式：游戏内嵌独立验证器 `selfTest`——① 40 关配置与初始局面合法（各让子档子数逐关断言）；② 走法单元测试：直行遇敌不可进、斜前空格可走、斜前吃子、冲线判胜；③ 6 局 AI 低深度自战对拍：每步必须来自走法生成器、每步棋子总数不增、正常分出胜负。
- 生成与验证结果：14/14 项自检通过（含 6/6 局 AI 对拍）。
