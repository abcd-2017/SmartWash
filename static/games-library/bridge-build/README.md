# 造桥承重（gameKey：`bridge-build`，category 建议：`other`）

- 玩法：在山谷两侧节点间架杆造桥，预算内让卡车安全过谷；先铺桥面再加斜撑，杆件受力会变色，超强度即断裂。
- 操作：触屏点两个节点架一根杆（单杆 ≤100），再点「试跑」放卡车；键盘空格试跑、Z 撤销、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；44 关内嵌，到达关卡经 GB 桥上报（desc），metricExtra 为本关造价。
