# 泡泡龙（gameKey：`bubble-shooter`，category 建议：`arcade`）

- 玩法：顶部六边形排列的彩色泡泡阵，拖动瞄准发射同色泡泡，3 个以上相连即消除，失去支撑的悬空簇整体掉落；步数内达到目标分或清空全场即过关，泡泡压到警戒线或步数用尽则失败。
- 操作：在画布上按住并拖动调整瞄准方向（带虚线弹道预览与落点圈），松手发射；右上角按钮暂停 / 继续。
- 说明：单文件自包含 H5，零外链零素材文件，全部画面由 Canvas 自绘；进度本地保存并上报账号，成绩经桥上报。

## 玩法规则

- 棋盘为 8 列六边形交错网格（偶数行 8 个、奇数行 7 个），世界坐标 240×460，画布等比缩放居中。
- 每次发射的泡泡颜色只从场上现存颜色中抽取，避免废弹。
- 得分：消除 n 个得 `10n + 20×max(0, n-3)`；失去支撑整体掉落的 m 个每个 25 分。
- 胜利：分数达到目标分，或清空全部泡泡；失败：步数用尽且未达标，或最低泡泡越过警戒线。
- 关卡数据为 `{name, rows, colors, moves, target, seed}`：初始行数 / 颜色数 / 步数 / 目标分 + 确定性种子，初始阵由引擎用种子生成且保证无预设三连，可复现、可校验。

## 关卡供给

- 包内 `DEFAULT_LEVELS` 12 关（离线可用），启动时调用 `GB.getLevels("bubble-shooter")` 拉取 DB 下发批次；任一条非法则整批放弃，继续使用缓存或包内默认。
- `.levels.json` 共 120 关（levelNo 1..120 连续）：行数 3→10、颜色 3→6、步数 21→45 递进，目标分 300→1363 单调不减，参数四元组与名称均不重复。

## 主题与规范

- 遵循 GAME-THEME.md：`:root` / `[data-theme=dark]` 两块 token + `<head>` 运行时（桥唯一控制，无按钮、无 matchMedia）。
- Canvas 颜色全部经 `PAL` 读 CSS 变量，JS 零颜色字面量；`__gOnTheme` 接 `palLoad()` 重绘。
- 全屏画布布局（`html,body{height:100%}` + `overflow:hidden`），运行时调 `setChrome('immersive')` 隐藏系统状态栏，保留原生返回栏。
- 交互热区 ≥44px，375px 宽度无横向溢出；字号仅用 12/14/16/22，圆角只用 16/14/12/10。
