# 星期推算（gameKey：`calendar-quiz`，category 建议：`other`）

- 玩法：三类题型递进——①今天是星期 X，N 天后（3-90 天）是星期几 ②某月 1 日是星期 X，本月 D 日是星期几 ③真实日历题（2024-2027 年随机日期，含闰年 2 月 29 日）；四选一，答错扣 5 秒，错满 3 题失败。
- 操作：触屏点选项；键盘 1-4 选答案、R 重开、L 选关。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（种子生成，6→10 题、70→55 秒），到达关卡经 GB 桥上报（desc，metricValue=过关关号，metricExtra=剩余秒数）；真实日历以「2024-01-01 星期一 / 2025-01-01 星期三 / 2026-01-01 星期四 / 2027-01-01 星期五」为锚点（均为真实历法，人工核对）；切后台自动暂停并把计时基点平移。

## 关卡验证

- 关卡结构 `{dc:{q,time,kinds},qs[]}`：每题 `{kind,text,opts[],ans,w/w1/y/m/dd,delta/d1}`，星期编码 0=周一…6=周日；答案按 mod 7 运算。
- 生成算法：偏移题 (w+delta) mod 7；日期题 (w1+d1−1) mod 7；真实题 = 年锚点 + 当日序数（平/闰月表 + 闰年判断 `y%4===0&&(y%100!==0||y%400===0)`）mod 7；干扰项为正确答案 ±1/±2/±3 天并互异。
- 验证方式：游戏内嵌**独立验证器** `verifyLevelData`（mod 题重算；真实日历题用公式重算并内置逐日步进路径交叉校验锚点），断言答案标记一致、选项均为合法星期名、互异且唯一正确。
- 标准锚点用例（人工核对真实历法）：①2024-02-29 = 星期四（闰年日）②2026-03-15 = 星期日 ③2024-01-01 = 星期一 ④2025-01-01 = 星期三 ⑤周三 + 25 天 = 星期日 ⑥1 日周三的 22 日 = 星期三。启动时逐关复核 40 关 + 锚点断言，验证失败在消息区告警。
- 生成与验证结果：40/40 关通过，无告警。
