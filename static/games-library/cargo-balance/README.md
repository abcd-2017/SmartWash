# 货载平衡（gameKey：`cargo-balance`，category 建议：`arcade`）

- 玩法：货箱依次到达，点左盘或右盘把它放上去。力矩 = 右侧总重 − 左侧总重，每一步都不能超过限位，超限即倾覆；全部放完且平衡即过关。
- 操作：触屏点「左盘 / 右盘」或棋盘左右；键盘 ←/→ 放置、Z 撤销、H 提示。
- 说明：单文件自包含 H5，canvas 自绘，零外链；48 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 48 关，每关结构为 `{name, boxes[], limit}`（boxes 为货箱重量序列，limit 为力矩限位）。
- 验证方式：游戏内嵌**独立 DP 求解器** `reachableFrom`，状态为当前力矩，逐箱放左/右并要求每一步 `|力矩| ≤ limit`，可达集合非空即判定可平衡；加载每关时实时复核，若不可平衡会在消息区告警。
- 生成与验证结果：48/48 关全部可平衡（离线生成器以同一 DP 判定，关关通过）。
