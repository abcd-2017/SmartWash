# 拆字找字（gameKey：`chai-zi`，category 建议：`word`）

- 玩法：屏幕上方展示一个大母字，下方候选字网格里混入了它拆出的部件字与形近干扰字；限时点选全部真实部件字即过关，点错扣一次机会，机会用完或超时则本关失败。120 关难度递进：母字笔画增多、部件变多、候选更形近、限时缩短。
- 操作：点选候选字按钮即可，点对高亮锁定、点错抖动扣机会；「提示」按钮每关一次，可高亮一个未找部件；「重玩本关」随时重置。
- 说明：单文件自包含 H5（CSS/JS 全内联、零外链、纯 DOM 自绘无素材文件），支持桥下发关卡（gameKey：`chai-zi`）与包内默认关兜底，进度自动保存并上报成绩。

## 拆分规则（公平性约定）

- 部件字＝母字**一步结构拆分**出的、能独立成字的部件（上下/左右/内外），偏旁部首（氵、亻、扌、艹、辶、宀、刂等）不算字。
- 第一步拆出的成字部件不足 2 个时，继续拆分非字部件并**保留中间成字部件**：如 湖 → 胡 → 古 + 月（胡保留）；而成字部件已够时不再下钻：如 驾 → 加 + 马（不收加里的力、口）。
- 重复部件按去重计：器 → 口 + 犬。
- 关卡数据 `{name, char, parts, distractors, time, mistakes}`，`parts` 与拆分表逐关一致，可由 `docs/level-gen/tools/chai-zi/` 的生成器复现、独立校验器复核。
