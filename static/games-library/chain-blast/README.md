# 连锁引爆（gameKey：`chain-blast`，category 建议：`puzzle`）

- 玩法：场上一片炸弹各有爆波半径，点一枚起爆，波及范围内的炸弹依次连锁殉爆；用最少的引爆次数清空全场，达到参考最少次数拿三星。
- 操作：触屏点炸弹起爆；键盘方向键选弹、空格起爆、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc），metricExtra 为引爆效率（par−次数+1，用满参考次数时为 1）。

## 关卡验证

- 内嵌 40 关（6→12 枚炸弹，位置与半径由 mulberry32 种子确定性生成，最小间距 40），结构 `{name, bombs:[{x,y,r}]}`。
- 验证方式：内嵌**精确求解器**——子集 DP（状态=已爆掩码，转移=任选未爆弹起爆并做 BFS 连锁扩张），逐关求出最少引爆次数 `par`（∈[1,n]）；DB 下发关卡同样整表求解复核通过才接受。
- 锚点用例：① 三弹一线（间距 70、半径 75）→ par=1 ② 同布局半径 40 → 无连锁 par=3 ③ 两簇互不相通布局 → par=2 ④ 全部 40 关 par∈[1,n]。
- 生成与验证结果：`CB.selfTest()` 4 项锚点全 PASS，40/40 关求解通过（全表求解耗时 ~1ms，par 分布 3~10）。
