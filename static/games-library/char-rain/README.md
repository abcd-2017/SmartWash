# 汉字雨（gameKey：`char-rain`，category 建议：`word`）

- 玩法：60 秒限时赛，汉字从天而降，底部篮子左右移动，只接住**当前主题**的字（接对 5 个自动换主题）；接到其他主题的字扣 1 条命（共 3 条）并断连击，主题字漏接断连击、无主题字漏接无惩罚；速度随时间加快。
- 操作：触屏在画布按住拖动篮子；键盘 ←→ / A D 移动、空格暂停；切后台自动暂停（计时基点平移）。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载），素材全部 canvas 自绘、颜色经 PAL 读 CSS 变量；分数驱动款：结束上报本局最高分（desc，metricValue=本局分数，metricExtra=最大连击），历史最高分 localStorage + 账号存档双写（`sw.charrain.v1`），无桥自动降级。

## 上报口径

- `reportScore("char-rain", {metricValue: 本局最终分数, metricExtra: 最大连击})`，desc 语义（越大越好）。
- 分数规则：接对主题字 +10 + 连击加成（combo ≤20 时每连击 +2）；接错字扣命、清连击、不扣分。

## 内容校验（主题字库）

- 内嵌 12 主题 × 10 字（动物/植物/天气/身体/水果/交通/颜色/食物/学习/自然），启动时运行独立验证器 `auditThemes`：结构完整（每主题恰 10 个单字）+ **两两互斥**（每个字只属于一个主题，保证「接住/接错」判定无歧义）。
- 校验结论：120 字无跨主题重复，异常时消息区告警。
