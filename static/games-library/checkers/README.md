# 国际跳棋（gameKey：`checkers`，category 建议：`board`）

- 玩法：8×8 英式跳棋，绿方（你）与红方（电脑）对弈；兵沿斜前走、跳吃敌子，有跳必须跳、连跳可连续吃多子，到底线升王（可双向行走），对方无子可动或无着可走即胜。
- 操作：点自己的绿子再点目标格（连跳会逐步请点落点）；键盘方向键移光标、回车选子/走子、Esc 取消、U 悔棋、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关段位赛 = AI 段位 1-6 × 让子（你+2兵/双角王/电脑-2兵/电脑先手）组合，negamax+α-β 引擎，到达关卡经 GB 桥上报（desc）。切后台 AI 思考中断、轮次归还玩家。
