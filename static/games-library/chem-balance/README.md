# 方程配平（gameKey：`chem-balance`，category 建议：`other`）

- 玩法：给出未配平的化学方程式（系数显示「?」），填入全部系数使两边各元素原子数守恒；填最小正整数系数，提交错误标红扣一次机会，3 次内配平过关；关卡由易到难（3 物种化合 / 分解 → 4-5 物种复分解 / 氧化还原）。
- 操作：触屏点虚线槽再点数字键（1-6）；键盘 ←/→ 切槽、1-6 填系数、Backspace 清除、Enter 提交、H 提示（确认一槽）、R 重开、L 选关。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关对应自撰方程库 42 条**教科书常见反应**（化合 / 分解 / 置换 / 复分解 / 燃烧 / 氧化还原，含光合作用等，系数 1-6，支持括号式如 Cu(NO₃)₂）；到达关卡经 GB 桥上报（desc，metricValue=过关关号，metricExtra=失误次数）；不限时（纯事件驱动，切后台无需暂停）。

## 内容口径

反应全部为初中 / 高中化学教材常见反应，答案为唯一最小正整数系数组；分子式用 Unicode 下标书写（如 H₂O、C₆H₁₂O₆）；无离子方程式、无有机复杂机理题。

## 关卡验证

- 关卡结构 `{formulas[],ans[],arrow,name}`：formulas 为物种分子式（前 arrow 个为反应物），ans 为最小系数组。
- 验证方式：游戏内嵌**独立验证器** `verifyLevelData`——①分子式解析器（Unicode 下标 + 括号展开）核对非空 ②**暴力枚举系数 1-6 全组合做元素守恒检查**，只计 gcd=1 的最小整数解，断言守恒解恰为 1 且等于库答案（解空间一维 ⇒ gcd=1 解唯一，库答案若非最小解会被此检查抓住）③答案结构 / 系数边界。
- 标准锚点用例（人工核对）：①Ca(OH)₂ 解析 = Ca:1,O:2,H:2 ②Cu(NO₃)₂ 解析 = Cu:1,N:2,O:6 ③C₆H₁₂O₆ 解析 = C:6,H:12,O:6 ④水电解 2H₂O→2H₂+O₂ 唯一最小解 ⑤甲烷燃烧 CH₄+2O₂→CO₂+2H₂O 唯一最小解。启动时逐关复核 40 关（覆盖 42 条库方程中的 40 条）+ 锚点断言，验证失败在消息区告警。
- 生成与验证结果：40/40 关唯一最小守恒解通过，无告警。
