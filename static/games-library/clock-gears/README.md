# 拨钟对时（gameKey：`clock-gears`，category 建议：`puzzle`）

- 玩法：钟面挂着两个齿轮曲柄 A/B，每拨一格分别把时刻快进/倒退固定分钟数（齿比各不相同、可为负），每人配额有限，把指针拨到虚线目标时刻。
- 操作：触屏点 A−/A＋/B−/B＋ 拨格；键盘 A D 拨轮 A、J L（或方向键）拨轮 B、Z 撤销、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关由包内种子生成器产出，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 每关结构为 `{name, start, target, da, db, ba, bb, par, difficulty}`；`da/db` 为每格分钟数，`ba/bb` 为两曲柄配额（按绝对格数计）。
- 生成方式：包内固定种子（20261121）生成器随机取起点、齿比与配额，按隐藏解（x1,x2）反推目标时刻；难度 1→5 递进（齿比由整五向负数/非整五过渡、配额收紧）。
- 验证方式：游戏内嵌**独立穷举验证器** `solveGears`（对曲柄 A/B 在配额内全部 (x1,x2) 组合模 720 枚举），加载每关复核可达性并计算最少格数；DB 下发关卡逐关过滤，不可达关不进关卡表。
- 生成与验证结果：40/40 关可达，穷举实测最优与关卡 `par` 一致，步数 1-5 格分布；29/40 关最优组合唯一。
