# 钟面算术（gameKey：`clock-math`，category 建议：`other`）

- 玩法：看 SVG 钟面读出起始时间（24 小时制 5 分钟步进），按题面加 / 减若干小时与分钟，从 4 个选项里选结果时间；后期加入减法与跨午夜 / 跨正午循环（mod 1440 分钟）。
- 操作：触屏点选项；键盘 1-4 选答案、R 重开、L 选关。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（种子生成，6→10 题、70→55 秒），到达关卡经 GB 桥上报（desc，metricValue=过关关号，metricExtra=剩余秒数）；钟面为内联 SVG 自绘（表盘 / 刻度 / 时针分针全走 `--g-*` 变量）；切后台自动暂停并把计时基点平移。

## 关卡验证

- 关卡结构 `{dc:{q,time,sub,span},qs[]}`：每题 `{v:[h,m],sign,hrs,mins,opts[],ans}`，结果时间 = (h×60+m + sign×(hrs×60+mins)) mod 1440。
- 生成算法：起始时间随机（分钟 5 步进），加减量 15-130 分钟 / 0-2 小时（保证运算量非零），干扰项为结果 ±5/±30/±60/±90/±120/±45/±20/±15 分钟并保证互异且唯一正确。
- 验证方式：游戏内嵌**独立验证器** `verifyLevelData`（逐分钟步进模拟，与生成器的一次模运算为不同实现路径；选项正则解析为分钟数逐个比对，断言唯一正确 + 答案标记一致 + 格式合法 + 选项互异）。
- 标准锚点用例（人工核对）：①10:00 + 45 分 = 10:45 ②8:20 − 90 分 = 06:50 ③23:30 + 45 分跨午夜 = 00:15 ④7:55 + 1 小时 = 08:55。启动时逐关复核 40 关 + 锚点断言，坏关自动换种子重试，验证失败在消息区告警。
- 生成与验证结果：40/40 关通过，无告警。
