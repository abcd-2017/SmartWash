# 时钟纸牌（gameKey：`clock-solitaire`，category 建议：`board`）

- 玩法：52 张洗匀轮发 13 堆（A 到 Q 对应钟面 12 个位置，K 归中央），每堆 4 张暗置；从中央 K 堆翻起，翻出的牌点数决定下一堆（A→1 点位……Q→12 点位、K→中央），翻出的牌明置回同点数的牌堆下；被指到空堆则链断失败，52 张全部翻开即胜。
- 操作：点高亮（橙色描边）的牌堆翻牌，全程只有这一个动作；键盘空格 / 回车翻当前堆、R 重开。本局为确定性翻牌链（发局即定结局），考验的是对链的沉浸式解链体验。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关按发局号种子确定性发牌（全部为可走通的获胜链）；存档键 `sw.clocksolitaire.v1`，到达关卡经 GB 桥上报（desc）；无桥环境自动降级纯本地。翻牌链解谜玩法为合集新增，与接龙 / 配对类规则不同。

## 关卡验证

- 每关结构 `{name, seed, par, difficulty}`：`seed` 为发局号，`mulberry32(seed*613+11)` 确定性洗 52 张后轮发 13 堆（顶牌 = 后发者）；`par` 恒为 52（目标翻开张数）。
- 验证方式：游戏内嵌**独立确定性模拟器** `clockSim`（O(52) 逐步执行翻牌链：空堆判定 → 弹顶牌 → 点数跳转），加载时**同步复核全部关卡**（毫秒级），只有模拟获胜的种子进入关卡表。
- 生成与验证结果：构建期扫描 589 个候选种子（天然胜率约 6.8%）选出 40 个获胜种子，复核 **40/40 通过**；jsdom 无头冒烟测试中游戏全程自动点击翻牌链，实测从中央 K 堆一路翻满 `52/52` 并触发过关浮层（端到端走通）。
