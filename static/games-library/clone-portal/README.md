# 分身双行（gameKey：`clone-portal`，category 建议：`puzzle`）

- 玩法：蓝橙两个分身听同一指令同时行动（撞墙的分身原地不动，双卡不动不耗步），踩上传送门立刻传到同色门，让两个分身同时压住黄绿两个机关环即过关。
- 操作：触屏点四个方向按钮或在盘面上滑动；键盘方向键发指令、Z 撤销、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关由包内种子生成器产出（6×6→9×9，33 关含传送门），到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 每关结构为 `{name, rows[], cols, rowsN, par, difficulty}`；`rows` 为棋盘字符行（`.` 空 / `#` 墙 / `1` `2` 双机关 / `P` `Q` 传送门对 / `A` `B` 分身出生点），`par` 为最少步数。
- 生成方式：包内固定种子（20261131）生成器按密度带随机布墙，随机放双机关、双出生点与 0-2 对传送门，BFS 可达且 par 3-30 才收关，重复盘面剔除，par 升序排布。
- 验证方式：游戏内嵌**独立验证器**——`cpBFS` 对 (分身1×分身2) 双状态空间做 BFS（传送门落子即传送、双卡剪枝、父指针重建首着），加载每关复核可达性并计算最少步数；DB 下发关卡逐关过滤，不可达关不进关卡表。
- 生成与验证结果：40/40 关可达，BFS 实测最优与关卡 `par` 一致；规格 6×6→9×9，par 3→13 随难度递进。
