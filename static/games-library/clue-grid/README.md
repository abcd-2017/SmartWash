# 推理网格（gameKey：`clue-grid`，category 建议：`puzzle`）

- 玩法：「谁养鱼」式演绎推理：若干人 × 若干类别（宠物 / 饮品 / 帽子），按线索在网格里排除定位；点格循环 空白→✓→✕，勾对会自动排除同行同列，全部对上（每人每类恰一个 ✓、每值恰一人、线索全满足）即过关。
- 操作：触屏点格标记；键盘方向键移动（类别 → 值 → 人 序）、空格标记、H 提示（验证器代标一格）。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（3 人 2 类 → 4 人 3 类递进），到达关卡经 GB 桥上报（desc，附加线索数）；无桥自动降级 localStorage。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, ents[], cats[{name,vals[]}], clues[], difficulty}`；线索类型 `is` / `not`（某人某类是/不是某值）与 `link`（甲类取某值的人乙类必取某值），每类取值数 = 人数（双射）。
- 验证方式：页面内嵌**全排列组合枚举验证器**（N≤4、C≤3 → ≤13824 组合，2 解早停），加载每关时复核线索结构合法且满足全部线索的完整指派**恰有一个**，非唯一解的关不进关卡表；提示功能用同一验证器给出的唯一解代标一格。
- 生成与验证结果：构建期先随机生成双射解，再按「强线索（is/link）优先」贪心加入使解数严格下降且不为零的线索直到唯一解（保证每人与每类至少被提及），40/40 关通过包内验证器复核（唯一解）。
