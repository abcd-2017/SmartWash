# 过山车铺设（gameKey：`coaster-build`，category 建议：`other`）

- 玩法：链式轨道设计——N 段轨位按库存放入平/上/下/弯/刹/推六种轨件，让小车从站台靠重力与助推走完全程：中途不能失速停车、弯道限速不能脱轨、进站速度要落在 1.0~2.2 之间，试跑不限次。
- 操作：触屏点轨位循环换件（或数字键 1-6 直接放），「◀ 轨位 / 循环轨件 / 试跑」；键盘 ←/→ 选轨位、1-6 放件、Enter 循环、空格试跑、R 重置。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，库存=参考解+1 件机动，物理为确定性 v² 递推（无随机）。

## 关卡验证

- 内嵌 40 关，每关结构 `{name,N,inv[6],ref[N],difficulty}`；轨件规则：平/弯 -0.55 摩擦、上坡 -1.8、下坡 +1.8、刹车 -6、推进 +3（均为 v² 单位），初速 v²=1.44，弯轨 v²>6.76 脱轨、任意位置 v²≤0.05 失速、到站 v²∈[1,4.84]。
- 验证方式：游戏内嵌**确定性物理验证器** `CB.sim`（纯函数逐段递推并记录轨迹），生成期用构造式引导生成参考解并全量复核可到站，库存=参考解用量+1 件随机机动，`CB.validate` 复核结构与「库存覆盖参考解 + 参考解必到站」。
- 锚点用例（`window.__validateLevels()` 共 7 条，node 抽取 XC-CORE 复现）：下下平到站 v²=4.49（精确）、单弯进站太慢失速（why=slow）、推推弯 v²=6.89 脱轨于第 2 段（精确）、单上坡爬坡失速、下下下刹下 v²=2.64 进站（精确）、40 关参考解可到站、生成逐字节确定。
- 生成与验证结果：40/40 关参考解可到站（fail 空）。
