# 弹币入格（gameKey：`coin-flick`，category 建议：`arcade`）

- 玩法：按住硬币向后拖拽蓄力，松手弹出，硬币凭惯性滑入顶部得分格。不同格子分值不同，连续入格有加成，20 枚硬币用完结算。
- 操作：触屏按住硬币拖动再松手；键盘 ←/→ 调角度、↑/↓ 调力度、空格发射。
- 说明：单文件自包含 H5，canvas 自绘，零外链；分数经 GB 桥上报（desc），无桥降级 localStorage。
