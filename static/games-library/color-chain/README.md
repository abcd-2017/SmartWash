# 色链消（gameKey：`color-chain`，category 建议：`puzzle`）

- 玩法：一笔连满消除。从任意色块起笔，拖过相邻同色块，连满同色的一整个簇即整簇消除；清空全盘过关（同色不相邻的两个簇要分两笔）。
- 操作：触屏按住拖动画链（走回上一格即回退，松手未连满则本笔作废计一笔）；键盘方向键移光标、Enter 加格、Backspace 回退、Esc 作废本笔、Z 撤销、H 提示。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 张盘面内嵌（5×5→6×6），每笔消除数与剩余簇实时显示，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 每关结构为 `{name, cells[], cols, rows, par, difficulty}`；`cells` 为色块字符行（1-4 四色），`par` 为盘面色簇总数（通关笔数下界）。
- 生成方式：自回避随机游走把整盘分割为路径形色簇，邻簇贪心四染色保证同色簇互不相邻，保证每簇一笔可画完。
- 验证方式：游戏内嵌**独立验证器**（广度优先分簇 + 逐簇逐起点 DFS 哈密顿路搜索 `cvHasHam`）在加载时复核「每簇存在一笔画路径」；**交互判定**（递归泛洪求簇）负责连满判定。双实现互不引用。
- 生成与验证结果：40/40 盘面全部簇可一笔画（10 张 5×5、12 张 5×6、18 张 6×6），DB 下发盘面逐张过滤，含不可一笔画簇的盘不进关卡表。
