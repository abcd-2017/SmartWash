# 调色师（gameKey：`color-mix`，category 建议：`puzzle`）

- 玩法：给出一个由红 / 黄 / 蓝三原色颜料按滴数混合出的目标色，用三种颜料滴数（各 0-10）调出它的颜色，实时显示误差条，交卷按色距评分（≤22 三星 / ≤66 两星 / 其余一星）。
- 操作：触屏点 ＋ / − 调滴数、点颜料色块切换当前颜料；键盘 1/2/3 选颜料、↑↓ 或 +/- 加减、回车交卷。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（两色少量 → 三色大量递进），到达关卡经 GB 桥上报（desc，附加误差值）；无桥自动降级 localStorage。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, t[r,y,b], par, difficulty}`；`t` 为目标色的三原色滴数（0-10，总数 ≥2），`par` = 总滴数。
- 验证方式：页面内嵌**双实现互核验证器**——整数累加实现与浮点加权实现分别对深 / 浅两套调色板常量复算目标色：两实现每通道误差须 ≤1、目标色须在色域内、`par` 必须等于滴数总和；加载时逐关复核，不符的关不进关卡表。
- 生成与验证结果：构建期按难度采样滴数三元组，40/40 关通过包内验证器复核（双实现一致 + 色域合法 + par 一致）。
