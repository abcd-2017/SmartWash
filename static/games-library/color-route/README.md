# 色路最短（gameKey：`color-route`，category 建议：`puzzle`）

- 玩法：棋盘上有若干对同色端点和障碍墙，为每对端点画一条四向路径把它们连通——路线格数必须等于理论最短（BFS 距离），且所有路线互不交叉重叠。
- 操作：触屏点端点按下拖动延伸路径、往回拖即回退；键盘 1-4 选色对、方向键延伸、Backspace 回退、Z 撤销、H 提示。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, w, h, blocks(墙), pairs(端点对), lens(每对理论最短格数), difficulty}`；棋盘 7×7 至 8×8，每关 2-4 对。
- 验证方式：游戏内嵌**独立验证器**（逐对 BFS 最短距离 + 组合回溯搜索，与交互逻辑分离）：先核对每对 `lens` 与独立 BFS 距离一致，再回溯搜索「每对取一条最短路径且互不重叠」的组合是否存在（节点上限 30000）；后台分片逐关复核，验证失败的关在选关面板禁用。
- 生成与验证结果：40/40 关存在互不重叠的各对最短路径组合（构建期与运行时双重搜索复核，胜利判定客观：每对格数 = 独立 BFS 最短 + 无重叠）。
