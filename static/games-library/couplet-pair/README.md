# 对对联（gameKey：`couplet-pair`，category 建议：`word`）

- 玩法：每关 3 题，给出上联与 3-4 个候选下联（其余为其他诗联名句的错位行），选出最工整的一句；选错即划掉可再选，三题答完过关，前 20 关 3 候选、后 20 关 4 候选。
- 操作：触屏点候选下联；键盘 1-3 / 1-4 选择、R 重开；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关由固定种子生成器产关（120 题全覆盖不重复）；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每题结构为 `{u(上联), ok(正确下联下标), opts[候选]}`；全部正确答案取自内嵌 120 条**教科书级名句对**（如「白日依山尽 / 黄河入海流」），干扰项由固定种子从其他联的同字数行抽取（保证上下联字数相等这一对联铁律）。
- 内嵌独立验证器逐关复核：① 结构完整（opts 3-5 条、无重复、ok 下标有效）；② 对仗硬约束（每个候选与上联**字数相等**）；③ **生成一致性**——内嵌关每题的「上联+正确项」必须能在名句对库中复核命中，否则该关告警；④ 可通关性显然（正确项必在候选中，选错可重选）。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核）。
- 内容口径：上下联均为常见无争议的诗词名句/名联（律诗中二联对仗、名联摘句），逐条人工校对；干扰项为真实名句的错位配对，不与本题正确答案同源。
