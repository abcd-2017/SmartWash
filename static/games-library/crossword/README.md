# 中文填字（gameKey：`crossword`，category 建议：`word`）

- 玩法：中文填字闯关，共 4 关（动物 / 自然 / 校园 / 常识），每关 8 词。网格中横竖交替放置答案词，灰色空格为装饰填充。点格子选中所在词（横优先），点下方字块填入光标格（角标为剩余次数，用完置灰）；点已填格撤回重选；一条词全部填对会自动锁定（绿色浅底）。
- 操作：点击词条提示可选中对应词；全部填对后点「下一关」继续（最后一关完成后可回到第一关自由重玩）；「重玩本关」清空当前关进度。进度自动保存在 localStorage（`sw.crossword.v1`）。
- 说明：单文件自包含 H5，纯 DOM（无 canvas）。词库与提示均为自撰、经交叉一致性校验（每关通过 globalValidate：极大连通串恰为词表词）；字池 = 答案去重字 + 6 字干扰字，每字剩余次数与网格需求精确匹配。**已接入游戏数据平台化**：存档经桥代理跟随账号（本地 + 账号双写，结构 `{lv,done}`）；关卡支持后台热更新（DB 下发 `{name,words,distractors}` + 本地缓存 `sw.crossword.v1.levels` + 包内默认关兜底）；通关上报到达关卡进排行榜（desc）。无桥环境自动降级为纯本地。
