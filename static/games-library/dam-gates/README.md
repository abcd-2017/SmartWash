# 开闸分水（gameKey：`dam-gates`，category 建议：`puzzle`）

- 玩法：水库持续进水，按需开关闸门把水配给各区——各区要喝够定额、不能装过容量，水库也不能溢坝，限时内完成配水。
- 操作：触屏点闸门按钮开关放水；键盘 1-4 开关对应闸门、空格暂停、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc），metricExtra 为累计供水量。

## 关卡验证

- 内嵌 40 关（第 1 关为手工设计锚点关，其余公式化确定性生成 + 收敛调整），结构 `{name, ticks, w进水, gr[]闸速率, zd[]区定额, zc[]区容量, rc库容}`。
- 验证方式：内嵌**独立策略回放验证器**（离散 tick 模型：进水→放水→洪溢/溢坝/缺水判定；策略=缺口优先+泄压兜底），逐关回放须 `win`，生成期不过关的关自动抬高容量重试直至可通关（坏关不进表）；DB 下发关卡同样整表回放通过才接受。
- 锚点用例：① 第 1 关策略回放过关且供水恰为手工推演的 36/26 ② 第 1 关全闸常开必在第 13 tick 洪溢（3×13=39＞36）③ 全部 40 关回放可通关。
- 生成与验证结果：`DG.selfTest()` 3 项锚点全 PASS，40/40 关可通关。
