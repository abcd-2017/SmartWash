# 骰子期望（gameKey：`dice-odds`，category 建议：`other`）

- 玩法：掷一颗骰子押 1 枚筹码，给出 3-4 个注池（单点 / 奇偶 / 大小 / 范围 / 非点，各配不同赔率），选出**期望收益最高**的注；期望 = 胜率×赔率 − 败率×1，注卡上直接给出胜率与赔率，考验期望速算；答错扣 5 秒，错满 3 题失败。
- 操作：触屏点注卡；键盘 1-4 选注、H 提示（期望公式）、R 重开、L 选关。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（种子生成，6→10 题、75→60 秒、3→4 个注），到达关卡经 GB 桥上报（desc，metricValue=过关关号，metricExtra=剩余秒数）；期望全部以整数分子（分母恒 6）精确比较，最高期望唯一且与次高差距 ≥1/3；切后台自动暂停并把计时基点平移。

## 关卡验证

- 关卡结构 `{dc:{q,time,n},qs[]}`：每题 `{items[],ans}`，items 元素 `{n,w,label}`（n=6 面骰命中数 1-5、w=赔率 1-9、label=条件文案），期望分子 = n×w−(6−n)。
- 生成算法：从条件池（按命中数分组：1 点/奇偶/大小/范围/非点）随机抽注，双键去重（条件唯一 + 命中数×赔率唯一），每题校验最高期望唯一且与次高差 ≥2 个分子单位，不满足重抽。
- 验证方式：游戏内嵌**独立验证器** `verifyLevelData`（参数边界 + 期望分子重算 + 最高唯一 + 差距阈值 + 答案标记一致 + 注不重复）。
- 标准锚点用例（人工核对）：①单点 1:5 → 期望 0（公平）②偶数 1:1 → 期望 0 ③单点 1:6 → 期望 +1/6 ④≥5（2/6）赔 1:2 → 期望 0 ⑤≥3（4/6）赔 1:1 → 期望 +2/6。启动时逐关复核 40 关 + 锚点断言，验证失败在消息区告警。
