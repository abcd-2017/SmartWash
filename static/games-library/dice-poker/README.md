# 骰子扑克（gameKey：`dice-poker`，category 建议：`board`）

- 玩法：快艇骰（Yahtzee）式五骰计分。每轮最多掷 3 次，掷前/掷间可点骰子锁住要保留的点数；掷完后从记分卡选一档计分（每档一局只能用一次）：一点~六点（同点求和）、三条/四条（全部骰面求和）、葫芦 25、小顺 30、大顺 40、快艇 50、机会（总和）；全部轮数结束总分 ≥ 目标即过关。
- 操作：点骰子锁定、点「掷骰」、点记分卡选档；键盘 1-5 锁骰、R 掷骰、Tab+回车 选档、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关为配置型关卡（牌型档随关卡解锁：一二点档 → +三条/四条 → +葫芦/小顺 → +大顺/快艇 → +机会；轮数 3→6）；存档键 `sw.dicepoker.v1`，到达关卡经 GB 桥上报（desc，附总分）；无桥环境自动降级纯本地。骰子组合计分玩法为合集新增。

## 关卡验证

- 每关结构 `{name, rounds(2..20 轮), cats(6..13 档), target, difficulty}`；target 由目标函数 `levelTarget`（可用档位前 rounds 大理论最大值之和的 55%）确定性给出。
- 验证方式：
  ① **计分三路一致性**：游戏内计分引擎 `gameScore` 与独立实现 `testScore`、以及 29 条**手工判定权威用例**（覆盖每种牌型的正例/边界/反例）三方逐条比对，任何一条不一致即淘汰全部关卡；
  ② **目标可达上界**：target 必须 ≤ 前 rounds 大档位的理论最大值之和（随机结果类关卡的可解性以可达上界陈述）；
  ③ 配置合法性（档位 6..13、轮数范围）。
- 生成与验证结果：40 关全部通过 29 用例三路比对与上界校验（**40/40**）；jsdom 无头冒烟测试打完整关（掷骰→锁骰→选档→结算）并验证键盘锁骰与选关流转。
