# 折扣速购（gameKey：`discount-math`，category 建议：`other`）

- 玩法：限时看一组商品的原价与折扣（折扣 / 每满减 / 后期混合），点出折后价最低的那件；答错扣 5 秒，错满 3 题失败，时间到失败，限时答完即过关。
- 操作：触屏点商品卡；键盘 1-4 选对应商品、R 重开、L 选关。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（种子生成，3→4 件商品、6→10 题、75→55 秒，后期混入每满减），到达关卡经 GB 桥上报（desc，metricValue=过关关号，metricExtra=剩余秒数）；价格以「分」为整数单位运算，折后价全部整分；切后台自动暂停并把计时基点平移（deadline=now+剩余）。

## 关卡验证

- 关卡结构 `{dc:{n,q,time,man},qs[]}`：每题 `{items[],ans,finals[]}`，items 元素 `{kind,price,a,b,nm}`（kind=0 折扣率 a%、kind=1 每满 a 分减 b 分），ans 为最低折后价下标，finals 为独立算出的折后价。
- 生成算法：折扣件先选折扣率（50-90，含 75/85），原价取 `100/gcd(rate,100)` 的倍数保证折后整分；满减件按档（100/200 元）配减（20/30/50 元）随机原价；每题校验最低价唯一且与次低差距 ≥0.5 元，不满足重抽。
- 验证方式：游戏内嵌**独立验证器** `verifyLevelData`（整除性断言 + 与生成器不同的乘除路径重算折后价 + 唯一最低 + 差距阈值 + 参数边界），逐题复核。
- 标准锚点用例（人工核对）：①68 元 7.5 折 = 51.00 元 ②230 元每满 100 减 30 = 170.00 元 ③9.9 元不满档保持原价 9.90 元 ④40 元 8.5 折 = 34.00 元。启动时逐关复核 40 关 + 锚点断言，坏关自动换种子重试，验证失败在消息区告警。
- 生成与验证结果：40/40 关通过，无告警。
