# 叠盘塔（gameKey：`dish-stack`，category 建议：`arcade`）

- 玩法：传送带送来餐盘，点按叠上塔顶；出沿部分被削圆边、盘越叠越窄，全脱手塔塌。完美对齐补回盘沿并叠连击倍率，带速逐层加快，层数即分数，分数驱动冲最高分。
- 操作：触屏点屏幕落盘；键盘空格/回车/方向键下落盘，P 暂停、R 重开。
- 说明：单文件自包含 H5，零外链、canvas 自绘；--g-* 主题 token 双主题；接 GB 桥最高分存档与成绩上报，无桥自动降级 localStorage。
