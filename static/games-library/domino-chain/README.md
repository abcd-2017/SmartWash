# 多米诺（gameKey：`domino-chain`，category 建议：`other`）

- 玩法：在带墙格的棋盘上用有限骨牌摆出连锁路线——只有正交相邻的牌才会传力；点「推倒」放倒首牌，连锁覆盖的立牌数达到目标即过关。倒牌越多、省牌越多得分越高，墙更多牌更紧逐关递增，共 42 关。
- 操作：触屏点格摆牌、再点收回，按钮推倒/清空；键盘方向键移动光标、空格摆牌、回车推倒、P 暂停。
- 说明：单文件自包含 H5，零外链、canvas 自绘；42 关内嵌，逐关经 BFS 精确可达性 + 游戏内同一连锁模拟函数复核可解；接 GB 桥存档/关卡/成绩上报，无桥降级 localStorage。
