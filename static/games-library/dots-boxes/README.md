# 点格棋（gameKey：`dots-boxes`，category 建议：`board`）

- 玩法：玩家与 AI 轮流在相邻圆点之间画横边或竖边；某条边落下后若正好围成 1×1 格子则得 1 分并**继续行动**（可连环围格），全部边画完后总分高者获胜。关卡由棋盘尺寸（2×2 → 5×5 格子）、AI 档位、先手方与让分组合而成，共 120 关，难度递进。
- 操作：触屏点按两条相邻圆点之间的边即可画线（边的命中热区 ≥44px）；「悔棋」回退自己上一步及后续 AI 应对，「重玩」重置本局，「选关」进入已解锁关卡。进度自动保存，通关解锁下一关。
- 说明：单文件自包含 H5，CSS/JS 全内联、零外链零素材文件；棋盘、圆点、边线与占格全部 Canvas 自绘。主题只由桥控制（`getTheme` / `__applySmartWashTheme`），无桥恒浅色，画布颜色经 `PAL` 读取 CSS 变量并在 `__gOnTheme` 钩子中重绘。

## AI 三档策略（自研）

| 档位 | 名称 | 策略 |
|---|---|---|
| ai=0 | 入门 | 在「安全边」（不会把某个格子喂成三面、送对手直接得分）中随机选择；无安全边时随机应招。 |
| ai=1 | 进阶 | 优先落子封闭边（能围成格子的边，按可围格数最多、副作用最小排序）；否则走安全边；被迫送礼时，用贪心链模拟估算对手能连带围走的格数，选择「送礼代价」最小的边。 |
| ai=2 | 大师 | 在进阶启发式之上做 3 层极大-极小搜索（alpha-beta 剪枝，候选着法按封闭优先/危险度排序并限流），评估函数计入分差与场上三面格机会；搜索超预算时回落到进阶策略。 |

## 关卡数据格式

```json
{ "name": "入门·001", "rows": 2, "cols": 2, "ai": 0, "first": 0, "handi": 2 }
```

- `rows` / `cols`：格子行列数，取值 2..5（即 2×2 → 5×5 的棋盘尺寸）。
- `ai`：AI 档位，0 入门 / 1 进阶 / 2 大师。
- `first`：先手方，0 玩家先手 / 1 AI 先手。
- `handi`：让玩家开局即得的让分，取值 0..2。

参数组合空间为 4×4 尺寸 × 3 档位 × 2 先手 × 3 让分 = 288 种，每关组合唯一。
`.levels.json` 为顶层数组，每项信封 `{"levelNo","name","difficulty","data"}`，levelNo 1..N 连续，
name ≤32 字，difficulty 1..10，单关 data ≤64KB，总条目 ≤500、文件 ≤2MB。

## 生成与校验工具

位于 `docs/level-gen/tools/dots-boxes/`（`docs/` 已被 .gitignore 排除）：

- `generate.mjs`：枚举全部 288 种参数组合，按难度基值升序排序后等间距抽取 120 关，写出 `.levels.json`。
- `verify.mjs`：独立校验信封契约、结构取值、组合唯一性、数量与字节上限、难度递进。
- `test-parse.mjs`：从 `index.html` 抽取 `validLevel` / `parseDbLevels`，对 `.levels.json` 全量及各类非法输入做整批放弃单测。
