# 画线救小球（gameKey：`draw-save`，category 建议：`puzzle`）

- 玩法：每关有小球、尖刺、墙体与一只目标杯。按住画布手绘任意折线给小球铺路，松手线条固化成墙、小球受重力开始滚动；沿你画的线导流，静止落入杯内即过关，撞尖刺或掉出屏幕算失败。墨水有限，线条总长不能超过墨水条，剩余越多星级越高。
- 操作：按住画布拖动手指画线（自动采样防折断），松手固化并放球；「重画」随时清线重来（墨水恢复），过关/失败浮层内可下一关、重玩或选关。
- 说明：自研简化物理（圆刚体 + 圆-线段/圆-矩形碰撞 + 固定步长确定性积分），120 关全部由生成器构造参考解并经引擎回放与扰动容错验证；支持 DB 关卡下发（任一条非法整批放弃）、进度与星级双写存档、成绩上报；卡片式布局，单文件自包含 H5，canvas 自绘零外链。
