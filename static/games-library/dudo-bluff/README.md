# 骗骰（gameKey：`dudo-bluff`，category 建议：`board`）

- 玩法：双方各持暗骰轮流叫「N 个 X 点」，加叫必须大于当前叫数（数量更大或同数量点数更大）；觉得对方吹牛就开盅验谎，叫数不成立则叫方输一骰，先打光对方骰子获胜。
- 操作：点 −/＋ 调数量、点 1-6 选点数后点「叫数」；认为对方吹牛点「开盅」；键盘 ↑↓ 数量、←→ 点数、回车 叫数/下一轮、D 开盅、H 提示、R 重开、L 选关。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关 = 骰量 5/4/3 × 电脑段位 1-6 × 百搭规则组合，到达关卡经 GB 桥上报（desc）。切后台 AI 思考中断、轮次归还玩家。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, dice(2-5), wild(0/1), skill(1-6)}`；百搭局 1 点可作任意点数（禁叫 1）。
- 验证方式：游戏内嵌独立验证器 `selfTest`，覆盖四类检查——① 40 关配置结构校验；② 开盅概率函数与二项分布闭式解对拍、边界值；③ 叫数偏序规则（抬量/抬点/同叫/缩量）性质测试与百搭计数；④ 12 场全 AI 对拍局（双方均走 `aiDecide`），逐手断言加叫单调合法、每轮恰扣一骰、对局能正常终局。
- 生成与验证结果：25/25 项自检通过（含 12/12 场 AI 对拍局合法终局）。
