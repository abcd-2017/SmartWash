- 玩法：在 n×n 棋盘上每行放一枚皇后，使其互不攻击；部分关卡预置金色皇后不可动。
- 操作：触屏点格放 / 收皇后；键盘方向键移动光标 + 空格放置、Z 撤销、H 提示。
