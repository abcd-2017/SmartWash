# 电梯调度（gameKey：`elevator-rush`，category 建议：`other`）

- 玩法：楼栋各层冒出候梯乘客，点乘客（或一键派梯）把最优空梯派过去；乘客等太久会跑单，跑满 3 单被炒，限时内送达目标人数即过关。
- 操作：触屏点右侧候梯圆点派梯；键盘空格一键派梯、↑↓ 选呼、Enter 派选中、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc），metricExtra 为累计送达人数。

## 关卡验证

- 内嵌 40 关（第 1 关为手工锚点关，其余由种子确定性生成呼叫时间轴），结构 `{name, ticks, F 层数, elevs 梯数, cap 载客, move 每层 tick, patience 等待耐心, calls[] 呼叫, target}`。
- 验证方式：内嵌**策略回放验证器**（每 tick 给所有未派呼叫派最近空梯，等价于「一键派梯」策略），逐关回放须 `win` 且无跑单；DB 下发关卡同样整表回放通过才接受。收敛链：抬耐心→降目标→加梯（坏关不进表）。
- 锚点用例：① 第 1 关策略回放恰好送达 6 人且零跑单 ② 合成超员关（6 呼叫挤 1 部慢梯、耐心极短）必跑满 3 单判负 ③ 全部 40 关回放可达成。
- 生成与验证结果：`ER.selfTest()` 3 项锚点全 PASS，40/40 关可达成。
