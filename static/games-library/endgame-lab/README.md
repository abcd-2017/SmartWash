# 残局课（gameKey：`endgame-lab`，category 建议：`board`）

- 玩法：兵残局攻防课。白先走，把任一白兵护送到底线升变即胜；黑王（后期含黑兵）由 AI 最强防守，白兵被吃光 / 黑兵升变 / 无子可动判负，60 步内未升变判负。
- 操作：触屏点白子再点目标格；键盘方向键移光标、Enter 选子/走子、Esc 取消、U 悔棋、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 局内嵌（白兵 1-2 枚、黑兵后期加入），AI 深度 2→4 递进；到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 每局结构为 `{name, fen, par, depth, difficulty}`；`fen` 为只含王与兵的残局（白先、双方王均不被攻击），`par` 为验证器给出的白方强制升变步数上界，`depth` 为黑方 AI 搜索深度。
- 验证方式：**独立验证器**（王/兵专用走法 + 己王安全过滤 + 带备忘录的强制获胜搜索 `wvForcedWin`，白负分支含黑升变/白兵尽墨/白困毙）在加载时迭代加深 1..8 步求 `par`；**对弈引擎**（独立实现的 K/P 走法 + 极小化 AI）负责交互。双实现走法集合与攻击判定逐局交叉核对。
- 生成与验证结果：40/40 局白先必胜，双实现走法 80/80、攻击判定 2560/2560 完全一致；par 按 1→5 升序排布（12 局一步升变、9 局两步、7 局三步、9 局四步、3 局五步），AI 深度 2/3/4 随关卡递进。
