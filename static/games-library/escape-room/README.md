# 单景密室（gameKey：`escape-room`，category 建议：`puzzle`）

- 玩法：单间密室里摆着门、箱柜、保险箱、拉杆与线索牌；看懂符号方程线索推出保险箱密码，按依赖顺序开箱取物、扳闸解锁，最终打开大门出逃。
- 操作：触屏点物件交互、点密码面板数字键输码；键盘 1-9 快捷选中物件、Tab/Enter 遍历点击、数字键输码。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, objs(物件数组：kind/reqItems/reqObjs/gives/code 等), difficulty}`；物件类型含 clue（符号方程线索）、take/lock（物品链）、safe（三位密码）、lever（机关依赖）、door（胜利目标）、deco（干扰装饰）。
- 验证方式：游戏内嵌**独立验证器**（与交互状态机分离）：① 枚举符号值组合解线索方程组，要求唯一解且拼出的密码与 safe 的 `code` 一致；② 对机关依赖图做 BFS（状态=已开机关集合×背包物品集合），要求 door 可达且全部功能物件（非 deco/clue）可解开，防死机关。后台分片逐关复核，验证失败的关在选关面板禁用。
- 生成与验证结果：40/40 关可通关（构建期与运行时双重 BFS 复核，密码方程 40/40 唯一解）。
