# 吹羽上行（gameKey：`feather-blow`，category 建议：`arcade`）

- 玩法：按住吹气托着羽毛一路上升，气槽有限、松手回气；侧风会把羽毛越吹越偏，躲开横出的枝叶风障（碰一次少一根羽毛），捡露珠补气加分。高度即分数，三根羽毛用完落地结算，分数驱动冲最高分。
- 操作：触屏按住吹气、左右拖动躲障；键盘按住空格/W 吹气、方向键或 AD 平移、P 暂停、R 重开。
- 说明：单文件自包含 H5，零外链、canvas 自绘；--g-* 主题 token 双主题；接 GB 桥最高分存档与成绩上报，无桥自动降级 localStorage。
