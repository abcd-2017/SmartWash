# 冰火同行（gameKey：`fire-ice`，category 建议：`puzzle`）

- 玩法：单人同控冰火双角色：每次输入两人同时向同方向移动（各自独立判阻挡），火灵不能碰水、冰灵不能碰岩浆，踩压力板开门，双双到达同色出口过关；步数对比参考最优。
- 操作：方向键 / WASD 同控双角色，触屏画布滑动或使用屏上方向按钮；U / 撤销按钮回退一步；「重玩 / 选关 / 下一关」按状态切换。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）。40 关由种子生成器确定性生成（墙 / 危险区 / 压力板机关密度随关卡递增），**每关出生即经联合 BFS 可解性验证**（状态=火位×冰位，门开=踩板，致死转换剪枝），不可解自动重造；调试入口 `window.__validateLevels()` 可复现全部验证（node 抽取 XC-CORE 段独立运行）。关卡缓存 `sw.fireice.v1.levels`，支持 DB 下发整批替换（任一条非法或不可解整批放弃）；存档 `sw.fireice.v1` 本地 + 账号双写，过关上报到达关卡（desc，附步数）。

## 关卡与验证

- 关卡数据：`{name, cols, rows, grid:[行字符串], par}`；网格字符集 `# . w l p q D E F I f i`（f/i 出生，F/I 出口，w 水 l 岩浆，p/q 压力板对应 D/E 门）。
- 可解性：联合 BFS 最短步数 par∈[8,39]（实测 40/40 可解，均值 18.7）；生成即验证 + 下发即验证双保险。
