# 钓鱼达人（gameKey：`fishing`，category 建议：`arcade`）

- 玩法：三段式钓技：摆动力度条定深度抛竿 → 浮漂下沉瞬间点屏起竿（QTE 窗口随关卡收窄 900→420ms）→ 按住收线搏鱼，张力爆表持续 0.55s 断线、鱼挣扎周期性发力；竿数内钓满目标渔获过关，8 种鱼图鉴逐尾收集。
- 操作：点画面 / 空格锁定力度抛竿；咬钩再点一次起竿；按住收线（松手泄力），触屏按住与键盘空格按住同效；「重试 / 选关 / 下一关」按状态切换。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）。40 关由种子生成器确定性生成（竿数 5→9、目标 2→6 尾、QTE 收窄、鱼种池 2→8 种），每杆咬钩时间 / 鱼种 / 挣扎相位由种子确定；深度偏离鱼种带宽则晚咬 2.5s。**可完成性验证 = 完美策略回放**（力量取带宽中点、QTE 点窗口正中、张力 <0.86 收线否则松手，与游戏共用同一状态机），40/40 全达标；调试入口 `window.__validateLevels()` 复现（node 抽取 XC-CORE 段独立运行）。图鉴存档 `sw.fishing.v1`（dex 逐种取多，账号双写合并），关卡缓存 `sw.fishing.v1.levels`，DB 下发整批替换（回放不过整批放弃）；过关上报到达关卡（desc，附得分）。

## 关卡与验证

- 关卡数据：`{name, casts, need, win(ms), pool:[鱼种下标], seed}`；鱼种 `{name, band:[深,浅], power, value}`。
- 可完成性：完美策略回放 40/40 达标（每杆钓获用时 5-16s，全关卡时长 1-3 分钟）。
