# 连色铺满（gameKey：`flow-connect`，category 建议：`puzzle`）

- 玩法：5×5 至 9×9 网格内分布若干对同色圆点，拖动连接每对圆点；路径沿格子走、不可交叉，用所有颜色的连线铺满全部格子即过关。
- 操作：从任一圆点（或已有连线的任意格）按住拖动划线；往回拖可撤销线段；点击「重玩本关」清空重画；「选关」可回溯已解锁关卡。
- 说明：单文件自包含 H5，零外链；关卡包内默认 108 关，支持管理后台下发扩展；进度（解锁/最佳连线次数/星级）自动保存并双写账号。

## 关卡数据

- `.levels.json`：顶层数组，信封 `{levelNo,name,difficulty,data:{size,pairs:[{c,a,b}]}}`，共 108 关。
- 生成方式：确定性哈密顿路径（行蛇/列蛇/螺旋随机取向）经 2-opt 随机重排后随机切段，每条线段即一组同色端点的解路径（构造法保证可解）。
- 校验：结构校验、组合唯一（含颜色置换同构去重）、独立求解器复核可解性、解覆盖全格且无交叉。
- 主题：UI 壳与棋盘走 `--g-*` token；连线素材色复用库内 `--g-bp1..8` 高辨识度色板，深色自动切换提亮变体；canvas 经 `PAL`/`__gOnTheme` 随桥推送重绘。
