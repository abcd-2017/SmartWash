# 分数切饼（gameKey：`fraction-pie`，category 建议：`puzzle`）

- 玩法：把一块切成 den 等分的披萨分给客人——每位客人要求自己的分数（k/den 即 k 块），所有人需求之和恰为整饼；后段关卡还要求每人拿到的块连成一片（环形绕回也算连续）。
- 操作：触屏点客人选中 → 点披萨块分给（再点可收回），点「自动配一人」给选中客人配一段连续空块；键盘 ←→ 选客人、Enter/空格自动配、U 撤销、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关 = 4-12 等分 × 2-5 位客人 × 连片要求开关，纯事件驱动（无计时），到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, den(4-12), need[2-5 人各需 k 块], contig(0/1)}`；validLevelData 强制 Σneed = den。
- 验证方式：游戏内嵌独立验证器 `selfTest`——① 40 关配置校验；② **标准锚点用例**（环形连续判定，手推）：连续弧真、三段散块假、空盘假、全满真、环形绕回真、双段假；③ **标准分配锚点**：den=6 需求 [3,2,1] 的标准分配三人全满足并触发胜利判定、超额不满足、连片模式下散块不满足而连续弧满足；④ **40 关全量复核**：非连片关顺序贪心可分配满、连片关按客人顺序做弧摆放后逐人通过满足判定。
- 生成与验证结果：14/14 项自检通过。**开发期曾修复 personOk 引用未定义变量的缺陷。** 纯事件驱动（无计时/AI），切后台无需暂停处理。
