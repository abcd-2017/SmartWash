# 空当接龙（gameKey：`freecell`，category 建议：`board`）

- 玩法：52 张牌全明置发成 8 列（前 4 列 7 张、后 4 列 6 张），另有 4 个自由格与 4 个归位区；连串（红黑交替、点数降序）可整体搬移，单张可入自由格中转，同花色从 A 起升序归位，四方收满即胜。
- 操作：点牌选中（可带整段连串），再点目标列 / 自由格 / 归位区；双击顶牌自动归位或入自由格；键盘 1-8 选列顶串、Shift+1-8 移入该列、Q/W/E/R 移入自由格、F 顶牌归位、Z 撤销、H 提示。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关按发局号种子确定性发牌，随难度递进（参考步数 32→57）；存档键 `sw.freecell.v1`，到达关卡经 GB 桥上报（desc，附步数）；无桥环境自动降级纯本地。连串可移上限 =（空自由格+1）×2^空列数，与经典规则一致。与 `solitaire`（Klondike，有牌库翻牌）规则实质不同。

## 关卡验证

- 每关结构 `{name, seed, par, difficulty}`：`seed` 为发局号，`mulberry32(seed)` 确定性洗 52 张后按行发 8 列；`par` 为构建期求解器给出的参考步数。
- 验证方式：游戏内嵌**独立求解器**（最佳优先搜索 + 安全自动归位 + 状态去重 + 连串搬移剪枝，cap 20000 节点），加载时先同步复核当前关、再后台逐关复核全部关卡；只有求解成功的关卡进入关卡表（坏关淘汰，复核完成前对应选关按钮保持锁定；校验计数只驱动解锁，不占玩家界面）。
- 生成与验证结果：构建期扫描 110 个候选种子选出 40 关（全部节点数 < 8000），运行期以同算法 cap 60000 复核 **40/40 通过**（复核最大节点数 7666，远低于上限）；jsdom 无头冒烟测试中游戏内验证器实测 40/40 通过。
