# 剪线拆弹（gameKey：`fuse-cut`，category 建议：`puzzle`）

- 玩法：炸弹上有 4-6 根彩色引线，面板给出若干条剪序线索（先后、定位置、禁位置、相连、紧随）；按唯一正确顺序点线剪断，全部剪对即拆除，剪错任意一根立即爆炸。
- 操作：触屏点引线剪断（已剪的线显示刀序号）、线索卡实时变绿/变红；键盘方向键选线、空格剪断、Z 撤销（爆炸前）、H 提示。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（4 线 → 6 线递进），到达关卡经 GB 桥上报（desc），爆炸次数随存档累计；无桥自动降级 localStorage。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, wires[中文名], clues[{t,a,b?,k?}], difficulty}`；线索类型 `before`（a 先于 b）/`pos`（a 恰在第 k 位）/`notpos`（a 不在第 k 位）/`adj`（a、b 相连）/`next`（剪完 a 立刻剪 b），下标指向 wires。
- 验证方式：页面内嵌**独立排列枚举验证器** `fcSolve`（N≤6 → ≤720 排列，带部分剪序约束与提前剪枝），加载每关时复核线索结构合法且**满足全部线索的剪序恰有一个**，非唯一解的关不进关卡表；提示功能用同一验证器给出当前部分剪序下的下一根线。
- 生成与验证结果：构建期先随机生成剪序，再逐条加入使解数严格下降的线索直到唯一解（并保证每根线至少被提及）；40/40 关通过包内验证器复核（唯一剪序）。
