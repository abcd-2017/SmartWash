# 不等数独（gameKey：`futoshiki`，category 建议：`puzzle`）

- 玩法：Futoshiki——n 阶拉丁方填数（每行每列 1..n 各一次），格间的蓝色不等号必须全部成立；盘面只有部分提示格，推理填满全盘即胜。
- 操作：触屏选格 → 点数字键盘填充（"清"清除）；键盘方向键选格、数字键填充、0/退格清除、U 撤销、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关 = 4/5/6 阶 × 提示数递减，离线生成器产关 + 唯一解验证，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, n(4-6), g[行提示串 0=空], h[行内不等号 < / > / 0], v[行间不等号（行界约定：v[r][c]=格(r,c)与(r+1,c)之间）], sol}`。
- 验证方式：游戏内嵌独立验证器 `selfTest`——① 40 关配置校验；② **标准锚点用例**（手排 4 阶拉丁方 1-2-3-4/3-4-1-2/2-1-4-3/4-3-2-1，逐格手推不等号）：满格题唯一、挖 (0,0)(0,1) 两格仍唯一（列约束强制回原值）、空盘有解——并用脚本核对锚点方与符号逐项一致；③ **40 关全量复核**：内嵌回溯求解器逐关计数解数（上限 2），全部唯一且首解与 `sol` 一致。
- 生成与验证结果：6/6 项自检通过（含 40/40 关唯一解复核）；离线生成器与内嵌求解器为两套实现，全程一致。纯事件驱动（无计时/AI），切后台无需暂停处理。
