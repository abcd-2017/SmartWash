# 2048（gameKey：`g2048`，category 建议：`puzzle`）

- 玩法：4×4 网格滑动数字块，相同数字相撞合并翻倍并计分，凑出 2048 即胜利（可选择继续挑战更大数字），无可动方向即结束。
- 操作：触屏在棋盘上向任意方向滑动（位移阈值 30px、按主轴判定），或键盘 ↑↓←→ / WASD 兜底；「新游戏」随时重开，最高分本地保存。
- 说明：单文件自包含 H5；合并动画为简版——新块/合并块缩放淡入，无滑动位移动画。**已接入游戏数据平台化**：存档经桥代理跟随账号（本地 + 账号双写，账号更优才覆盖）；上报最高分进排行榜（desc，附最大方块值）。无桥环境自动降级为纯本地。
- 主题：按 `GAME-THEME.md` D5 接入——主题由桥唯一控制（无桥恒浅色），深色仅经 `__applySmartWashTheme` 推送进入，无 matchMedia / 无页面内切换；数字块色板为玩法素材保留原值，棋盘/空格走 `--g-board`/`--g-cell` 素材 token 深色变体，>2048 超级块走 `--g-tilesuper`。
