# 浇园定水（gameKey：`garden-waters`，category 建议：`other`）

- 玩法：一畦 3-6 株需水习性各异的植物（蒸腾速率与舒适湿度带不同），水箱有限，点水阀给植物补水，把每株湿度都稳在绿区直到收工——旱了积累旱胁迫、涝了积累涝胁迫，任一株状态满格即失败。
- 操作：触屏点植物开/关对应水阀（再点关闭）；键盘 1-6 直接开/关水阀、左右键+Enter 选择开关、空格 暂停/继续、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，株数/带宽/蒸腾随关递增，水阀同时全开会抢水箱。

## 关卡验证

- 内嵌 40 关，每关结构 `{name,time,tank,plants:[{drain,lo,hi}],difficulty}`；`tank` 由参考策略实测用水量 ×1.25+4 得出。
- 验证方式：游戏内嵌**确定性模拟器** `GW.tick`（0.25s 固定步长纯函数：开阀补水/蒸腾/旱涝双向胁迫积分）+ **参考策略回放** `GW.runPolicy`（带回差的滞环阀控：低于下沿+4 开、到上沿-3 关），生成期逐关断言策略回放全存活且 maxStress ≤60，`GW.validate` 复核结构+可解性。
- 锚点用例（`window.__validateLevels()` 共 7 条，node 抽取 XC-CORE 复现）：旱胁迫单步 0.375（(40-37.5)×0.6×0.25 精确，含本拍蒸腾）、开阀单步 +2.0（(10-2)×0.25 精确）、空箱只蒸腾 -0.5（精确）、枯死一拍判定 dead、策略回放存活（用水 80.6L 可复核）、40 关策略回放全部存活、生成逐字节确定。
- 生成与验证结果：40/40 关参考策略回放全部存活（fail 空），未触发兜底。
