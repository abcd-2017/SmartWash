# 齿轮联动（gameKey：`gear-mesh`，category 建议：`puzzle`）

- 玩法：轴点网格上已有一个主动轮（标「动」）和若干固定轮（黄色带转向箭头）；在空轴上放齿轮、让相邻齿轮互相咬合，把主动轮的转动传到全部目标轮（红圈=未带动，绿圈=已带动），齿数上限内完成即过关。
- 操作：触屏点空轴放齿轮、点已放的收起；键盘方向键移动光标、空格/回车放收齿轮、Z 撤销、H 提示。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（5×5 → 6×7 递进），到达关卡经 GB 桥上报（desc）；无桥自动降级 localStorage。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, cols, rows, pegs[[x,y]], driver, targets[], fixed[[i,dir]], tray, par, difficulty}`；轴点正交相邻即咬合，`fixed` 的方向必须与曼哈顿奇偶一致（二部格上连通后转向唯一确定）。
- 验证方式：页面内嵌**独立验证器**（并查集连通检查 + 空轴子集枚举），逐关求「最少补充齿轮数」：必须 1 ≤ min ≤ tray 且 `par` 与之一致，否则该关不进关卡表；提示功能用同一验证器给出与当前摆位差最小的补/收建议。
- 生成与验证结果：构建期用「连通斑块生长」保证轴点全连通，再指派目标与固定轮；40/40 关通过包内验证器复核（可解、最少齿数与 par 一致、固定轮方向合法）。
