# 字形演变（gameKey：`glyph-pair`，category 建议：`word`）

- 玩法：左列展示 4 枚甲骨文线条画，右列展示 4 个今字，两列配对；配对成功即展示该字「甲骨文 → 金文 → 今字」三段演变链，全部配对过关。
- 操作：触屏左列点甲骨文、右列点今字；键盘 1-4 选甲骨文、Q/W/E/R 选今字、R 重开；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关由固定种子生成器从 43 字字形库产关（每关 4 字）；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, zs[4], difficulty}`；字形库为 43 个常用意符字，每字含甲骨文（细线）与金文（粗线+饰段）两套 SVG 线段画，全部 canvas/SVG 自绘、零版权素材。
- 内嵌独立验证器逐关复核：① 结构完整（zs 恰 4 字、关内唯一）；② 内容引用正确（每字必须命中字形库，甲/金两套线段画齐备）；③ 可通关性由配对构造保证（右列必含对应今字）。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核，异常关会在消息区告警）。
- 内容口径：古字形为**简化线条意符画**（如「日」圆中一横、「木」上枝下根），不追求学术摹写精确但须可辨识；字形库内建 43 条图形特征提示，配错时给出形状线索。
