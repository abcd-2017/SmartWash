# 黄金矿工（gameKey：`gold-miner`，category 建议：`arcade`）

- 玩法：钩子在井架滑轮上自动左右摆动，摆到目标方向时点按放钩，钩子沿当前角度直线伸出，碰到物品即抓住并匀速收回（越重收得越慢），收回入账；限时内凑够目标金额过关。金块 50/150/500、钻石 600（又贵又轻）、石头 11/20（重而不值钱，可引爆弃单）、神秘袋开出金币或炸药。
- 操作：点画布或「放钩」按钮出钩；钩住物品收回途中点「引爆」按钮可炸掉不值钱的战利品（每关限量，立即空钩快速收回）；支持空格/回车放钩、B 引爆、P 暂停。
- 说明：单文件自包含 H5，Canvas 全自绘（零外链零素材文件）；120 关（包内默认前 12 关 + DB 下发），关卡含确定性种子，神秘袋开袋结果整局可复现；进度（解锁/最佳金额）本地与账号双写，过关上报成绩；主题经桥推送深浅色，卡片式布局，375px 视口无横向溢出。

## 关卡数据格式（dataJson）

`{name, time, target, seed, dyn, items}`：

| 字段 | 含义 | 域 |
|---|---|---|
| `name` | 关卡名 | 非空 ≤32 字 |
| `time` | 限时（秒） | 30–90 |
| `target` | 目标金额 | 100–999999 |
| `seed` | 确定性种子（神秘袋开袋等） | 0–2147483647 |
| `dyn` | 本关炸药数 | 0–4 |
| `items` | 物品布局 `[type,x,y,size]` | 6–16 件 |

- `type`：`g` 金块（size 1/2/3）、`s` 石头（size 1/2）、`d` 钻石、`m` 神秘袋（size 恒 1）；`x/y` 为逻辑坐标（360×440 世界，地表之下）。
- 物品必须在钩子摆动可达扇区内、互不重叠、不出墙（下发解析逐条校验，任一条非法整批放弃）。
