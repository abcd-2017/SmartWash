# 高尔夫纸牌（gameKey：`golf-solitaire`，category 建议：`board`）

- 玩法：28 张牌明置 7 列（每列 4 张），其余 24 张为牌堆、第 1 张翻开为基牌；点数等于基牌 ±1（K-A 环绕）的列顶牌可收进基础堆并成为新基牌，无牌可收时翻牌堆换基牌，七列全部收空即胜。
- 操作：点可收的列顶牌（绿色描边标识）直接收进基础堆，点牌堆换基牌；键盘 1-7 收对应列顶牌、D 换基牌、U 撤销、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关按发局号种子确定性发牌，参考步数 42→51 递进；存档键 `sw.golfsolitaire.v1`，到达关卡经 GB 桥上报（desc，附步数）；无桥环境自动降级纯本地。邻点数连收玩法为合集新增，与接龙/配对类规则不同。
