# 五子棋 · 人机对弈（gameKey：`gomoku`，category 建议：`board`）

- 玩法：15×15 棋盘，玩家执黑先手，AI 执白后手，先连成五子者胜、棋盘下满为和棋；战绩（胜/负/和）localStorage 累计。
- 操作：点按棋盘任意位置自动吸附最近交叉点落子；底部「悔棋」一次撤回 AI 与玩家的两步棋，「重新开局」清空棋盘。
- gameKey 建议：`gomoku`；分类建议：`board`。AI：单层加权评分制（成五/活四/冲四/活三等棋型攻防加权求和，无搜索树），中等休闲难度。
- 说明：**已接入游戏数据平台化**：存档经桥代理跟随账号（本地 + 账号双写，账号胜场更多才覆盖本地）；上报胜场进排行榜（desc）。无桥环境自动降级为纯本地。
