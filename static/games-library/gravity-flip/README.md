# 重力反转（gameKey：`gravity-flip`，category 建议：`puzzle`）

- 玩法：重力滑块迷宫。小球选定一个重力方向后一直滑到撞墙 / 出界 / 目标环为止（原地卡住的方向无效），反转重力规划滑行路线，滑进绿色目标环即过关。
- 操作：触屏点四个方向按钮或在盘面上滑动；键盘方向键即重力方向、Z 撤销、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关由包内种子生成器产出（6×6→9×9、墙密度递增），到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 每关结构为 `{name, rows[], cols, rowsN, par, difficulty}`；`rows` 为棋盘字符行（`.` 空 / `#` 墙 / `S` 起点 / `G` 目标环），`par` 为最少滑动次数。
- 生成方式：包内固定种子（20261130）生成器按密度带随机布墙放起终点，BFS 可达且 par≥4 才收关，全距均匀采样保证 par 谱铺开（4→11 递进），重复盘面剔除。
- 验证方式：游戏内嵌**独立验证器**——`gfBFS` 对 (位置×重力) 双状态空间做 BFS（父指针重建首着），加载每关复核可达性并计算最少滑动次数；DB 下发关卡逐关过滤，不可达关不进关卡表。
- 生成与验证结果：40/40 关可达，BFS 实测最优与关卡 `par` 一致；规格 6×6→9×9，par 4→11 随难度递进。
