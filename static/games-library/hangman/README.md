# 猜单词（gameKey：`hangman`，category 建议：`word`）

- 玩法：经典猜单词玩法：隐藏一个英文单词并给中文释义。点屏幕字母键逐字母猜，猜对填入、猜错扣一次机会；机会从 7 次收紧到 4 次，词长从 3 递进到 10，共 122 关、八大主题。
- 操作：触屏点击屏幕内置字母键盘（QWERTY 全键，热区 ≥44px），也支持物理键盘 A–Z；「上一关 / 重玩本关 / 下一关」自由切换，进度与已过关卡自动保存。
- 说明：单文件自包含 H5，零外链零素材文件；绞架与小人由 canvas 自绘，颜色全部经 CSS token（`PAL` + `__gOnTheme`）。关卡采用包内默认 + DB 下发双通道（`GB.getLevels("hangman")`），任一条非法整批放弃，无 DB 时回落包内默认。

## 关卡数据格式

```json
{ "name": "校园·01", "word": "art", "hint": "画画和手工制作一类的课程", "topic": "校园", "maxWrong": 7 }
```

- `word`：2–10 个英文字母（本库实际 3–10）
- `hint`：非空中文释义，不含答案中的任何字母
- `topic`：主题分组（校园 / 食物 / 生活 / 动物 / 自然 / 运动 / 科技 / 旅行）
- `maxWrong`：错误机会上限，4–7（随词长 7→4 递减）
