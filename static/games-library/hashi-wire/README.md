# 数桥（gameKey：`hashi-wire`，category 建议：`puzzle`）

- 玩法：在岛屿之间架横竖的桥，可在同一对岛间架双桥，桥不能交叉。全部岛屿连通，且每座岛的桥数恰好等于岛上数字。
- 操作：触屏点两座同排岛屿架桥，再点一次加双桥；键盘方向键选岛/架桥、Tab 切换岛屿、Z 撤销、H 提示。
- 说明：单文件自包含 H5，canvas 自绘，零外链；48 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 48 关，每关结构为 `{name, r, c, islands[[x,y,n],...]}`。
- 验证方式：游戏内嵌**独立穷举求解器** `hashiSolve`（对候选边按 0/1/2 回溯 + 度数约束 + 交叉剪枝 + 连通性判定），统计解数上限 2；加载每关时复核，解数 ≠ 1 会告警；提示取该唯一解的桥数。
- 生成与验证结果：48/48 关唯一解（离线生成器以同一求解器复核，48 种不同岛屿布局）。
