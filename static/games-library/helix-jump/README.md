# 螺旋跳塔（gameKey：`helix-jump`，category 建议：`arcade`）

- 玩法：球贴螺旋塔面下坠，左右旋转塔身让球从缺口穿越、避开红色危险段（绿=安全反弹），层数走完落到终点平台过关；层数 / 红段密度 / 自转速度逐关递增。
- 操作：触屏左右拖动旋转塔身，键盘方向键 / A D 匀速旋转；「重试 / 选关 / 下一关」按状态切换；切后台提示暂停。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）。40 关由种子生成器确定性生成并**逐关做可通性验证**——把塔角可达集离散成 72 桶，层间按玩家旋转预算 ±90° + 自转漂移传播、与缺口求交，任一层可达集为空即判不可通并换种子重造（生成即验证闭环）；调试入口 `window.__validateLevels()` 可复现（node 抽取 XC-CORE 段独立运行）。碰撞判定（段角度区间含接触点）与验证器共用核心。关卡缓存 `sw.helixjump.v1.levels`，DB 下发整批替换（不可通整批放弃）；存档 `sw.helixjump.v1` 双写，过关上报到达关卡（desc）。
