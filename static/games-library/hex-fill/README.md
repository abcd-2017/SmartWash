# 六角填色（gameKey：`hex-fill`，category 建议：`puzzle`）

- 玩法：六角网格部分格子预填三色，给空格补色——相邻六角格不能同色，且三种颜色的总数量必须与指定数量一致。
- 操作：触屏先点底部色板选色、再点六角格填色（同色再点清除）；键盘 1/2/3 选色、方向键移动、Enter 填色/清除、Z 撤销。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, rows, cols, cells(-1 空格 / 0-2 预填色), counts(三色目标数量), sol(唯一解), difficulty}`；棋盘 4×5 至 5×6，三色。
- 验证方式：游戏内嵌**独立验证器**（邻接表构建 + MRV 回溯计数器 `hxCount`，与交互逻辑分离）：要求解数恰为 1（相邻异色 + 每色数量双约束），并预检预填格无相邻冲突、计数不超；后台分片逐关复核，验证失败的关在选关面板禁用。
- 生成与验证结果：40/40 关唯一解（生成器逐格挖空、每挖一格即复核唯一性，构建期自检 + 运行时复核双重确认）。
