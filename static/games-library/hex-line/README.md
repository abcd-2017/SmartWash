# 六角连边（gameKey：`hex-line`，category 建议：`board`）

- 玩法：Hex 六角棋博弈，你执绿子要把棋盘上下两条绿边连成一条链，电脑执红子连左右两条红边，六方向相邻即连，先贯通自己两边者胜（Hex 无和棋）。
- 操作：点空格落子；键盘方向键移动光标、回车落子、U 悔棋、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关段位赛 = 盘面 5×5→11×11 递进 × AI 段位 1-6 × 先手让先组合，AI 用 0-1 BFS 虚拟最短路评估 + 必胜/必挡 + 二层前瞻，到达关卡经 GB 桥上报（desc）。切后台 AI 思考中断、轮次归还玩家。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, n(5-11), skill(1-6), first(0/1)}`；`first=1` 为电脑先手让先关。
- 验证方式：游戏内嵌独立验证器 `selfTest`——① 40 关配置与尺寸递进校验；② 连通判定双算法互核（BFS 版 vs 独立的并查集版）：主斜不相邻/反斜贯通/横行贯通左右三个构造局面；③ 最短路评估基准：空盘成本=n、整排封锁=INF；④ 必挡战术：电脑差一格成链时 AI 必落其威胁格；⑤ 8 局全 AI 自战对拍（盘面 5-7）：每步只落空格、终局由并查集独立复核且恰有一方贯通。
- 生成与验证结果：17/17 项自检通过（含 8/8 局 AI 对拍）。
