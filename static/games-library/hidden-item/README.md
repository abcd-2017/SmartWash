# 场景寻物（gameKey：`hidden-item`，category 建议：`puzzle`）

- 玩法：种子生成的房间场景里藏着若干件小物品（星星 / 爱心 / 钥匙 / 月亮 / 小鱼 / 树叶 / 铃铛 / 水滴 / 闪电 / 杯子），按上方清单限时把它们全部点出来，点错只计数不扣时，切后台自动暂停。
- 操作：触屏直接点场景中的隐藏物品；键盘方向键移动探针、回车探测。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（物品 3 → 8 件、限时 65 → 45 秒递进），到达关卡经 GB 桥上报（desc，附加剩余秒数）；无桥自动降级 localStorage。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, seed, m, time, difficulty}`；`seed` 驱 12 件陈设与物品布点（mulberry32 确定性回放），物品类型互不相同（即清单），布点满足物品两两间距 ≥0.14、与陈设保持最小距离（点选无歧义）。
- 验证方式：页面内嵌**模拟回放验证器**——按种子重建陈设与物品布点，校验物品界内、类型互异、间距达标；回放「逐件点选」可全部找齐。布点失败的种子直接弃用，加载时不符的关不进关卡表。
- 生成与验证结果：构建期按难度取物品数 / 限时随机产关，40/40 关通过包内验证器复核（布点合法 + 清单互异 + 回放可找齐）。
