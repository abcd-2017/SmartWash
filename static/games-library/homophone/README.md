# 同音辨析（gameKey：`homophone`，category 建议：`word`）

- 玩法：每关 4 题，给出一个挖空句子（如「他___家写作业」）与 2-4 个同音异形词候选，选出用得对的那个；选错即划掉可再选，四题答完过关。
- 操作：触屏点候选词；键盘 1-4 选择、R 重开；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关由固定种子生成器从 46 组同音词组（183 句例句）产关（每关 4 题，近重排布）；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每题结构为 `{s(含 ___ 挖空的句子), opts(同音词候选), ok(正确词下标)}`；候选 = 该题所属同音组的完整词表。
- 内嵌独立验证器逐关复核：① 结构完整（句子必须含挖空、候选 2-4 个无重复、ok 下标有效、候选词长 ≤2）；② **组表一致性**——每题的「句子+正确词」必须能在同音词组表中复核命中（词表逐字一致），否则该关告警；③ 可通关性显然（正确词必在候选中，选错可重选）。
- 数据抽查结论：46 组 / 183 句全部通过校验（挖空齐全、正确词均在组内词表）。
- 内容口径：46 组同音词对均为普通话同音（再/在、做/作、账/帐、度/渡、带/戴、反映/反应、已/以/己 等），例句逐条人工校对为该词的标准用法；不含方言读音或争议搭配。
