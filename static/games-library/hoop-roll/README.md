# 滚铁环（gameKey：`hoop-roll`，category 建议：`arcade`）

- 玩法：铁钩推铁环沿山道前进，坡度和颠簸会让铁环倾斜。向倾斜反方向轻推保持平衡，滚得越远分越高，倾倒即结束。
- 操作：触屏长按左/右半屏施加推力；键盘按住 ←/→ 施加推力，空格开始。
- 说明：单文件自包含 H5，canvas 自绘，零外链；最高距离经 GB 桥上报（desc），无桥降级 localStorage。
