# 成语十字（gameKey：`idiom-cross`，category 建议：`word`）

- 玩法：每关 2 个十字盘，横向一个四字成语、纵向一个四字成语，共享交叉格的一个字（7 格）；从 10 字字池（7 正字 + 3 干扰字）中选字放入格中，拼出纵横两句成语；两盘全拼对过关。
- 操作：触屏先点字池选字、再点空格放置；键盘 Tab 切换 + Enter 选择/放置；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌 80 组十字成语对；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每盘结构为 `{h(横成语), v(纵成语), ch(横共享位), cv(纵共享位), pool(字池)}`；字池由固定种子从盘面用字 + 干扰字库生成。
- 内嵌独立验证器逐关复核：① 结构完整（h/v 均为 4 字、共享位下标有效、字池 8-14 字无重复）；② **十字约束**——`h[ch] === v[cv]`（纵横共享字一致）且字池覆盖盘面全部用字（保证必有解）；③ 可通关性显然（正确字全在池中，放错可继续尝试）。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核，异常关会在消息区告警）。
- 内容口径：80 组横纵成语对全部为通行成语（如「一心一意 × 意气风发」共享「意」），逐组人工校对成语写法与共享字位置，不使用生僻或存疑组合。
