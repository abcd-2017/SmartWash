# 碎图拼合（gameKey：`jigsaw-snap`，category 建议：`puzzle`）

- 玩法：种子生成的风景画作切成 3×3 / 4×4 碎片散落在下方托盘，棋盘上铺着淡色参考图；把碎片拖回原位即锁定，放错会弹回托盘并计一次失误，全部归位过关。
- 操作：触屏按住碎片拖到棋盘松手；键盘 P 切换碎片、方向键移动光标格、回车放置、H 提示。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（3×3 → 4×4），到达关卡经 GB 桥上报（desc，附加失误数）；无桥自动降级 localStorage。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, n, seed, difficulty}`；`seed` 同时驱动画作生成与碎片打乱顺序（mulberry32 确定性回放，打乱顺序即托盘排列）。
- 验证方式：页面内嵌**模拟回放验证器**——按种子重建碎片序列后校验「碎片→归属格」映射为双射（每格恰一次），再逐块回放「放到归属格」直至铺满；映射重复或越界的关不进关卡表。
- 生成与验证结果：构建期按关卡序号取 3×3（前 22 关）与 4×4（后 18 关）+ 随机种子，40/40 关通过包内验证器复核（归属双射、回放可铺满）。
