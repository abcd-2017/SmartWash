# 跳一跳（gameKey：`jump-jump`，category 建议：`arcade`）

- 玩法：小人站在悬浮平台上，按住屏幕蓄力、松手起跳，抛物线飞向下一个平台；落在台面中心附近得分更高，连续落中心「perfect」连击加分翻倍（2/4/6/8/10 封顶），落台面边缘得 1 分，撞壁/掉落/越过即失败；限定平台数内达到目标分过关，按超出比例评 1~3 星。
- 操作：按住屏幕任意处蓄力（头顶压缩 + 底部力度条），松手起跳；支持桌面空格键按住/松开；「力度已满」闪烁提示蓄力封顶；重试与下一关走浮层按钮，切后台自动暂停。
- 说明：单文件自包含 H5，全屏 canvas 沉浸式（`setChrome('immersive')`），小人剪影与圆台/方台/井盖/便利店魔方等 6 种平台全部 canvas 自绘，零外链零素材。物理为自研解析抛物线（蓄力时长→初速，固定 60° 仰角 + 重力 2200），落点在起跳瞬间由解析式唯一确定，帧率无关；同按压时长必同落点。存档经桥代理跟随账号（`{lv, stars, best}`），关卡支持后台热更新（DB 下发 + 本地缓存 `sw.jump-jump.v1.levels` + 包内 6 关兜底，任一条非法整批放弃），过关上报到达关卡与得分。

## 关卡数据格式

```json
{ "name": "热身·第1关", "seed": 309682803, "count": 8, "target": 17, "sizeRange": [46, 60], "gapRange": [134, 174] }
```

- `seed`：确定性 PRNG 种子（正 int32），`mulberry32` 生成平台序列（间距/半径/高度差/造型），同一关跨端可复现。
- `count`：平台数 6–24（跳 count-1 次到关底）。
- `target`：目标分（达到即过关），上限为「全 perfect 连击」理论分的 82%。
- `sizeRange` / `gapRange`：平台半径与相邻中心距的取值区间（px），随关卡递进；引擎强制相邻平台不重叠。

## 计分与星级

- 落点距台心 ≤ max(6, r×0.24) 记 perfect：得 `2×min(连击数, 5)`（2/4/6/8/10 封顶）；台面内其余位置 +1 并断连；撞壁/掉落/越过失败。
- 星级：过关 1 星；≥ 目标 + (理论上限−目标)×25% 得 2 星；×55% 得 3 星。

- 生成器：`docs/level-gen/tools/jump-jump/generate.mjs`（110 关：平台数 8→17、半径 [46,60]→[28,42]、中心距 [134,174]→[178,348] 四维递进）。每关先逐跳几何可达校验（满蓄力射程 ≥ 跳距窗口左缘、最小跳不越过右缘），再用「策略玩家模拟」（解析反解瞄准中心 + 高斯按压误差 σ 0.042→0.018 递进，判定计分与线上引擎逐字同构）统计分数分布，目标锚定 P40（通过率约 60%）并夹取理论分 28%~82%，复验通过率 ≥55%，不达标换种子重生成。
