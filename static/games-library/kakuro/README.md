# 数谜（gameKey：`kakuro`，category 建议：`puzzle`）

- 玩法：在白色格子填 1-9，使每段横向、纵向数字之和分别等于黑格右上的横提示与左下的纵提示，且同一段内数字不重复。
- 操作：触屏点选白格后点数字盘；键盘方向键移动选格、1-9 填数、0/Backspace 擦除、Z 撤销、H 提示。
- 说明：单文件自包含 H5，canvas 自绘，零外链；48 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 48 关，每关结构为 `{name, n, g[], sol}`：`g` 为 n 行 token（`#` 黑格、`.` 白格、`a\d` 横/纵提示），`sol` 为白格行主序答案。
- 验证方式：游戏内嵌**独立穷举求解器** `kakuroSolve`（回溯 + 段内不重复 + 段和剪枝），统计解数上限 2；加载每关时复核，解数 ≠ 1 会在消息区告警；提示直接取该唯一解。
- 生成与验证结果：48/48 关唯一解（离线生成器以同一求解器穷举复核，48 种不同盘面）。
