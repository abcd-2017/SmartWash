# 开锁时机（gameKey：`key-turn`，category 建议：`arcade`）

- 玩法：指针绕三环锁芯扫动，看准当前亮环缺口点按对位——对上即锁环，三环依次全开过锁；失手扣一次机会，用完锁死。转速 150→297°/s 逐关加快、缺口随之收窄，共 42 关。
- 操作：触屏点屏幕对位；键盘空格对位，P 暂停、R 重开本关。
- 说明：单文件自包含 H5，零外链、canvas 自绘；42 关内嵌，逐关验证对位窗口 ≥111ms（403ms 渐进收窄，节奏可掌握、可通关）；接 GB 桥存档/关卡/成绩上报，无桥降级 localStorage。
