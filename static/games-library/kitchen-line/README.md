# 后厨流水线（gameKey：`kitchen-line`，category 建议：`other`）

- 玩法：按订单上的投料顺序点食材（面/蛋/菜/肉/酱/芝/米/海八种），一道做完自动出餐；点错全部订单扣耐心，砸满 3 单收摊。
- 操作：触屏点食材；键盘 1-8 选料 · 空格出锅 · Z 撤一步 · R 重开；切后台自动暂停（计时基点平移）。

## 关卡验证

- 内嵌 40 关，确定性订单生成（食材池 3→8 种、重复度与订单数递进，限时 34s→18s）；关卡结构含订单序列与需求序列。

- 锚点用例：第 1 关完美策略出餐零砸单；错投触发扣耐心；连续砸 3 单正确收摊。
