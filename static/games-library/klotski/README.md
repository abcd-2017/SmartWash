# 华容道（gameKey：`klotski`，category 建议：`puzzle`）

- 玩法：4×5 棋盘滑块棋。2×2 的曹操与长条、小卒错落相扣，每次滑动一个滑块（不可越界、不可压块），把曹操移到底部虚线出口即过关，步数越少越好。
- 操作：点选滑块后拖动，或点相邻空位走一格；也支持键盘方向键。每关记录最少步数。
- 说明：单文件自包含 H5，内置 12 个默认关卡（含经典「横刀立马」），支持 DB 下发关卡、进度存档与成绩上报。

## 关卡数据

- 格式：`{ "name": "…", "blocks": [[x,y,w,h],…], "goal": [x,y] }`
  - `blocks` 第一块恒为 2×2 主块（曹操）；其余为 2×1 / 1×2 长条与 1×1 小卒。
  - `goal` 为主块左上角目标位，缺省 `[1,3]`（底部中间出口）。
- 包内 `DEFAULT_LEVELS` 12 关；`.levels.json` 下发 128 关（难度 1–10，五档块集递进）。
- 生成方式：以可解根布局跑 A* 求最优路径，沿路径取后缀精确命中目标最少步数，再随机游走扩展变体；独立校验器复核结构 / 可解性 / 唯一性。
