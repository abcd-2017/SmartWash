# 解绳结（gameKey：`knot-free`，category 建议：`puzzle`）

- 玩法：平面图展开谜题。绳段是硬绳不会弯折，拖动圆点 rearrange 位置，让所有绳段互不交叉即过关；交叉点实时标红计数。
- 操作：触屏按住圆点拖动（松手结算）；键盘 Enter 依次选点、方向键按网格移动选中点、Esc 取消、U 撤销、H 提示（短暂显示解法位置虚线圈）。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；图形源自环/轮/梯子/网格/嵌套双环等平面图族的整数网格嵌入打乱，40 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 每关结构为 `{name, e[][], pos[][], sol[][], par, difficulty}`；`e` 为边集（点对），`pos` 为打乱后的点位置（网格坐标，两两不同且至少 1 处交叉），`sol` 为已知可展开嵌入（0 交叉），`par` 为打乱态交叉数。
- 验证方式：**独立验证器**（方向式严格相交判定 `vCross`，共享端点不计）在加载时逐关复核「sol 零交叉 + pos 有交叉」双重条件；**交互判定**（参数化求交法，交点参数 t/s 落在开区间才计交叉）负责实时交叉计数。两套实现互不引用、逐关交叉核对。
- 生成与验证结果：40/40 关满足双条件（4 个图族嵌入曾含非平面扇形，已修正为凸六边形+辐条），双实现交叉计数 40/40 一致；初始交叉数 1→30 随难度递进。
