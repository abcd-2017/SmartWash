# 灯升风变（gameKey：`lantern-rise`，category 建议：`arcade`）

- 玩法：按住控火放飞孔明灯，油量有限、左右推压回正灯身——灯越歪升力越低；阵风来临前有预警箭头，峡谷石台与岩壁会撞破灯纸（三盏灯），捡油袋补燃料。高度即分数，分数驱动冲最高分。
- 操作：触屏按住控火、左右拖动回正；键盘按住空格/W 控火、方向键或 AD 推压、P 暂停、R 重开。
- 说明：单文件自包含 H5，零外链、canvas 自绘；--g-* 主题 token 双主题；接 GB 桥最高分存档与成绩上报，无桥自动降级 localStorage。
