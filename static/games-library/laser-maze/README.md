# 激光折镜（gameKey：`laser-maze`，category 建议：`puzzle`）

- 玩法：激光从边框射入网格，遇到棱镜按 `/` 或 `\` 折转、遇到墙即止；点可动棱镜切换朝向，让光路命中全部圆环靶（靶为穿透式，命中后光继续前进），调整次数越少越好。
- 操作：触屏点带旋钮的棱镜转向（固定棱镜带警示色不可动）；键盘方向键移动光标、空格/回车转向、Z 撤销、H 提示。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（5×5 → 7×7 递进，杂棱镜与墙逐段增多），到达关卡经 GB 桥上报（desc）；无桥自动降级 localStorage。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, cols, rows, src[x,y,dir], mir[[x,y,rot,fixed]], tgt[[x,y]], walls[[x,y]], par, difficulty}`；`src` 必须在入射边框上，`rot` 0=`/`、1=`\`，`fixed` 1 为不可动。
- 验证方式：页面内嵌**独立验证器**（算术式反射 `/ : newDir=3-dir`、`\ : newDir=dir^1` + 递归光路模拟 + 循环剪枝），对 2^k（k≤8）可动棱镜朝向做全枚举：必须存在制胜组合、初始朝向不得已全中、`par` 必须等于最少翻转数；加载时逐关复核，不满足者不进关卡表。
- 生成与验证结果：构建期用「路径编织」构造式产关（先织光路、途中设靶与棱镜、再翻乱初始朝向），40/40 关通过包内验证器复核（存在制胜组合、初始非全中、par 复算一致）。
