# 点灯谜阵（gameKey：`lights-out`，category 建议：`puzzle`）

- 玩法：5×5 点灯，点击一格翻转自身与上下左右共五格，全部熄灭即过关；关卡制 50 关递进（生成步数 7→20），步数 ≤ 参考最优得 ★ 最优标记，50 关后转无尽随机阵型。
- 操作：点灯格翻转十字；「重开本关」恢复初始阵型，「上一关」回看已通关卡。
- 说明：单文件自包含 H5，零外链；每关由全灭状态倒推生成（奇偶校验保证参考最优可解，经 200 局抽测）；进度与 ★ 标记本地保存（`sw.lightsout.v1`）。**已接入游戏数据平台化**：存档经桥代理跟随账号（本地 + 账号双写，账号优先，关卡与 ★ 取并集更优才覆盖）；过关上报最高关卡（desc，越大越好）进排行榜。无桥环境（普通浏览器）自动降级为纯本地。**每日挑战**：工具栏「每日 MM-DD」入口，按本地 UTC+8 日期 seed 派生 k=6+seed%15 反向走棋生成当日棋盘（纯本地，绕过 DB 关卡），完成后在既有存档内追加 `daily` 记录（同日取更优，保留最近 30 天），成绩不进排行榜。
