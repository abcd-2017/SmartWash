# 密盒开锁（gameKey：`logic-box`，category 建议：`puzzle`）

- 玩法：一只盒子上串着 2-3 道机关——符号钮按点数排序按压、密码盘按先前机关的点数规律推算密码（求和 / 最大值 / 指定符号个数）、灯阵记忆复现；依次解开全部机关盒子弹开，按错会震动复位并计失误。
- 操作：触屏点按钮；键盘数字键按符号钮、+/- 调密码盘、方向键+空格点灯阵、回车确认。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（六种机关组合轮换），到达关卡经 GB 桥上报（desc，附加失误次数）；无桥自动降级 localStorage。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, stages[], difficulty}`；`stages` 为 2-3 道机关：`order`（`items[{g,n}]` 点数互异、规则 asc/desc）、`dial`（`src` 只能引用更早的 order 段，`mode` 为 sum/max/count，推演密码必须落在 0-9，sum 模式要求点数和 ≤9）、`pattern`（3-5 个互异亮格）。
- 验证方式：页面内嵌**模拟回放验证器**——按数据逐段推演标准答案（顺序排序 / 密码计算 / 灯阵校验）走完整个开锁流程，任何一段推演不出答案或引用非法的关不进关卡表；提示功能直接给出验证器推演的答案。
- 生成与验证结果：构建期按关卡序号轮换六种机关组合并随机参数，40/40 关通过包内验证器复核（每段答案可推演 + 密码盘引用合法）。
