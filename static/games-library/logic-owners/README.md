# 谁养鱼（gameKey：`logic-owners`，category 建议：`puzzle`）

- 玩法：几座房子各有宠物 / 饮料 / 颜色，依据全部为真的线索推出整张配对表，回答「谁养鱼」；提交错误扣一次机会，3 次内推出全表即过关。
- 操作：触屏点格子再点选项填入；键盘方向键选格、Enter 打开选项或提交、1-5 填值、Esc 关闭、H 提示（暴露光标格正确值）、R 重开、L 选关。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（种子生成），到达关卡经 GB 桥上报（desc，metricValue=过关关号，metricExtra=失误次数）；线索分三类：直接（X 号房…）、相邻（…和…相邻）、左右（…在…左边，不要求相邻）；不限时（纯事件驱动，切后台无需暂停）。

## 关卡验证

- 关卡结构 `{n,cats,pets,drinks,colors,clues[],sol}`：n=3..5 房、cats=2..3 类，sol 为每类一个排列（整数索引），clues 全部从 sol 导出（恒真）。
- 生成算法：随机真解 → 样本贪心选相对线索（每轮排除最多随机采样解）→ 构造性区分阶段（逐轮加入「排除假解最多」的直接线索，直至解集唯一，可证收敛）→ 极小化（单条删除仍唯一才删）。
- 验证方式：游戏内嵌**独立验证器** `verifyLevelData`（按类别维度枚举全排列 + 直接线索硬剪 + 相对线索分层剪枝 + 最深全量线索校验 `cluesSat`），要求解数恰为 1 且唯一解为真解；生成器求解计数 `countSols` 与验证器为两条独立实现路径，互为对拍。
- 标准锚点用例（人工推演核对）：①唯一解检测（3 房 1 类：房 1 狗 + 猫在鱼左 → 房 2 猫房 3 鱼）②非唯一检测（狗猫相邻 + 鱼钉房 3 → 恰 2 解）③2 类全路径唯一谜题（房 1 猫+牛奶 / 房 2 狗+茶 / 房 3 鱼+咖啡，5 线索）④3 类全路径唯一谜题（房 1 狗+牛奶+蓝 / 房 2 鱼+茶+红 / 房 3 猫+咖啡+绿，7 线索）。启动时逐关复核 40 关 + 锚点断言，坏关自动换种子重试，验证失败在消息区告警。
- 生成与验证结果：40/40 关唯一解通过（线索 3-12 条，N=3 两类递进至 N=5 三类），无告警。
