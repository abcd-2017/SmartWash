# 疯狂填词（gameKey：`mad-lib`，category 建议：`word`）

- 玩法：每关一篇 3 空趣文模板，逐空按词性提示（形容词/名词/动词/副词/数量词）从 4 个候选词中选词填入；全部填完生成一篇错位趣文并统计「预设笑点词」命中数，创作无对错、填完即过关。
- 操作：触屏点候选词；键盘 1-4 选择、R 重开；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 篇自撰模板内嵌；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=笑点词命中数）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, tpl(含 {0}{1}{2} 占位符), bs:[{t:词性, opts:[4候选], ok(预设词下标)}]}`；候选词 = 预设词 + 固定种子从同词性词池抽取的 3 个干扰词（5 个词池共 56 词）。
- 内嵌独立验证器逐关复核：① 结构完整（占位符数=空数、候选 3-5 无重复、ok 下标有效、候选词长 ≤6）；② **词性一致性**——每空正确项必须属于该词性的词池；③ **生成一致性**——内嵌关每空 ok 项必须与模板预设词逐一相等；④ 可通关性显然（每空必有候选，填完即过）。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核，异常关会在消息区告警）。
- 内容口径：模板与词池全部自撰，措辞保证任一候选词填入均语法通顺；「最佳词」为预设笑点组合，仅作娱乐计分、非标准答案。
