# 幻方（gameKey：`magic-square`，category 建议：`puzzle`）

- 玩法：幻方填数——n 阶盘面上把 1..n² 各用一次，使每行、每列与两条对角线的和都等于幻和 M = n(n²+1)/2；盘面只给出部分数字，推理填满即胜。
- 操作：触屏选格 → 点数字键盘填充（已用数字变淡，"清"清除）；键盘方向键选格、数字键填充、0/退格清除、U 撤销、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关 = 3 阶（洛书系）/ 4 阶（双偶法·含丢勒名方）/ 5 阶（连续摆法）× 提示数递减，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, n(3/4/5), g[行串 逗号分隔 0=空], sol, m}`。
- 验证方式：游戏内嵌独立验证器 `selfTest`——① 40 关配置校验；② **标准锚点用例**：洛书（幻和 15）满格唯一、挖 1 格仍唯一、丢勒幻方（幻和 34）唯一；幻和公式 n(n²+1)/2 手算核对；③ **40 关全量复核**：回溯 + 幻和/去重剪枝求解器逐关计数解数（上限 2），全部唯一且首解与 `sol` 一致。
- 生成与验证结果：7/7 项自检通过（含 40/40 关唯一解复核）。**开发期内嵌复核曾抓出离线生成器「按位置而非按已填数剪枝」缺陷导致 10 关非唯一，已按 sol 回填提示格修复后全量唯一；求解器对角线/行列剪枝同步改为按已填数计数。** 纯事件驱动（无计时/AI），切后台无需暂停处理。
