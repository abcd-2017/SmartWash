# 魔塔（gameKey：`magic-tower`，category 建议：`puzzle`）

- 玩法：经典魔塔式数值解谜，8 层精简塔。你从 1 层爬到顶层战胜塔主即通关。战斗自动进行：我方每回合造成「攻击-怪物防御」伤害，怪物反击「怪物攻击-我方防御」，先手优势下只承受 `回合数-1` 次反击；打不过的怪物会被拒绝进入。黄钥匙开黄门，红/蓝药水加生命，红/蓝宝石加攻防。
- 操作：点击相邻格子移动；点击远处格子自动 BFS 寻路，遇怪物/门/楼梯自动停下处理。
- 说明：单文件自包含 H5。8 层地图全部经离线贪略求解器验证可通（`docs/crossword-tools` 同目录思路，脚本见调研附录），数值曲线按全收集口径校准。进度（楼层/四维/钥匙）经 localStorage 持久化，重开自动清档。**已接入游戏数据平台化**：存档经桥代理跟随账号（本地 + 账号双写，账号楼层更高才覆盖本地）；关卡支持后台热更新（DB 下发 + 本地缓存 + 包内默认关兜底）；上报到达层数进排行榜（desc，附剩余 HP）。无桥环境自动降级为纯本地。
