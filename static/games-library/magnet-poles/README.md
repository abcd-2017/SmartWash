# 磁极互斥（gameKey：`magnet-poles`，category 建议：`puzzle`）

- 玩法：棋盘高亮槽位两两相邻配对放入磁体（每个磁体占两格、一端 N 一端 S），同极四向相邻即互斥；还要让每行、每列的 N 极数量对上边缘数字，全部槽位占满即过关。
- 操作：触屏点空槽选中、再点相邻槽放磁体；点已放磁体依次「翻转 → 再翻转 → 收回」；键盘方向键移动光标、Enter 选中/配对、Space 翻转、Delete 收回。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, w, h, slots(槽位格), rowN/colN(每行/列 N 极线索), sol(参考解: {a,b,dir}), difficulty}`；槽位由随机骨牌铺放产生（保证存在完美配对），6×6 至 7×7。
- 验证方式：游戏内嵌**独立验证器** `mpCount`（配对 × 极性回溯计数器，与交互逻辑分离）：剪枝含同极相邻冲突与行/列 N·S 容量，要求解数 ≥ 1（40/40 关实际唯一解）；后台分片逐关复核，验证失败的关在选关面板禁用。
- 生成与验证结果：40/40 关可解且唯一（构建期与运行时双重回溯复核；行列线索由参考解 N 极分布导出）。
