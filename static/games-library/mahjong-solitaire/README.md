# 麻将连连看（gameKey：`mahjong-solitaire`，category 建议：`board`）

- 玩法：层叠麻将牌阵，点选两张图案相同且都自由的牌即可消除；牌上方无压牌、左右至少一侧无遮挡即为自由；清空全盘过关，无子可消时自动洗牌（保底可解）。
- 操作：触屏点选两张牌；「提示」高亮一对可消牌，「洗牌」重排余牌，「选关」进入已解锁关卡，「重玩」重置本关；双指缩放、单指拖动查看牌阵。
- 说明：单文件自包含 H5，Canvas 自绘牌面（万 / 条 / 筒 / 风 / 箭符号化图形，零素材、零外链）；进度存 `localStorage`（`sw.mahjong-solitaire.v1`），通关数经桥上报排行榜，关卡支持 DB 下发。

## 关卡数据格式

`.levels.json` 顶层数组，每项信封 `{"levelNo":N,"name":"…","difficulty":D,"data":{…}}`，`data` 结构：

| 字段 | 含义 |
|---|---|
| `w` / `h` | 牌阵外接矩形列数 / 行数（2–35） |
| `p` | 牌对数（总张数 = 2p） |
| `g` | 长度 `7p` 的 base36 串：每对 7 字符 = `c1 r1 z1 c2 r2 z2 t`（列、行、层、图案编号） |

- 坐标 `c,r` 为牌位列 / 行索引，`z` 为层（0 为底层），同层相邻即左右遮挡，正上方有牌即被压。
- 图案 `t`：0–8 万、9–17 条、18–26 筒、27–30 风（东南西北）、31–33 箭（中发白）。
- 紧凑（单关 ≤ 500 字节）、可校验（长度、字符、边界、格位唯一、支撑、成对、可解性），确定性由固定种子生成。

## 生成与可解性验证

- 生成：`docs/level-gen/tools/mahjong-solitaire/generate.mjs`。采用**反向放置构造法**——按层升序、每层内逐行处理，每行先取中间一张作为 leftover，其余按「中心向外」成对放置（第 k 对为排序后第 m-k 与第 m+k-1 个）。每行右侧邻居总比该牌更晚放置，故放置时至少一侧无遮挡；层升序保证放置时上方无压牌。逆序消除必然可行，生成的棋盘按构造可解。120 关张数 30→120、难度 1→10 递进，形状含阶梯金字塔 / 菱形 / 团块 / 十字 / 台阶五族。
- 校验：`verify.mjs` 用**独立的记忆化回溯求解器**从终盘确认存在完整消除序列（不依赖生成见证），并复核生成器记录的消除见证；另检结构、格位唯一、支撑（无悬空）、成对、唯一性、数量与字节上限。
- 解析单测：`test-parse.mjs` 把 `.levels.json` 全量 `dataJson` 喂给引擎的 `parseDbLevels`，并覆盖结构非法、悬空、无解、批次任一条非法整批放弃等用例。
- 关卡缓存：DB 同步写入 `sw.mahjong-solitaire.v1.levels`（含版本号），启动时快校验（结构 + 支撑 + 成对）后使用；非法缓存整批放弃并回落包内默认关。包内 `DEFAULT_LEVELS` 含 15 关兜底。
