# 播棋（gameKey：`mancala`，category 建议：`board`）

- 玩法：播棋（Kalah 规则），点自己一坑取走全部种子逆时针播撒（跳过对方粮仓）；末子落入己方粮仓可再播一次；末子落在己方空坑可收割对面坑的种子；一方坑空则其余种子尽归对方，粮仓多者胜。
- 操作：点自己一侧的坑播种，或数字键 1-6 选左起第几坑；U 悔棋、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关 = 6/4 坑 × 3/4/5 籽 × AI 段位 1-6（negamax 深度 1-4，再播同手延续）× 先手组合，到达关卡经 GB 桥上报（desc）。切后台 AI 思考中断、轮次归还玩家。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, pits(6/4), seeds(3/4/5), skill(1-6), first(0/1)}`。
- 验证方式：游戏内嵌独立验证器 `selfTest`——① 40 关配置与坑数/籽数变体校验；② 播种守恒、跳过对方仓、普通落点、末子入仓再播、末子落空坑收割、跨仓播撒等单元测试；③ 终局收仓正确性；④ 6 局全 AI 自战对拍（覆盖 6/4 坑与 3/4/5 籽）：每手来自走法生成器、全程种子守恒、正常终局。
- 生成与验证结果：16/16 项自检通过（含 6/6 局 AI 对拍）。验证过程中曾抓出并修复「走法生成漏最后一坑」的实现缺陷。
