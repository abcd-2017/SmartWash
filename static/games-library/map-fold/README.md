# 折纸对位（gameKey：`map-fold`，category 建议：`puzzle`）

- 玩法：一张彩色格纹纸（双面同色），选一条横线或竖线沿其折叠（上半↓ / 下半↑ / 左半→ / 右半←，折叠后纸变小、翻过来的部分盖在上面），在参考折数内折出右上角的目标图案。
- 操作：触屏先点「折线：横向/纵向」与 −/＋ 调折线位置，再点四个方向按钮执行；键盘 ←/→ 调折线、↑/↓ 切横纵、1-4 执行四方向、Z 撤销展开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, w, h, init(初始顶色), target(目标顶色), tw, th(目标尺寸), folds(参考折数 1-3), difficulty}`；纸 6×6 / 7×7，色数 3-4，折叠后纸严格变小。
- 验证方式：游戏内嵌**独立验证器**（折叠转移 BFS，与交互逻辑分离）：折叠转移函数基于「翻转部分的顶面成为覆盖区新顶面」（双面同色纸），从初始状态广度优先搜索全部合法折叠序列（≤ 参考折数），要求目标图案可达；后台分片逐关复核，验证失败的关在选关面板禁用。
- 生成与验证结果：40/40 关在允许折数内可折出目标图案（生成器随机折出目标后，构建期与运行时双重 BFS 复核可达性）。
