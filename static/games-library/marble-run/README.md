# 弹珠轨道（gameKey：`marble-run`，category 建议：`other`）

- 玩法：部件有限——右升/右降斜轨改弹道、弹珠台重新弹射；在带墙块的底板上铺一条从落珠口到木桶的轨道再放珠，弹珠滚进桶即过关，掉出底部或超时失败。路径更长、墙更多逐关递增，省下的部件算分，共 42 关。
- 操作：触屏先点芯片选部件再点格铺设、点已铺件拆回；键盘 1/2/3 选件、方向键移动、空格铺拆、回车放珠、P 暂停。
- 说明：单文件自包含 H5，零外链、canvas 自绘；42 关内嵌，逐关用 shipped 弹珠物理函数重放验证 42/42 进桶（1.2~5.1s）；接 GB 桥存档/关卡/成绩上报，无桥降级 localStorage。
