# 密码破译（gameKey：`mastermind`，category 建议：`puzzle`）

- 玩法：经典 Mastermind 密码破译。系统给出一个秘密序列（4-6 位、4-8 色，颜色可重复），玩家逐轮提交猜测，每轮得到「位置+颜色均对」与「仅颜色对」两项反馈，在限定轮数内猜中即过关。共 120 关，位数、颜色数、轮数逐级递进。
- 操作：先点下方颜色圆点选色，再点棋盘中的空圆圈填入；再点一次已填的圆圈可撤回。填满后点「提交猜测」，「清除」清空本轮，「重玩」重置本关。反馈中实心点表示位置颜色全对，空心圈表示颜色对但位置错。
- 说明：单文件自包含 H5，零外链零素材，DOM/CSS 自绘。每颗棋子同时用颜色与编号（1-8）双区分，支持色弱玩家。关卡包内自带 12 关默认，优先使用管理后台下发关卡（DB 下发覆盖本地缓存）。进度自动保存，成绩经游戏桥上报。
