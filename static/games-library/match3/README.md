# 宝石消除（gameKey：`match3`，category 建议：`puzzle`）

- 玩法：8×8 宝石棋盘，交换相邻宝石使行或列连成 3 个及以上即消除，上方下落补充并触发连锁；在限定步数内达到目标分即过关，步数用完未达标可重试。开局棋盘无预设三连且至少有一步可消，无可走步时自动重排。
- 操作：触屏按住宝石向相邻格拖动，或点选一颗宝石后再点相邻宝石进行交换；「重玩本关」重置当前关，过关后点「下一关」继续。
- 说明：单文件自包含 H5，canvas 自绘 6 种宝石（形状 + 颜色双重区分），零外链零素材。已接入游戏数据平台化：存档经桥代理跟随账号（本地 + 账号双写，结构 `{lv}`）；关卡支持后台热更新（DB 下发 `{name,moves,target,colors,seed,board}` + 本地缓存 `sw.match3.v1.levels` + 包内 12 关兜底）；通关上报到达关卡与得分进排行榜（desc）。无桥环境自动降级为纯本地。

## 关卡数据格式

```json
{ "name": "红宝石·第1关", "moves": 13, "target": 1305, "colors": 4, "seed": 349561679, "board": "0203…011" }
```

- `moves`：限定步数（5–40）。
- `target`：目标分（≥100）。每个消除的宝石计 10 分，连锁会一次性消除更多宝石，故连锁天然加分。
- `colors`：宝石色数（4–6），色数越多越难凑连。
- `seed`：补充宝石的确定性 PRNG 种子（有符号 int32 正区间）。补充顺序固定（列从左到右、空位自上而下），因此同一关的每一步补充结果唯一可复现。
- `board`：64 字符初始棋盘（行优先，字符 `0`–`colors-1`）。开局保证无预设三连且至少存在一步可行消除。

## 关卡生成与验证

- 生成器：`docs/level-gen/tools/match3/generate.mjs`（120 关，难度按色数 4→6、步数与目标分递进）。
- 可通关验证：生成时用与线上**逐字同构**的引擎块做启发式贪心求解（立即收益 Top-6 候选 + 多次确定性重启），取 `target = 贪心最优分 × 难度系数`，贪心路径即具体解。
- 独立校验器：`validate.mjs`（结构 / 棋盘合法性 / 唯一性 / 数量 / 字节 / 独立贪心复跑）。
- 解析单测：`parse-test.mjs`（含非法输入整批放弃、`applyLevels` 持久化）。
- 冒烟：`smoke.mjs`（无浏览器 DOM 桩，验证启动、375 视口格子 44px、点选/拖动交换）、`smoke-bridge.mjs`（DB 下发整批应用、缓存与账号存档）。
