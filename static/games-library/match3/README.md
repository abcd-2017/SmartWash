# 宝石消除（gameKey：`match3`，category 建议：`puzzle`）

- 玩法：8×8 宝石棋盘，交换相邻宝石连成 3 个即消除并下落连锁；4 连生成条纹块（清整行/列）、L/T 形 5 块生成爆炸块（炸 3×3）、5 连生成彩虹块（与任意宝石交换清全场该色），特殊块互换还能触发组合（条纹+条纹=十字、条纹+爆炸=三行三列、爆炸+爆炸=5×5、彩虹+条纹=该色全变条纹）。每关 1~2 个目标（限步达分/收集指定颜色/清除冰层），全部达成才过关，剩余步数比例定 1~3 星。
- 操作：触屏按住宝石向相邻格拖动，或点选一颗宝石后再点相邻宝石交换；彩虹块与任意相邻宝石、任意两特殊块可直接交换（无需成三连）；「重玩本关」重置，过关后点「下一关」。
- 说明：单文件自包含 H5，canvas 自绘 6 种宝石（形状+颜色双重区分）与三种特殊块标记（条纹线/爆炸环/彩虹扇形，形状+颜色双区分适配色弱），零外链零素材。存档经桥代理跟随账号（本地 + 账号双写，结构 `{lv, stars}`）；关卡支持后台热更新（DB 下发 + 本地缓存 `sw.match3.v1.levels2` + 包内 6 关兜底）；通关上报到达关卡与得分。无桥环境自动降级纯本地。

## 特殊块

| 块 | 生成条件 | 触发效果 |
|---|---|---|
| 条纹块 | 4 连直线（横 4 连→清行、竖 4 连→清列） | 被消除/参与 3 连时清整行或整列 |
| 爆炸块 | L/T 形 5 块（横竖连交叉） | 被消除时炸开周围 3×3 |
| 彩虹块 | 5 连直线 | 与任意宝石交换清除全场该色；与条纹交换=该色全变条纹并触发；双彩虹=全场清空 |
| 组合技 | 任意两特殊块直接交换 | 条纹+条纹=十字双清、条纹+爆炸=三行三列、爆炸+爆炸=5×5 |

冰层为格子固定覆盖层（1-2 层，不随宝石下落），冰格自身或相邻格发生消除时破损一层（每波至多一层），清完全部冰即达成 ice 目标。

## 关卡数据格式

```json
{ "name": "红宝石·第1关", "moves": 15, "goals": [{"type":"score","value":1404}], "seed": 349561679, "board": "1122…2031", "ice": "0000…0000" }
```

- `moves`：限定步数（5–40）。
- `goals`：目标数组（1–2 个），三类：`{"type":"score","value":限步目标分}`、`{"type":"collect","color":色号,"count":收集数}`、`{"type":"ice","count":冰层总数}`。全部达成才过关。
- `seed`：补充宝石的确定性 PRNG 种子（有符号 int32 正区间），同一关每步补充唯一可复现。
- `board`：64 字符初始棋盘（行优先，字符 `0`–`9`）。色数由棋盘推导（最大字符+1，4–6 色且全色出现），开局无预设三连且至少一步可消。
- `ice`：可选，64 字符冰层编码（`0`/`1`/`2` = 该格冰层数），仅当 goals 含 ice 目标时存在且层数总和须与 `count` 一致。

## 关卡生成与验证

- 生成器：`docs/level-gen/tools/match3/generate.mjs`（120 关：前 5 关特殊块/冰层教学，目标类型 8 关一循环轮换，色数 4→5→6、步数与系数递进）。目标锚定「自然轮」贪心轨迹（分数 P25 分位；collect 按物理量锚定 moves×4.5/色数×难度系数），再用真实目标独立复验（必须存在全达成路径），冰关附加乱走通过率下限（≥15%）保证人类可达。
- 独立校验器：`docs/level-gen/tools/match3/validate.mjs`（信封契约 / goals 与 ice 一致性 / 棋盘合法性 / 唯一性 / 数量 / 字节 / 不同 pickSeed 的独立可通关复跑）。
- 引擎机制回归：`engine-test.mjs`（31 项白盒用例：特殊块生成位置/触发/全部组合/冰层/目标结算/无效交换）。
- 解析单测：`parse-test.mjs`（62 项：从 index.html 抽取真实 parseMatch3Levels/applyLevels，含非法输入整批放弃、ice 一致性、缓存持久化）。
- 统一终检：`docs/level-gen/tools/validate-all.mjs`（match3 分支已按新数据格式校验）。
