# 一步将杀（gameKey：`mate-in-one`，category 建议：`board`）

- 玩法：国际象棋残局题库，白先一步将杀；棋盘给出王/后/车/象/马/兵残局，找到那步杀着即过关，走错自动收回并计失误。
- 操作：触屏点白子再点目标格；键盘方向键移光标、Enter 选子/走子、Esc 取消、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；规则：无王车易位/吃过路兵，兵到底线自动升后；40 局内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 每局结构为 `{name, fen, par, sol, difficulty}`；`fen` 为 8×8 残局（白先、双方王均不被攻击），`sol` 为杀法（起止格）列表，`par` 为杀法总数。
- 验证方式：双引擎交叉——**独立验证器**（逐子扫描式伪走法 + 攻击覆盖判定）在加载时复核「存在白棋一步杀」并重算杀法集合；**对弈引擎**（射线式攻击判定）负责交互走子与将死判定。两套实现互不引用，杀法集合逐局比对必须完全一致。
- 生成与验证结果：40/40 局可解且双引擎杀法集合完全一致（34 局唯一解、其余 2-6 处杀法任选其一即胜），后段局面含马/兵升变配合杀。
