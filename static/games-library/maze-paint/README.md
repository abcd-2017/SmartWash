# 迷宫填色（gameKey：`maze-paint`，category 建议：`puzzle`）

- 玩法：带墙格迷宫中，从绿色入口出发沿通道一笔走遍全部格子（不重复、不漏格）即填满过关；通道里有刻意增设的误导支路，走回头路可沿原轨迹拖回。
- 操作：触屏从入口起拖动画线（拖回上一格即回退）；键盘方向键移动、Z 撤销、H 提示。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（4×5 → 6×7 递进，支路逐段增多），到达关卡经 GB 桥上报（desc，附加移动步数）；无桥自动降级 localStorage。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, cols, rows, open, start, difficulty}`；`open` 为每格开口位掩码的 base36 串（1=北 2=东 4=南 8=西），`start` 为入口格；掩码必须上下左右对称且无越界开口。
- 验证方式：页面内嵌**独立 Warnsdorff DFS 验证器**（优先走后续出口最少的邻格，节点预算 6 万），从 `start` 搜索哈密顿通路：无解或预算内无法确认的关不进关卡表；提示功能用同一验证器给出下一格。
- 生成与验证结果：构建期先用 Warnsdorff 随机哈密顿通路造迷宫（天然可解），再按难度概率增设支路，40/40 关通过包内验证器复核（结构合法 + 通路存在，且搜索均在预算内完成）。
