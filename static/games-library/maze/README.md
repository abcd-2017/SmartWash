# 迷宫（gameKey：`maze`，category 建议：`puzzle`）

- 玩法：在墙与路组成的迷宫中，从绿圈起点走到红旗终点。关卡全部由生成器构造（生长树打通所有通路），保证全图连通、起终点可达；每关给出「标准步数」（BFS 最短路径），不超过标准可获三星。
- 操作：点按虚拟方向键、在棋盘上滑动 / 拖拽、或点击相邻格移动；键盘方向键 / WASD 同样可用。
- 说明：单文件自包含 H5，零外链、素材全部 Canvas 自绘。包内自带 12 关默认关卡，后台可下发 120 关（DB 优先，本地缓存兜底，任一条非法整批放弃）；进度与每关最佳步数 / 用时自动存档，通关上报成绩。

## 关卡数据格式

```json
{ "name": "新手·回廊01", "rows": 9, "cols": 9, "cells": "111…010" }
```

- `cells` 为 `rows*cols` 的位图字符串：`'1'` = 墙，`'0'` = 路，行优先。
- 起点 = 行优先扫描首个 `'0'`，终点 = 逆序扫描首个 `'0'`（生成器固定落在左上 / 右下房间）。
- 游戏启动时对每个关卡做 BFS 复核：全部通路连通 + 起终点可达，并求出最短路径作为标准步数。
- `.levels.json` 顶层为数组，信封 `{levelNo,name,difficulty,data}`；levelNo 1..120 连续，难度 1-10 递进。

## 关卡生成与校验工具（docs/level-gen/tools/maze/）

| 脚本 | 作用 |
|---|---|
| `generate.mjs` | 确定性生成 120 关（9×9→19×19 递进，开口率递减 + Prim 权重递增使分支 / 死路比例递进），写出 `.levels.json`；`--defaults` 打印包内默认关字面量 |
| `verify.mjs` | 独立校验：契约、结构、BFS 连通、唯一性、数量 / 字节上限、难度递进、包内默认关一致性 |
| `test-parse.mjs` | 抽取游戏解析函数做单测：真实批次接收 + 各类非法输入整批放弃 |

复现：生成器逐关使用固定种子（失败按固定序列换种子重试），重复运行输出逐字节一致。
