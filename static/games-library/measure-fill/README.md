# 量词补位（gameKey：`measure-fill`，category 建议：`word`）

- 玩法：每关 3 题「一___×」量词填空（如 爷爷家养了一___大白马），从 3-4 个量词候选中选出正确搭配；选错即划掉可再选，三题答完过关，前 20 关 3 候选、后 20 关 4 候选。
- 操作：触屏点量词卡片；键盘 1-4 选择、R 重开；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关由固定种子生成器产关（120 条题库全覆盖）；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每题结构为 `{s(含 ___ 的搭配句), opts(量词候选), ok(正确量词下标)}`；题库为 120 条自撰强搭配语境句，干扰量词由固定种子从 62 个常用量词池抽取（排除正确项）。
- 内嵌独立验证器逐关复核：① 结构完整（句子含挖空、候选 3-4 个无重复、ok 下标有效、候选为 1-2 字量词）；② **题库一致性**——每题的「挖空句+正确量词」必须能在题库中复核命中，否则该关告警；③ 可通关性显然（正确项必在候选中，选错可重选）。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核）。
- 内容口径：挖空句均为强搭配语境（如 一匹大白马、一艘轮船、一峰骆驼、一枚邮票），正确量词按最常用的规范搭配人工核定；干扰量词来自通用量词池但填入句中明显不搭。
