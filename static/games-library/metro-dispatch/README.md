# 地铁发车（gameKey：`metro-dispatch`，category 建议：`other`）

- 玩法：一条地铁线几座车站持续来客，你择机从车厂发列车跑全程；车载容量有限、站台会挤爆滞留，发太早拉不满人浪费班次，发太晚旅客滞留超标被通报。
- 操作：触屏点「发一班车」；键盘空格/回车发车、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc），metricExtra 为累计送达人数。

## 关卡验证

- 内嵌 40 关（第 1 关为手工锚点关，其余由种子确定性生成客流后冻结为 `arr[站]=[{t,d}]`），结构 `{name, ticks, S 站数, K 组车, cap 容量, hop 站间 tick, dwell 停站, rt 折返, cd 发车间隔, lostMax 滞留上限, arr 客流, target}`。
- 验证方式：内嵌**策略回放验证器**（场上有积压且车库有空车时立即发车的贪心策略），逐关回放须 `win` 且无滞留；DB 下发关卡同样整表回放通过才接受。收敛链：加编组→降目标→加车（坏关不进表）。
- 锚点用例：① 第 1 关策略回放送达 ≥26 人且零滞留（全程 65 名到达）② 合成单点爆量关（小容量站瞬时涌入）必因滞留超标判负 ③ 全部 40 关回放可达成。
- 生成与验证结果：`MD.selfTest()` 3 项锚点全 PASS，40/40 关可达成。
