# 扫雷（gameKey：`minesweeper`，category 建议：`puzzle`）

- 玩法：9×9 棋盘埋 10 颗雷，翻开所有非雷格即胜；首点保护——第一次点击及其 3×3 邻域必不是雷；点开空格自动泛洪展开。
- 操作：点按翻开；触屏长按约 400ms 插旗/拔旗（已用 CSS 禁用长按弹菜单与合成 click 误触），桌面右键插旗；「新局」随时重开。
- 说明：剩余雷数 = 10 − 已插旗数，计时从首次翻开开始；数字配色沿用经典（1 蓝 2 绿 3 红 4 紫 5 深红 6 青 7 黑 8 灰）；最佳用时本地保存（`sw.minesweeper.v1`）。**已接入游戏数据平台化**：存档经桥代理跟随账号（本地 + 账号双写，账号优先，更优才覆盖）；通关上报用时（asc，越少越好）进排行榜。无桥环境（普通浏览器）自动降级为纯本地。
