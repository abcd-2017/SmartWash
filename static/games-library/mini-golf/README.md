# 迷你高尔夫（gameKey：`mini-golf`，category 建议：`arcade`）

- 玩法：俯视球道击球入洞。后拉拖动瞄准并蓄力，球受摩擦减速、与边界/障碍/坡道反弹；标准杆 +2 为限杆，超杆失败可重试。沙坑大幅减速，落水回原位并 +1 杆。
- 操作：在球道上向后拖拽（拖得越远力度越大），松手击球；「重试本关」重置，「选关」进入关卡列表。
- 说明：单文件自包含 H5，Canvas 自绘素材零外链。120 关由模板化生成器产出（直道/拐角/回廊/沙阵/碧水/斜坡/桩阵/综合），几何可达性与限杆经逐关校验；关卡支持 DB 下发（包内 10 关兜底），进度与星级自动保存。

- [x] 物理确定性：固定步长 1/120s 推进，圆-矩形 / 圆-圆反弹 + 指数摩擦 + 速度上限
- [x] 关卡信封：顶层数组，levelNo 连续，name ≤32，difficulty 1-10，单关 data ≤64KB
- [x] 校验：布局合法、发球区与球洞存在且不重叠、BFS 几何可达、限杆合理、组合唯一、120 关、≤2MB
- [x] 主题：token 两块 CSS + head 运行时（无按钮、无 matchMedia），canvas 颜色进 PAL，`__gOnTheme` 重绘
- [x] 触屏：拖动热区覆盖整条球道，按钮 ≥44px，375px 视口无横向溢出
