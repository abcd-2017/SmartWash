# 五五将棋（gameKey：`minishogi`，category 建议：`board`）

- 玩法：5×5 将棋，双方各持王飛角金銀歩六子；吃掉的子成为持驹、可打回盘中任意空格（步兵同列禁二歩、禁打敌阵底线）；进入敌阵自动升变（と/全/馬/龍）；吃掉对方王将即胜。
- 操作：点自己的绿子再点目标格；点底部持驹（或数字键 1-5）选驹后点空格打入；键盘方向键移光标、回车确认、Esc 取消、U 悔棋、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；lite 规则：自动升变、吃王制胜（无将帅宣告）；40 关 = AI 段位 1-6 × 让子（电脑无角/無飛/無銀/电脑先手）组合，negamax+α-β，到达关卡经 GB 桥上报（desc）。切后台 AI 思考中断、轮次归还玩家。
