# 找零大师（gameKey：`money-change`，category 建议：`other`）

- 玩法：商品已付清，用给定面额凑出指定找零额——凑够时所用张数等于最优张数才过关；前期是标准人民币面额（角 / 元），后期换成受限面额集，贪心常常失效，要用最优组合思维。
- 操作：触屏点面额累加（超过目标会拦下），点已用张数区下方的撤销回退；键盘 1-8 选面额、Z 或 Backspace 撤销、H 提示（显示最优张数）、R 重开、L 选关。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（种子生成，金额 1-80 元、面额集 3-8 种），到达关卡经 GB 桥上报（desc，metricValue=过关关号，metricExtra=所用张数）；金额一律以「分」为整数单位；不限时（纯事件驱动，切后台无需暂停）。

## 关卡验证

- 关卡结构 `{coins[],target,best}`：coins 为面额（分）升序数组，target 为找零额（分），best 为最少张数。
- 生成算法：标准关用人民币面额（10/50/100/500/1000/2000/5000/10000 分）随机角级目标；受限关随机抽 3-4 种面额、目标取 2-5 枚面额之和保证可凑；迭代 DP 求最优张数，不可凑自动换种子重试（5 次后退化为固定可凑关卡兜底）。
- 验证方式：游戏内嵌**独立验证器**（广度优先 BFS 分层搜索，与生成器的迭代 DP 为不同实现路径），核对可凑性与最优张数一致。
- 标准锚点用例（人工核对）：①标准面额 160 分 = 100+50+10 → 3 枚 ②贪心陷阱集 [1000,900,400] 目标 1800：贪心 1000+400+400 共 3 枚、最优 900+900 共 2 枚（DP/BFS 均应为 2）③[1000,900] 目标 500 不可凑（DP/BFS 均判不可达）④BFS 与 DP 对拍一致。启动时逐关复核 40 关 + 锚点断言，验证失败在消息区告警。
- 生成与验证结果：40/40 关 DP/BFS 对拍一致通过，无告警。
