# 直棋（gameKey：`morris-line`，category 建议：`board`）

- 玩法：直棋（九子直棋 Nine Men's Morris），布子阶段轮流落 6-9 枚子，三子成线即成「三」并提掉对方一子（成三中的子受保护）；布满后沿线走子，剩三子可飞到任意空位；对方只剩两子或无路可走即胜。
- 操作：布子点空位；走子先点自己的绿子再点目标点；成三后点对方高亮子提掉；键盘方向键移动光标、回车确认、Esc 取消、U 悔棋、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关段位赛 = 子数 9/7/6 × AI 段位 1-6 × 先手组合，negamax+α-β 含提子分支展开，到达关卡经 GB 桥上报（desc）。切后台 AI 思考中断、轮次归还玩家。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, men(6-9), skill(1-6), first(0/1)}`。
- 验证方式：游戏内嵌独立验证器 `selfTest`——① 40 关配置与子数变体校验；② 棋盘拓扑校验：邻接表对称、总度数=64、16 条成三线在邻接表上首尾相连；③ 成三识别与提子保护单元测试（含「对方皆在三中」的降级规则）；④ 飞子规则（剩三子可至任意空位）；⑤ 6 局 AI 低深度自战对拍（9 子与 7 子规则）：动作合法、提子只提对方子、正常终局。
- 生成与验证结果：16/16 项自检通过（含 6/6 局 AI 对拍）。
