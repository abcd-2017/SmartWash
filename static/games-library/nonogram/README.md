# 像素数织（gameKey：`nonogram`，category 建议：`puzzle`）

- 玩法：根据行列提示数字还原隐藏像素画，共 12 关原创图样（十字标、圣诞树、小房子、蝴蝶、爱心、棒棒糖、船锚、猫头、蘑菇、小火箭、帆船、城堡），尺寸从 5×5 递进到 10×10。行/列提示数字表示该行/列中连续填充段的长度，段与段之间至少空一格；某行/列当前填充恰好满足提示时，对应数字自动变绿（满行自动核对）。
- 操作：点按填格（再点取消）；长按约 340ms 标记叉/取消叉（已填格不会被叉覆盖）；按住拖动可连续刷格（起手格状态决定刷入"填"还是"擦"）；桌面右键标记叉。「提交完成」统一核对——填错不判死，只提示矛盾格数并高亮错误格；「即时纠错」开关打开后，填在底图空处的格子会立刻闪红退回（只计纠错次数，不结束游戏）。通关后覆盖层以逐格动画揭示像素画，解锁下一关。
- 说明：步数只统计填/擦操作（画叉不计）；每关最佳步数、通关进度与即时纠错开关存于 localStorage（键 `sw.nonogram.v1`，全部 try/catch 包裹）。12 幅像素图均为本项目原创设计，玩法参考经典 Nonogram 规则，未抄用任何原型代码。
