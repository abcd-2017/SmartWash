# 数径最大（gameKey：`number-maze`，category 建议：`puzzle`）

- 玩法：从网格左上角走到右下角，每次只能向右或向下走一格，收集路径上数字之和；后期出现负数格与障碍格，要走出与参考最优一致的最大和路径。
- 操作：触屏点击当前端点右侧 / 下方的格子延伸路径，点已走路径任意格回退到该处；键盘 →/↓ 走一格、←/↑ 撤销、H 提示（高亮下一步）、R 重开、L 选关。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（种子生成，5×5 无障碍递进到 7×7 障碍+负数），到达关卡经 GB 桥上报（desc，metricValue=过关关号，metricExtra=路径步数）；不限时（纯事件驱动，切后台无需暂停）。

## 关卡验证

- 关卡结构 `{n,vals[],obs[],best}`：n=5..7，vals 为格值（可走 1-9 或 -4..-1，障碍格 0），obs 为障碍布尔阵，best 为起点至终点（仅右 / 下移动）的最大收集和。
- 生成算法：seeded 随机网格（障碍率 0→0.18、负数率 0→0.30 递进），滚动 DP 计算最优并校验可达且最优和为正，不满足自动换种子重试（5 次后退化为无障碍正数网格兜底）。
- 验证方式：游戏内嵌**独立验证器** `verifyLevelData`（自顶向下记忆化递归 `suf`，与生成器的滚动 DP 为两条不同实现路径），核对可达性、最优和与关卡 `best` 一致、格值 / 障碍边界。
- 标准锚点用例（人工核对）：①2×2 全正格最优 8（右右下下 vs 下下右右取大）②3×3 含负格最优 30（绕开 -1/-2）③3×3 双障碍唯一路径最优 21 ④3×3 对角负数最优 -1（两条路径同值）。启动时逐关复核 40 关 + 锚点断言，坏关自动换种子重试，验证失败在消息区告警。
- 生成与验证结果：40/40 关最优一致通过，无告警。
