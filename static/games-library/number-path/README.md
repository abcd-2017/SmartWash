# 数字长径（gameKey：`number-path`，category 建议：`puzzle`）

- 玩法：网格上散布着路径锚点数字，把其余格子填上数字，使 1、2、3……终点每个数字都落在四向相邻的格子里，连成一条完整的长径。
- 操作：触屏点空格选中、再点底部数字板填入（「擦」清除）；键盘方向键移动、1-9 直接填、0/Backspace 擦除、Z 撤销、H 提示。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, w, h, g(锚点数字数组，0=空), sol(完整路径解), difficulty}`；棋盘 5×5 至 6×6（25-36 格），路径覆盖全格。
- 验证方式：游戏内嵌**独立验证器** `npCount`（数字序回溯计数器，与交互冲突检查分离）：按 1→N 顺序回溯（固定数字校验 + 空格枚举 + 下一锚点邻接偏置剪枝），要求解数恰为 1；后台分片逐关复核，验证失败的关在选关面板禁用。
- 生成与验证结果：40/40 关可解且唯一（生成器用随机哈密尔顿路径产解，逐格挖空、每挖一格即复核唯一性，构建期自检 + 运行时复核双重确认）。
