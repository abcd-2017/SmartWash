# 数墙（gameKey：`nurikabe`，category 建议：`puzzle`）

- 玩法：把格子涂黑成海。黑海必须连通且不能出现 2×2 黑块；每座数字岛恰好包含一个数字，且岛屿格数等于该数字。
- 操作：触屏点空格在「涂黑 / 留白」间切换；键盘方向键移动光标、空格/回车切换、Z 撤销、H 提示。
- 说明：单文件自包含 H5，canvas 自绘，零外链；48 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 48 关，每关结构为 `{name, r, c, nums[[x,y,n],...]}`。
- 验证方式：游戏内嵌**独立穷举求解器** `nurikabeSolve`（按岛枚举连通形状的不交组合 + 黑海连通/无 2×2 约束），统计解数上限 2；加载每关时复核，解数 ≠ 1 会告警；提示取该唯一解的黑海掩码。
- 生成与验证结果：48/48 关唯一解（离线生成器以同一求解器复核，48 种不同岛屿布局）。
