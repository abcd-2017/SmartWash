# 螺母配对（gameKey：`nut-bolt`，category 建议：`puzzle`）

- 玩法：点螺柱拧下顶部螺母，收纳架必须从左到右按序配对同色螺栓；挡路的螺母可先挪到别的螺柱（每柱最多 4 只）。步数预算有限、超支失败，颜色更多种数更多逐关递增，共 42 关。
- 操作：触屏点螺柱/螺栓操作；键盘方向键选择、空格取放，P 暂停、R 重开本关。
- 说明：单文件自包含 H5，零外链、canvas 自绘；42 关内嵌，逐关 BFS 精确求解最小步数并校验预算=最小步数+松弛（全部可解）；接 GB 桥存档/关卡/成绩上报，无桥降级 localStorage。
