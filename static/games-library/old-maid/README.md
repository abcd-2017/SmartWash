# 抽鬼牌（gameKey：`old-maid`，category 建议：`board`）

- 玩法：与 AI 对局。牌组为若干对点数牌（6→15 对随关卡递增）外加 1 张「鬼」；洗匀后两人轮流发牌，发牌后成对的牌自动亮出；双方轮流从对方手中盲抽一张，抽到成对立即亮出；全部配对出手后，谁手里剩「鬼」谁输。
- 操作：轮到你时点对手任意一张暗牌抽牌（盲抽，位置不影响结果）；键盘 Tab 选中对手暗牌 + 回车抽牌、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关为配置型对局（牌量递增）；存档键 `sw.oldmaid.v1`，到达关卡经 GB 桥上报（desc）；无桥环境自动降级纯本地。AI 为随机盲抽 + 轻度位置记忆（优先抽本轮未抽过的位置）；本游戏核心为运气博弈，非解谜。

## 关卡验证

- 每关结构 `{name, pairs(4..20 对), difficulty}`：牌组 = pairs 对（每对两花色）+ 1 张鬼（哨兵码 90），共 2·pairs+1 张。
- 验证方式：游戏内嵌**独立无头对局模拟器** `omSimulate`——加载时对每关以固定随机流自动对局 **150 局**，逐局校验：对局必然终止、终局恰有一方持鬼、持鬼方手牌恰为 1 张（牌量守恒与配对规则一致性）；任一局异常即淘汰该关。另有牌组结构校验（张数 = 2·pairs+1）。
- 生成与验证结果：40 关（pairs 6→15）全部通过 150×40=6000 局模拟校验（**40/40**）；jsdom 无头冒烟测试完整对局到分出胜负并正常重开/选关。
- 已修复的关键边界：pairs≥14 时点数牌码（52/53）与鬼牌哨兵码冲突，哨兵改为 90 后全部通过。
