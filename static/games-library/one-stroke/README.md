# 一笔画（gameKey：`one-stroke`，category 建议：`puzzle`）

- 玩法：给定节点和连线组成的图形，从空心圈起点出发，点相邻节点逐段画线，把全部边不重复地一笔画完即过关；画错可撤销或重开，高关卡有限步挑战变体（步数恰好等于边数，不可撤销）。
- 操作：点击当前所在节点的相邻节点画线；「撤销一步」回退最近一段，「重玩本关」整关重来，「选关」跳转已解锁关卡；重复走线与非相邻移动会被拒绝并提示。
- 说明：单文件自包含 H5，Canvas 自绘零外链；关卡数据符合欧拉路径条件（连通且奇度节点 0 或 2，起点必为奇度点），100 关由逆向随机游走构造并经 Hierholzer 算法独立复核；进度自动保存，无桥时用包内默认 12 关。

## 关卡与难度

- 共 100 关（`.levels.json`，DB 下发优先、本地缓存兜底、包内默认前 12 关）。
- 难度递进：节点 6→19、边 8→29，入门关以轮廓图形（五角星/小房子/日字格/蝴蝶结/爱心/小鱼/风车等）为主，中后期以网格与环形布局为主，约 1/4 关卡为限步挑战。
