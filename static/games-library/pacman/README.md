# 吃豆人（gameKey：`pacman`，category 建议：`arcade`）

- 玩法：13×15 迷宫吃豆，四只幽灵各有性格（直追/预判/游走/试探），scatter 与 chase 轮换；能量豆让幽灵变蓝可反吃，分数翻倍连击。吃光 99 颗豆过关，幽灵逐关提速。
- 操作：触屏在画面上滑动转向（上/下/左/右），松手保持当前方向；键盘方向键 / WASD 转向，P 暂停。
- 说明：单文件自包含 H5，零外链；迷宫经连通性与死胡同脚本校验；localStorage 存最高分（`sw.pacman.v1`）；切后台自动暂停。**已接入游戏数据平台化**：存档经桥代理跟随账号（本地 + 账号双写，账号优先，更优才覆盖）；结算上报最高分（desc，越大越好）进排行榜。无桥环境（普通浏览器）自动降级为纯本地。
