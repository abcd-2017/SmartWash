# 翻饼大师（gameKey：`pancake-flip`，category 建议：`arcade`）

- 玩法：按住蓄力把煎饼抛上天，飞行中每点一次空中连翻加一层分，拖动平底锅把落饼接住；油面随时间向两侧扩散、锅面越用越窄，接住可刮回部分锅面，掉地三次结束，分数驱动冲最高分。
- 操作：触屏按住蓄力、松开抛饼、空中点按连翻、拖动移锅；键盘空格蓄力/翻饼、方向键或 AD 移锅、P 暂停、R 重开。
- 说明：单文件自包含 H5，零外链、canvas 自绘；--g-* 主题 token 双主题；接 GB 桥最高分存档与成绩上报，无桥自动降级 localStorage。
