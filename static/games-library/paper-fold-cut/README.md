# 一剪成形（gameKey：`paper-fold-cut`，category 建议：`puzzle`）

- 玩法：8×8 的纸沿中线对折（横折或竖折，每关指定），在对折后的半张纸上剪一条直线刀口（同行/同列/45° 对角的连续格），展开后黑色镂空图案须与目标完全一致。
- 操作：触屏在对折纸上点第一格、再点共线的第二格定刀口（展开预览实时刷新）；键盘方向键移动光标、Enter 定点、Z 清除当前刀口、H 提示。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, fold(横折 h / 竖折 v), holes(刀口格,折后局部坐标), target(8×8 展开图案 0/1), difficulty}`；刀口长度 1-6 格。
- 验证方式：游戏内嵌**独立验证器**（与展开预览逻辑分离）：枚举对折纸上全部共线点对所成线段，逐条展开比对目标图案，要求至少一条刀口可达成（40/40 关由生成器的 `holes` 直接达成并被枚举覆盖）；后台分片逐关复核，验证失败的关在选关面板禁用。
- 生成与验证结果：40/40 关可由一条直线刀口达成（构建期与运行时双重枚举复核，展开映射「局部格 → 原纸两个对称格」双向校验一致）。
