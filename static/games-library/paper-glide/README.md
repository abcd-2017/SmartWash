# 纸机穿环（gameKey：`paper-glide`，category 建议：`arcade`）

- 玩法：按住蓄力掷出纸飞机，飞行中按住抬升、松手俯冲；从环心穿过 +100 且连击每环加成、碰环缘只断连击、错空不罚，撞顶撞地结束。飞得越远带速越快、环位越散，分数驱动冲最高分。
- 操作：触屏按住蓄力/抬升、松手俯冲；键盘空格或 W 按住同理，P 暂停、R 重开。
- 说明：单文件自包含 H5，零外链、canvas 自绘；--g-* 主题 token 双主题；接 GB 桥最高分存档与成绩上报，无桥自动降级 localStorage。
