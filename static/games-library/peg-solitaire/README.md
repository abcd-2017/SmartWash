# 孔明棋（gameKey：`peg-solitaire`，category 建议：`board`）

- 玩法：经典英式十字盘 33 孔，棋子隔一颗相邻棋子跳到正后方空位，被跳过的棋子移除；把棋子减到本关目标数即过关（目标为 1 时最后一子需落在盘心）。
- 操作：点选一颗棋子，再点高亮空位完成跳吃；点已选棋子取消；「撤销」回退一步；「重玩本关」重置；「选关」可回溯已解锁关卡。
- 说明：单文件自包含 H5，零外链；棋盘与棋子全部 CSS/DOM 自绘（无 canvas、无素材文件），颜色走 `--g-*` token，深浅主题自动生效无需重绘；包内默认 104 关，支持管理后台下发扩展；进度（解锁/星级/最少撤销）自动保存并双写账号。

## 关卡数据

- `.levels.json`：顶层数组，信封 `{levelNo,name,difficulty,data:{board,goal}}`，`board` 为 33 位 `0/1` 位图（行优先，盘心为第 16 位），共 104 关。
- 生成方式：从目标终局（剩 1 子时固定在盘心）出发随机反向跳跃（逆操作）生长到指定初始子数，逆序回放即一组解，构造上保证可解。
- 校验：结构校验、组合唯一（布局+目标去重）、参考解回放、独立 DFS 求解器复核可解性（104/104 通过）。
- 主题：UI 壳走 §2 基线 token；棋盘/孔位/棋子走 `--g-board/--g-cell/--g-card` 等 §3 素材 token，深色为同色相压暗变体。
