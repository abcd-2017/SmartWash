# 点球大战（gameKey：`penalty`，category 建议：`arcade`）

- 玩法：五轮制点球，每轮先射门后守门。射门观察门将重心偏移打反向角落，可假动作诱使门将提前移动；守门时猜左/中/右扑救。进球多者胜，平局进入突然死亡。
- 操作：在球场上向上拖拽射门（左右定方向、距离定力度）；按「扑左/守中/扑右」守门；「假动作」在射门前晃动骗门将。
- 说明：单文件自包含 H5，Canvas 自绘素材零外链。120 关由生成器按「合理策略胜率 ≥70%」筛选（门将反应、射手精度、轮数递进），同参数同结果（种子流确定性 AI）；关卡支持 DB 下发（包内 10 关兜底），进度与星级自动保存。
