# 钟摆炮（gameKey：`pendulum-shot`，category 建议：`arcade`）

- 玩法：摆锤带着炮球来回荡，在合适相位点画布松脱，炮球沿抛物线飞出砸中靶心；墙壁会挡炮弹（高关卡有活动墙），顺路可摘星星。
- 操作：触屏点画布或「松脱发射」按钮发射；键盘空格发射、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc），metricExtra 为本关摘星数。

## 关卡验证

- 内嵌 40 关（第 1 关为手工锚点关，其余公式化确定性生成 + 收敛回退链：移墙→抬靶→落到摆幅顶点正下方），结构 `{name, px,py 悬点, L 绳长, A 摆幅, om 角频, tg 靶, walls[] 墙, mw 活动墙频率, st[] 星}`。
- 验证方式：内嵌**独立相位扫描验证器**——对 360 个释放相位逐个做确定性抛体模拟（固定步长 1/120s，重力/墙碰/落地判定），存在命中相位即判可解；DB 下发关卡同样整表扫描通过才接受。
- 锚点用例：① 第 1 关摆幅顶点松脱（v≈0）炮球竖直下落命中正下方靶（手工推演起点 x=130+110·sin 0.9≈216=靶心 x）② 合成密封箱关（靶被四面墙封死）扫描判定无解 ③ 全部 40 关扫描有解。
- 生成与验证结果：`PS.selfTest()` 3 项锚点全 PASS，40/40 关可解（扫描耗时 <300ms）。
