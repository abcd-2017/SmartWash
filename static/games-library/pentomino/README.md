# 五格拼盘（gameKey：`pentomino`，category 建议：`puzzle`）

- 玩法：12 种五格骨牌（F I L N P T U V W X Y Z）可旋转翻转，把托盘里的子集铺满矩形棋盘；关卡由 3 块的 5×3 一路加码到 12 块的 6×10 经典全拼。
- 操作：触屏点托盘选块 → 点旋转 / 翻转 → 点棋盘放置（自动贴齐边界），点已放的块收回；键盘方向键移光标、Enter 放置 / 收回、R 旋转、F 翻转、[ ] 换块、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 每关结构为 `{name, cols, rows, ids[], par, sol[][], difficulty}`；`ids` 为本关使用的骨牌子集（0-11 对应 12 种），`par` 为可铺满标记，`sol` 为加载时求出的一组参考解（提示用）。
- 验证方式：游戏内嵌**独立验证器**——精确覆盖 DFS（恒以最上最左空格为锚，枚举 12 种骨牌的全朝向表）在加载时逐关求可铺满性并生成参考解；DB 下发关卡逐关过滤，不可铺满关不进关卡表。
- 生成与验证结果：40/40 关可铺满（生成器以同源 DFS 挑选随机子集），解覆盖校验逐关通过；规格递进 5×3×10 关 → 5×4×8 → 5×5×8 → 5×6×6 → 4×10×4 → 5×9×2 → 6×10×2。
