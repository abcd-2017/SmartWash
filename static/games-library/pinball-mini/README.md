# 单台弹珠（gameKey：`pinball-mini`，category 建议：`arcade`）

- 玩法：按住蓄力把球打进台面，左右拍挡板救球；撞弹射柱 +50、点灯位 +100，三灯全亮开出 12 秒多球并 +500，多球期间两颗球一起吃分；三颗球全部落袋结算。发射力道不足会滚回发射道，分数驱动冲最高分。
- 操作：触屏按住屏幕蓄力发射，左/右半屏按住拍左/右挡板；键盘空格蓄力发射，←/→ 或 AD 拍挡板，P 暂停、R 重开。
- 说明：单文件自包含 H5，零外链、canvas 自绘；自研段反射 + 挡板尖端速度物理，冒烟测试验证发射入场合界/自然落袋/弱力回落；接 GB 桥最高分存档与成绩上报，无桥降级 localStorage。
