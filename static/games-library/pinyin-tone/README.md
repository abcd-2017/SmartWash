# 声调归位（gameKey：`pinyin-tone`，category 建议：`word`）

- 玩法：给出常用词语（目标字高亮指定），把词语按目标字的声调分进阴平/阳平/上声/去声四个声调塔，五词全归位即过关。
- 操作：触屏点词语选中、点声调塔归位；键盘 ←/→ 选词、1-4 归入对应声调塔、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc，metricExtra=本关错误数）。

## 关卡验证

- 词库 159 条 `[词, 目标字带调拼音, 目标字下标]`，覆盖四声（36/38/39/46）。每关 5 词、要求覆盖 ≥3 种声调、关内不重复，共 40 关。
- 验证方式：游戏内嵌**三层独立验证器**——① 拼音推导声调 `deriveTone`（调号→声调数，为唯一答案来源，答案由拼音决定而非人工标注）；② 词条校验 `validWord`（词长/下标/拼音合法且恰含一个调号）；③ 单关结构校验 `validLevelData`（索引有效、关内不重复、声调多样性 ≥3）。加载时逐关复核，坏关不进关卡表；DB 下发关卡走同一校验，任一非法整批放弃。
- 生成与验证结果：词库 159/159 条校验通过（0 异常）；40/40 关结构复核通过（0 坏关，词条全覆盖）。
- 内容口径：拼音（含声调）与「字—音」对应关系全部人工逐条校对，采用最常见无争议读音；不收录含轻声/儿化的词，避免归调争议。
