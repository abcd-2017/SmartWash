# 看拼写词（gameKey：`pinyin-write`，category 建议：`word`）

- 玩法：每关 4 个词语，屏幕上方给出整词拼音（逐音节带声调）与释义提示，下方 6 个字块（目标词全部字 + 干扰字，已打乱），按拼音顺序点字块拼出词语；填满自动判定，拼错清空重拼并计失误，四词全拼对过关。
- 操作：触屏点字块填槽、点已填槽退回；键盘 1-6 点字块、Backspace 退格、R 重开；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关由固定种子生成器产关（160 词库全覆盖）；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每题结构为 `{py(整词拼音), w(目标词), hint(释义), tiles(字块,含目标字+干扰字)}`。
- 内嵌独立验证器逐关复核：① 结构完整（拼音按空格分音节、每音节匹配 `^[a-z]+[1-5]$` 带调格式）；② **音节-字数一致**——音节数必须等于词字数；③ **字块覆盖**——字块必须包含目标词的全部字（必有解）且无重复字；④ 关内词唯一；⑤ 可通关性显然（拼错可退格重拼）。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核，异常关会在消息区告警）。
- 内容口径：拼音为自撰数据，按汉语拼音方案标注，**声调用数字 1-4 表示，轻声标 5**（如 朋友 peng2 you5）；ü 一律写作 v；词库均为常用双字词（少量 3 字场所词），拼音与释义逐条人工校对。
