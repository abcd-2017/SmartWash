# 管道工（gameKey：`pipes`，category 建议：`puzzle`）

- 玩法：网格中每格一块带方向的管道（端点 / 直管 / 弯管 / 三通 / 十字），点按即可顺时针旋转。把绿圈水源与红圈出水口接通，并让所有管道连成一张没有漏口的网（边界不得开口、相邻端口必须互相咬合）即通关。共 120 关，棋盘 3×3 递进至 8×8，类型组合从纯端点/直/弯逐步加入三通与十字。
- 操作：触屏点按格子旋转管道块（375px 宽下每格 ≥44px）；「上一关 / 重玩 / 下一关」切换与重置，「选关」打开已解锁关卡网格；通关弹出成绩面板。进度（含每关最少步数）自动保存，通关经游戏桥上报成绩。
- 说明：单文件自包含 H5，CSS/JS 全内联、零外链零素材文件；棋盘、管道、水流、漏口与起止标记全部 Canvas 自绘。主题只由桥控制（`getTheme` / `__applySmartWashTheme`，无桥恒浅色，无按钮、无 matchMedia），画布颜色经 `PAL` 读取 CSS 变量并在 `__gOnTheme` 钩子中重绘。关卡包内自带 12 关默认，优先使用管理后台下发关卡（DB 下发覆盖本地缓存）。

## 关卡数据格式

```json
{ "name": "入门·3×3 001", "size": 3, "tiles": [6,4,6], "src": 8, "snk": 4, "par": 15 }
```

- `size`：棋盘边长 n（3–8），`tiles` 长度 n²。
- `tiles[i]`：紧凑编码 0–14。端点 0–3 / 直管 4–5 / 弯管 6–9 / 三通 10–13 / 十字 14；数值即方向旋转量（端点/弯管/三通按 0=上起顺时针，直管 0=竖 1=横）。
- `src` / `snk`：水源与出水口格子下标（r*n+c），两格必须是端点件。
- `par`：参考解所需的最少顺时针点击数（成绩面板展示用）。

## 可解性构造与校验

生成器（`docs/level-gen/tools/pipes/`）先用「连通解构造 → 随机旋转打乱」：3×3 关用随机哈密顿路径（Warnsdorff 回溯）保证纯端点/直/弯；4×4 起用限制度数的随机 Prim 生成树，再补边把度 2 升三通、度 3 升十字以满足分段配额；水源/出水口取树上距离最远的两片叶子并保护其度数。打乱后校验初始态未提前通关，故解必然存在。独立校验器不依赖生成过程，对每关运行回溯求解器（MRV + 前向检查）实际求出「全格连通且无漏口」的旋转方案并重放确认。
