# 诗句重排（gameKey：`poem-order`，category 建议：`word`）

- 玩法：每关 2 首公版四句古诗，句卡被打乱（保证乱序不等于原序），按原诗顺序逐张点句卡排入 4 个槽位；放对即入槽标绿、放错计失误并提示句位，已排句可点槽撤回，两首全排对过关；诗名作为回忆提示展示。
- 操作：触屏点句卡入槽、点已排槽撤回；键盘 1-4 选句卡、U 撤销、R 重开；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关由固定种子产关（内嵌 82 首公版古诗库取 80 首，跨关轮换）；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每题结构为 `{hint(诗名提示), lines:[4 句原序]}`。
- 内嵌独立验证器逐关复核：① 结构完整（恰 4 句、句长 ≤14、诗名与句卡关内唯一）；② 可通关性由构造保证（正确句必在卡中，放错可撤销重排，无时限）；③ **内容正确性**——诗句为公版古诗通行教材版本，逐首人工默写核对（静夜思、登鹳雀楼、枫桥夜泊、石灰吟等，作者时代自唐至清，均已过著作权保护期）。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核，异常关会在消息区告警）。
- 内容口径：诗句取通行版本（如「遥看瀑布挂前川」「乡音无改鬓毛衰」按教材读音与写法），异文从教材；不放近现代有版权作品。
