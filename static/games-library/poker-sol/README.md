# 牌型计分（gameKey：`poker-sol`，category 建议：`board`）

- 玩法：Poker Squares——把 25 张牌逐张放进 5x5 盘，每行每列各成一手牌按 USPC 牌型计分（同花顺 100 / 四条 50 / 葫芦 25 / 同花 20 / 顺子 15 / 三条 10 / 两对 5 / 一对 2），总分达到关卡目标即胜；21 关起加入双王牌（万能牌）。
- 操作：触屏点任意空格放下当前牌；键盘方向键选格、Enter 放牌、U 撤销、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关 = 目标分 70-188 递进 × 无王/双王两段，纯事件驱动（无计时），到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, target(40-260), jokers(0/2)}`；牌局每局随机洗牌（52 ± 2 王）。
- 验证方式：游戏内嵌独立验证器 `selfTest`——① 40 关配置校验；② **标准锚点用例**（固定手牌 USPC 分，手算）：皇家同花顺 100、同花顺 75、四条 50、葫芦 25、同花 20、顺子 15（含乱色与 A2345 轮子）、三条 10、两对 5、一对 2、散牌 0；③ **王牌锚点**：单王补成皇家（两种缺牌位）、双王补四条 50；④ 计盘锚点：空盘 0 分、单行皇家 100 分；⑤ 发牌结构：54/52 张无重复。
- 生成与验证结果：21/21 项自检通过。**开发期锚点曾抓出「逐牌展开分组导致三条误判葫芦」缺陷。** 纯事件驱动（无计时/AI），切后台无需暂停处理。
