# 鱼塘养成（gameKey：`pond-fish`，category 建议：`other`）

- 玩法：一口塘的养成循环——每天定一档投喂（省/中/足，饲料按量计费），鱼群日长夜大；均重到 0.7kg 且赶上好鱼价就全捕变现，随后补苗扩群，密度超容量会折损；到期资产达标即过关。
- 操作：触屏点「喂·省/中/足」定当天投喂，「投苗 +5」「捕捞」随时可用，「下一天」推进生长；键盘 1/2/3 三档投喂、B 投苗、V 捕捞、回车下一天、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，鱼价逐日正弦波动（确定性种子），目标=参考策略终值×0.8。

## 关卡验证

- 内嵌 40 关，每关结构 `{name,days,cap,startN,startCash,minW,prices[],target,difficulty}`；生长模型：g=料/尾×0.15−0.045 kg/天，超容量按 cap/n 折算生物量。
- 验证方式：游戏内嵌**确定性周期模拟 + 参考策略回放** `PF.greedyRun`（喂足量力而行、达标记且价不低于中位数时全捕、随后补苗到满塘），生成期 target=floor(策略终值×0.8) 并要求策略终值≥起手 1.1 倍，`PF.validate` 复核结构与策略可达标。
- 锚点用例（`window.__validateLevels()` 共 7 条，node 抽取 XC-CORE 复现）：足喂日增 1.5kg（10 鱼 F=13，精确）、超容折损先增后折算 9.458（精确）、全捕按当日价 +160（tw=8@20 元/kg，精确）、未达标拒捕 why=small、投苗 -20/+5 尾/+0.25kg（精确）、40 关策略可达标、生成逐字节确定。
- 生成与验证结果：40/40 关策略可达标（fail 空），终值从 ~1009（第 1 关）升至 ~1701（第 40 关）。
