# 电力调度（gameKey：`power-grid`，category 建议：`puzzle`）

- 玩法：电网调度的静态谜题——左侧发电机（数字=容量）、右侧负荷（数字=需求），中间线路可任意合闸/断开；要找出一种接线让**全部负荷得电且任何发电机不超容量**，合闸次数越接近参考值越好。
- 操作：触屏点线路中点的开关方块（编号 1-N）；键盘 1-9/0 合断对应线路、H 提示（指出应合/应断的线路）、R 重置。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，静态谜题无实时压力，过关即解锁下一关。

## 关卡验证

- 内嵌 40 关，每关结构 `{name,gens[容量],loads[需求],edges[[gi,li]],init[0/1],par,difficulty}`；供需留 1-2 余量，初始接线必缺电。
- 验证方式：游戏内嵌**独立最大流求解器** `PG.flow`（Edmonds-Karp：源→发电机(容量)→开通线路→负荷(需求)→汇），`PG.feasible` = 最大流 ≥ 总需求；`PG.minFlips` 暴力枚举 2^E 接线状态求最少操作数（E≤10），生成期要求 par∈1..4 且初始不可行，`PG.validate` 复核。
- 锚点用例（`window.__validateLevels()` 共 6 条，node 抽取 XC-CORE 复现）：借线合闸 flow=5/par=1（精确）、孤网合闸 par=1（精确）、借线分配 flow=4/par=1（精确）、硬缺电 flow=2<3（精确）、40 关结构+par 校验、生成逐字节确定。
- 生成与验证结果：40/40 关通过（fail 空），par∈1..4，全部初始缺电（保证有操作感）。
