# 质数拆弹（gameKey：`prime-fact`，category 建议：`puzzle`）

- 玩法：把炸弹数（合数）逐层拆成两个因数，直到所有叶子都变成质数；拆分次数的理论下限 = Ω(N)−1（质因数个数−1），失误次数越少越好。
- 操作：触屏点红色合数叶子 → 数字键盘输入一个因数 → 点「拆」（另一因数自动算出，除不尽会报失误）；键盘数字键输入、Enter 确认、退格删除、U 撤销、H 提示（最小质因数）、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关 = Ω 从 2 递进到 6（1 刀到 5 刀）× 数字增大，纯事件驱动（无计时），到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, N(6-9999 合数)}`；Ω(N) 逐段 2→6 不降。
- 验证方式：游戏内嵌独立验证器 `selfTest`——① 40 关配置校验（全部为合数）+ Ω 递进校验；② **标准锚点用例**（手算）：已知质数 [2,3,5,7,11,13,89,97,101,7919] 全判真、已知合数 [1,4,6,9,15,91,221,100,7917] 全判假、Ω(12)=3 / Ω(60)=4 / Ω(48)=5 / Ω(64)=6 / Ω(97)=1、360=2³·3²·5 试除分解、最小质因数 91→7 / 221→13；③ **拆分语义锚点**：模拟拆 12 → 叶子 [2,2,3]、刀数 = Ω−1；④ 拆弹完成时叶子多重集与试除分解一致（运行时强校验）。
- 生成与验证结果：12/12 项自检通过。**开发期锚点曾修正 Ω(96)=6（2⁵·3）与 12 的叶子集两处手算错误。** 纯事件驱动（无计时/AI），切后台无需暂停处理。
