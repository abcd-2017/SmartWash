# 俗语填空（gameKey：`proverb-fill`，category 建议：`word`）

- 玩法：每关 3 题俗语谚语挖空句（如「三个臭皮匠，顶个___」），从 3-4 个候选词中选出补全项；选错即划掉可再选，三题答完过关，前 20 关 3 候选、后 20 关 4 候选。
- 操作：触屏点候选词；键盘 1-4 选择、R 重开；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关由固定种子生成器产关（120 题位覆盖 120 条题库）；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每题结构为 `{s(含 ___ 的俗语挖空句), opts(候选词), ok(正确词下标)}`；题库为内嵌 120 条**通行俗语谚语**（三分耕耘、老马识途、水涨船高等），干扰词由固定种子从其他题的正确词池抽取（后 20 关加第 4 干扰）。
- 内嵌独立验证器逐关复核：① 结构完整（句子含挖空、候选 3-4 个无重复、ok 下标有效、候选词长 ≤4）；② **题库一致性**——每题的「挖空句+正确词」必须能在俗语库中复核命中，否则该关告警；③ 可通关性显然（正确项必在候选中，选错可重选）。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核）。
- 内容口径：俗语谚语均为广泛流传的通行版本，逐条人工校对挖空处关键字；干扰词为同域常见词但填入明显不合语义。
