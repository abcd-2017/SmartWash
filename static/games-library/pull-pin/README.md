# 拉环救援（gameKey：`pull-pin`，category 建议：`puzzle`）

- 玩法：洞穴滑道上堆着宝石，抽掉插销让宝石沿斜壁滚落、绕开岩浆全部滚进宝袋即过关；每关的插销拔除顺序决定成败，陷阱销拔早了宝石会坠入岩浆。自研简化物理：宝石=圆刚体（重力+圆-圆/圆-线段/圆-旋转矩形碰撞，固定步长确定性），插销=线段胶囊刚体，岩浆=矩形致死区。
- 操作：点击插销将其拔出（点击热区约 48px），宝石受重力沿滑道滚动；全部宝石安全入袋=三星、救回 60% 以上=二星、救回至少 1 颗=一星、全灭=失败。
- 说明：单文件自包含 H5，零外链；自研 2D 物理引擎（固定步长确定性），关卡由包内 DEFAULT_LEVELS（12 关）+ DB 下发（120 关）驱动，`GB.getLevels("pull-pin")`。
