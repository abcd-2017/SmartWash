# 金字塔纸牌（gameKey：`pyramid-sol`，category 建议：`board`）

- 玩法：28 张牌按 7 行堆成金字塔，其余 24 张为牌堆；两张明牌点数相加为 13 即成对卸下（A+Q、2+J……9+4、10+3），K 点数 13 可单张卸下；牌堆逐张翻入弃牌堆，弃牌堆顶可与金字塔明牌配对，牌堆翻完可重洗一次。金字塔全部卸空即胜。
- 操作：点一张明牌选中，再点与之凑 13 的另一张；K 点一下直接卸；点牌堆翻牌；键盘 Tab+回车 选牌确认、D 翻牌、U 撤销、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关按发局号种子确定性发牌，参考步数 53→77 递进；存档键 `sw.pyramidsol.v1`，到达关卡经 GB 桥上报（desc，附步数）；无桥环境自动降级纯本地。与接龙类（solitaire / freecell / spider）的「叠放收牌」规则实质不同，属配对卸牌玩法。
