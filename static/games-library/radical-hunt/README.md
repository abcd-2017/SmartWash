# 部首收集（gameKey：`radical-hunt`，category 建议：`word`）

- 玩法：每关给出一个目标部首（如「氵」）和 12 字字阵，点出所有含该部首的字（恰好 5 个）；点错算失误并抖动提示，5 个全找对过关。
- 操作：触屏点字块；键盘 1-9 / 0 / Q / W 按位置点字、R 重开；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关由固定种子生成器从 14 部首字库产关；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, rad(部首), zi(12 字阵), count(=5)}`；字库为 14 个常用部首 × 各 10 个目标字 + 14-16 个固定干扰字（氵木口亻火土艹钅纟虫米石讠日）。
- 内嵌独立验证器逐关复核：① 结构完整（字阵恰 12 个单字、关内唯一、部首合法、count 4-6）；② **目标字归属**——字阵中命中部首字表的字数必须恰等于 count，其余全为该部首的固定干扰池字；③ **干扰互斥**——各部首干扰池逐一人工核对不含该部首（如「火」的干扰池不含任何火部字），保证答案判定唯一。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核，异常关会在消息区告警）。
- 内容口径：部首按通行形旁口径（氵木口亻火土艹钅纟虫米石讠日），目标字均为以该部首为偏旁的常用字，逐字人工校对；干扰字为简明常用字且确定不含目标部首。
