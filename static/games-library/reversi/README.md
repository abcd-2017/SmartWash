# 黑白棋（gameKey：`reversi`，category 建议：`board`）

- 玩法：经典黑白棋（Reversi），8×8 棋盘。你执黑先行，AI 执白后手；落子须夹住对方至少一枚棋子并将其全部翻面，横、竖、斜八个方向均生效。无合法手时自动跳过，双方都无手时终局，子多者胜。
- 操作：点击高亮的合法位置落子；「难度」按钮切换 困难（搜索深度 3）/ 简单（随机放行）；「重新开始」重置棋盘。
- 说明：单文件自包含 H5。AI 采用 negamax + alpha-beta 剪枝，按位置权重排序走子（角最大、X/C 位为陷阱）提升剪枝效率，中局落子耗时控制在百毫秒级；胜 / 负 / 平与难度经 localStorage 本地保存。**已接入游戏数据平台化**：存档经桥代理跟随账号（本地 + 账号双写，账号胜场更多才覆盖本地，难度偏好保留本地）；上报胜场进排行榜（desc）。无桥环境自动降级为纯本地。
