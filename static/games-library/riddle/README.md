# 灯谜问答（gameKey：`riddle`，category 建议：`word`）

- 玩法：限时四选一。读谜面（自撰字谜 / 物谜 / 脑筋急转弯），从 4 个候选中选出正确答案；每关答对达标即过关，越快越准星级越高。
- 操作：点按下方选项作答；答错会标出正确答案；剩余时间见顶部进度条。
- 说明：单文件自包含 H5，零外链零素材；谜面与选项全部自撰，未复制现代出版的谜语集。

## 题库

- 自撰 **427** 条：字谜 157、物谜 149、脑筋急转弯 121（含少量一词/俗语谜）。
- 每条含谜面、答案与 3 个干扰项；选项在组卷时随机洗牌并重算答案索引。
- 难度分层：同组形近/音近干扰（如「清/晴/睛/情/请」）标记为强干扰，随关卡递进投放。
- 校验：答案索引合法、4 个选项不重复、答案唯一（答案必在选项中且仅出现一次）、谜面 ≤64 字、选项 ≤24 字、同关题目不重复、**跨关题目全局不重复**。

## 关卡

共 104 关，难度 1→10 单调递进：

| 关卡 | 题数 | 限时 | 达标 |
|---|---|---|---|
| 1-35 | 3 | 30-26 秒/题 | 允许错 1 题 |
| 36-70 | 4 | 22-18 秒/题 | 允许错 1 题 |
| 71-104 | 5 | 18-14 秒/题 | 高难度要求全对 |

- 数据格式：`{name,questions:[{q,t,options[4],answer}],time,need}`。
- 组卷用确定性种子抽取，同一批次内 415 道题互不重复；每关题量、限时、干扰项强度均随难度上升。

## 存档与上报

- 进度（解锁关卡 / 星级 / 每关最快用时）双写 localStorage 与账号（键 `sw.riddle.v1`）。
- 通关上报 `reportScore`：`metricValue=已通关数`（desc），`metricExtra=累计星级`。
- 星级：过关保底 1 星；全程无错 +1 星；剩余时间 ≥30% +1 星。
- 关卡下发走桥 `getLevels("riddle")` + `version` 缓存，包内 DEFAULT_LEVELS（前 10 关）离线兜底；任一条非法整批放弃。
