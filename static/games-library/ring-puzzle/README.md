# 九连环（gameKey：`ring-puzzle`，category 建议：`puzzle`）

- 玩法：经典九连环规则的状态谜题。1 号环随时可解下/套回；要动第 k 环，必须第 k−1 环在杆上且 1..k−2 环全空。把环从初始形态摆成目标形态（画布左上角给出目标位串）。
- 操作：触屏点环解下或套回；键盘 1-9 动对应环、Z 撤销、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关由包内种子生成器产出（4 连环→9 连环），到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 每关结构为 `{name, n, init, goal, par, difficulty}`；`init/goal` 为位掩码（bit i = 第 i+1 环是否在杆上），`par` 为状态图最短路步数。
- 生成方式：包内固定种子（20261125）生成器按难度带随机取初始/目标形态，BFS 距离落在带内才收关（4→9 连环，par 4→62 递进）。
- 验证方式：游戏内嵌**独立全图 BFS 验证器** `rpBFS`（每个状态恰两个邻居：环 1 与最小在杆环的下一环，Gray-code 路径图），加载每关复核可达性并计算最少步数；DB 下发关卡逐关过滤，不可达关不进关卡表。
- 生成与验证结果：40/40 关可达，BFS 实测最优与关卡 `par` 一致；步数带 4→62 递进，末段为 9 连环长链。
