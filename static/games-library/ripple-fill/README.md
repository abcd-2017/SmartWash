# 数波（gameKey：`ripple-fill`，category 建议：`puzzle`）

- 玩法：棋盘被划分为若干 2-5 格的区块，在空格里填 1-5，使同一区块内数字不重复、相邻（含斜角）两格数字不同，填满全盘即过关。
- 操作：触屏点格子循环切换 1-5 / 清空；键盘方向键移动光标、数字 1-5 填入、退格清空、Z 撤销、H 提示。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（5×5 → 6×6 → 7×7 递进），到达关卡经 GB 桥上报（desc）；无桥自动降级 localStorage。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, cols, rows, reg, givens[[idx,val]], difficulty}`；`reg` 为每格区块 id 的 base36 串（长度 cols×rows）。
- 验证方式：页面内嵌**独立回掷求解器** `suguruSolve`（MRV 之外的静态序回掷，区内位掩码 + 八向邻域双剪枝），加载每关时逐关复核结构合法性（区块连通、大小 2-5、给定数互不冲突）与可解性，不可解的关不进关卡表；提示功能直接取求解器补一格。
- 生成与验证结果：构建期先随机生成完整解、再生长区块（构造式，天然可解），提示数经计数求解器收敛至**唯一解**；发布前用包内 `verifyLevel` 逐关复核，40/40 可解、40/40 唯一解。
