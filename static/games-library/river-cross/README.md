# 狼羊菜渡河（gameKey：`river-cross`，category 建议：`puzzle`）

- 玩法：小船限载摆渡，把岸上物品逐一运到对岸；狼·羊、羊·虎等相克组合不可独处一岸，摆渡次数越少越好。
- 操作：触屏点岸上物品装船、点船上物品卸下，再点「开船」；键盘 1-9 上下物品、空格开船、Z 撤销、H 提示。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；46 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 46 关，每关结构为 `{name, items[], bad[[i,j]], cap, rower, par, w?}`；`bad` 为相克物品对，`cap` 为船容量，`rower` 为必须随船的船夫下标（-1 表示无）。
- 验证方式：游戏内嵌**独立 BFS 求解器** `riverBFS`（状态=左岸物品掩码×船侧，枚举载子集，相克剪枝），加载每关时复核可解性并计算最少摆渡步数；无解或步数与 `par` 不符会在消息区告警，提示直接取 BFS 首跳。
- 生成与验证结果：46/46 关可解，BFS 实测最优与关卡 `par` 一致（7/9/5/11 步递进）。
