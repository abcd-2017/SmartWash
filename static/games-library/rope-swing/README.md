# 荡藤过谷（gameKey：`rope-swing`，category 建议：`arcade`）

- 玩法：角色在悬崖间奔跑，靠近藤蔓自动抓握并摆荡，点击松手飞出。掌握松手时机飞越峡谷，落地继续前进，坠落即结束。
- 操作：触屏点击松手、按住左/右半屏加摆力；键盘空格松手、←/→ 加摆力。
- 说明：单文件自包含 H5，canvas 自绘，零外链；最远距离经 GB 桥上报（desc），无桥降级 localStorage。
