# 旋片复原（gameKey：`rotate-pic`，category 建议：`puzzle`）

- 玩法：一幅种子生成的几何画作被切成 3×3 碎片并打乱旋转；点任意碎片会带动它自己和上下左右四块一起顺时针转 90°，角上有警示点的碎片尚未正位，让全部碎片转回 0° 对齐画作即过关。
- 操作：触屏点碎片联动旋转；键盘方向键移动光标、空格转动、Z 撤销、H 提示。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（打乱 2 → 9 次递进），到达关卡经 GB 桥上报（desc，附加星评）；无桥自动降级 localStorage。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, seed, taps, par, difficulty}`；`seed` 驱画作与打乱（mulberry32 确定性回放），状态编码为每格 2 位的 4 进制整数（4^9 状态空间）。
- 验证方式：页面内嵌**独立 BFS 验证器**——从全零态沿反向边（一次逆转=三次顺转）遍历全部 262144 个状态，得到每个状态到复原态的最少转数表；加载每关时按种子回放打乱，要求实测最少转数 = `par` 且 ≥1（非复原态），不符的关不进关卡表；提示功能沿距离梯度给出下一步该转的碎片。
- 生成与验证结果：构建期按难度取打乱次数随机产关，40/40 关通过包内 BFS 验证器复核（par 与实测一致、非复原态）。
