# 二阶魔方（gameKey：`rubik-mini`，category 建议：`puzzle`）

- 玩法：二阶魔方以展开图呈现，初始为随机打乱态；点任意面顺时针拧 90°（Shift+键逆拧），把六个面各自拧成同色即复原（二阶无固定中心，任意整体朝向均算复原），步数越少评价越高。
- 操作：触屏点展开图中的面或下方 U/D/L/R/F/B 按钮；键盘 U/D/L/R/F/B 顺拧、Shift+同键逆拧、Z 撤销。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（打乱 5 → 9 步递进），到达关卡经 GB 桥上报（desc，附加星评）；无桥自动降级 localStorage。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, scram, par, difficulty}`；`scram` 为 U/D/L/R/F/B 打乱序列（无连续同面），`par=ceil(len×1.6)` 为参考步数上限。
- 验证方式：页面内嵌**双实现互验器**——主实现（叉积旋转公式）与验证器实现（四元数旋转 + 格点回抛校验）各自从复原态施加打乱，两者状态哈希必须一致；随后双实现各自逆序回放，必须精确回到复原态；打乱后仍为复原态的关判为无效。加载时逐关复核，不合格的关不进关卡表。
- 生成与验证结果：构建期生成 5-9 步随机打乱，40/40 关通过双实现互验（哈希一致 + 回放复原 + 非复原态）。
