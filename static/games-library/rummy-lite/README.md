# 拉米组牌（gameKey：`rummy-lite`，category 建议：`board`）

- 玩法：一手 9-14 张牌（单副 52 张、无重复），把整手牌全部组成 meld 出净即胜；meld 两种：3 张以上同点数的「刻子」（花色不限）与 3 张以上同花连续点数的「顺子」（A 只作 1，如 A-2-3）。
- 操作：点选手牌（可多选）组成 meld 后按「出牌」；按钮实时提示当前选择是刻子 / 顺子 / 还不成组；键盘 1-9/0 点选前 10 张（其余 Tab+回车）、U 撤销、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关为构造保证可完全出净的手牌（组数 3-4、张数 9→14 递进）；存档键 `sw.rummylite.v1`，到达关卡经 GB 桥上报（desc，附出牌次数）；无桥环境自动降级纯本地。组牌出净玩法为合集新增，与接龙 / 配对类规则不同。

## 关卡验证

- 每关结构 `{name, cards[6..20 张互异牌码], par(构造时的 meld 组数), difficulty}`；手牌由构建期按「刻子/顺子」逐组构造拼装而成，保证存在完整分组。
- 验证方式：游戏内嵌**独立精确覆盖求解器** `rummyPartition`（枚举手牌全部候选 meld，DFS 找到覆盖全部手牌的分组才算通过；与玩法引擎相互独立），加载时同步复核全部关卡（毫秒级），求解失败的手牌不进关卡表。
- 生成与验证结果：构建期扫描 56 个种子生成 40 关互异手牌（组数 par=3~4、张数 9→14），独立求解器复核 **40/40 通过**；jsdom 无头冒烟测试中提示→出牌→撤销→非法选择拦截全链路通过。
