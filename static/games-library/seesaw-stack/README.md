# 跷板堆箱（gameKey：`seesaw-stack`，category 建议：`other`）

- 玩法：把重量 1-5 的箱子放上跷板，左右力矩要互相压住；负载条到头跷板倾覆、箱子全部滑落，能堆多少堆多少。
- 操作：触屏按住画布移动光标、松手放箱；键盘 ◀▶ 移动光标、空格放箱。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；分数驱动街机，结束上报历史最高堆箱数（desc）。与 balance-stack（静态配平）的差异：本作是连续落箱的动态力矩管理，跷板随力矩实时倾斜。

## 上报口径

- `metricValue` = 历史最高堆箱数（存档键 `sw.seesawstack.v1` 本地 + 账号双写，账号优先）。
- 倾覆结束（滑落动画完）时上报一次；无关卡概念，不使用 `metricExtra`。

## 验证说明

- 力矩模型确定性：T=Σ重量×杠杆，倾角目标=T·K（限幅），|T|>2400 判倾覆；箱子序列由 mulberry32 种子驱动。内嵌引擎 `SS.selfTest()` 3 项锚点全 PASS（力矩=重量×杠杆 60px 且右倾收敛 / 单侧连放必倾覆 / 左右箱力矩符号相反）。
