# 病句门诊（gameKey：`sentence-fix`，category 建议：`word`）

- 玩法：每关 3 题，每题给出一个病句和 3-4 个改正句候选，选出真正改对的那句；答对后公布病因（用词不当/重复啰嗦/语序不当/成分残缺/搭配不当/前后矛盾/关联词误用/分类不当/句式杂糅/指代不明等），三题答完过关。
- 操作：触屏点改正候选；键盘 1-4 选择、R 重开；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关由固定种子生成器产关（120 条题库全覆盖不重复，前 20 关 3 候选、后 20 关 4 候选）；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每题结构为 `{s(病句), fix(正确改法), cause(病因), opts(改正候选), ok}`；改正候选 = 正确改法 + 2 个预置干扰改法（后 20 关追加 1 个从其他题改法池抽取的干扰）。
- 内嵌独立验证器逐关复核：① 结构完整（病句/改法/病因非空、病因 ≤8 字、候选 3-5 个无重复）；② **改正有效性**——正确改法不得与病句相同；③ **题库一致性**——每题的「病句+正确改法+病因」三元组必须能在病句库中复核命中，否则该关告警；④ 可通关性显然（正确项必在候选中，选错可重选）。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核）。
- 内容口径：120 条病句全部自撰，覆盖小学语文常见十大病因类型；每条的正确改法与病因归类逐条人工校对；干扰改法为「没找到病根的改法」或引入新错误，不会与正确改法同为病句通顺改写。
