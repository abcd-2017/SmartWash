# 数列推理（gameKey：`sequence-next`，category 建议：`other`）

- 玩法：给出数列前 5 项，从 4 个选项中选出下一项；规律族随关卡递进——等差、等比、二阶等差（差为等差）、类斐波那契（前两项之和）、隔项双等差（奇偶位各自等差）。
- 操作：触屏点选项；键盘 1-4 选答案、R 重开、L 选关。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（种子生成，6→10 题、75→60 秒），到达关卡经 GB 桥上报（desc，metricValue=过关关号，metricExtra=剩余秒数）；切后台自动暂停并把计时基点平移。

## 唯一性口径

「唯一正确」以**候选选项**为口径：验证器对已给 5 项反推全部可拟合的常见规律族（等差 / 等比 / 二阶等差 / 类斐波那契 / 隔项双等差），要求 ①所有拟合族的合法外推值互相同值且等于正确项；②每个错误选项都不等于任何拟合族的外推值（即选错误项找不到任何规律支持）。数列同时拟合多族但外推不同值的题目一律不进表。

## 关卡验证

- 关卡结构 `{dc:{q,time,fams},qs[]}`：每题 `{seq[],opts[],ans}`，seq 为前 5 项（整数），opts 为 4 个整数字符串。
- 生成算法：按难度选族与参数构造 6 项数列（第 6 项为答案），先自检外推一致性，再从「答案 ±1..12」池抽干扰项并过滤掉所有拟合族外推值，不足 4 选项重抽。
- 验证方式：游戏内嵌**独立验证器** `verifyLevelData`（从数列反推规律族的独立实现 `famExtrapolations`，与生成器的参数构造路径不同），逐题断言外推一致性 + 干扰项不属任何外推 + 选项互异。
- 标准锚点用例（人工核对）：①[2,4,6,8,10]→12（等差，隔项族外推同值 12）②[1,2,4,8,16]→32（等比）③[1,4,9,16,25]→36（二阶等差）④[1,1,2,3,5]→8（类斐波那契）⑤[2,3,4,7,6]→11（隔项双等差）⑥[3,1,4,1,5]→无任何拟合族。启动时逐关复核 40 关 + 锚点断言，验证失败在消息区告警。
- 生成与验证结果：40/40 关通过，无告警。
