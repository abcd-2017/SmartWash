# 投影配对（gameKey：`shadow-match`，category 建议：`puzzle`）

- 玩法：底部托盘上的 5×5 立体柱体可旋转、翻面，正面投影是柱状剪影；把它转到与顶部目标影子逐列一致即过关。
- 操作：触屏点「左旋/翻面/右旋」三键；键盘 ←/→ 旋转、F 翻面、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, h(5×5 柱高 0-3), k(目标朝向 0-3), m(目标翻面 0/1), t(目标剪影 5 列高度), difficulty}`。
- 验证方式：游戏内嵌**独立验证器** `verifyLevel`（与交互逻辑分离）：枚举 8 个体状态（4 朝向 × 翻面）逐一计算正面剪影，要求目标剪影可由某状态达成，且 8 状态剪影至少 4 种（排除过度对称的退化体）；后台分片逐关复核，验证失败的关在选关面板禁用。
- 生成与验证结果：40/40 关可达成（生成器已排除「开局即胜」与对称退化体，构建期自检 + 运行时复核双重确认）。
