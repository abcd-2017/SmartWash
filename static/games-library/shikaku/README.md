# 矩形切割（gameKey：`shikaku`，category 建议：`puzzle`）

- 玩法：在带数字的棋盘上拖出矩形，每块矩形面积须等于所含数字、恰好包住一个数字，且铺满全盘。
- 操作：触屏拖拽画矩形；键盘方向键移动光标 + 空格起止选框、Z 撤销、H 提示。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；44 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 44 关，每关结构为 `{name, w, h, nums[[格下标,面积]]}`；数字格下标互异、面积合法。
- 验证方式：游戏内嵌**独立矩形回溯求解器** `shikaSolutions`（按数字顺序枚举包含该格的矩形，面积相等 + 不重叠 + 全盘覆盖，解数上限 2），加载每关时复核解存在且唯一；无解或解不唯一会在消息区告警，提示取该唯一解。
- 生成与验证结果：44/44 关唯一解（5×5 → 7×7 递进，离线生成器以同一求解器复核）。
