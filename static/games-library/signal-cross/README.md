# 路口红绿灯（gameKey：`signal-cross`，category 建议：`puzzle`）

- 玩法：四方向来车持续排队，你控制信号相位——点「南北绿」或「东西绿」放行，切换需清空路口 1 tick；限时内疏解目标车辆数且任何一队不堵爆即过关。
- 操作：触屏点两个相位按钮切换；键盘 1 南北、2 东西、空格暂停、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc），metricExtra 为总等待 tick 量。

## 关卡验证

- 内嵌 40 关（第 1 关为手工锚点关，其余由种子确定性生成车流后冻结为 `arr[4]` 位串），结构 `{name, ticks, cap 队容, flow 放行速率, clear 清空期, arr[] 到达位串, target}`。
- 验证方式：内嵌**策略回放验证器**（本向放空或对方积压更多时请求切换的防抖策略），逐关回放须 `win`；DB 下发关卡同样整表回放通过才接受。
- 锚点用例：① 第 1 关策略回放恰好疏解 9 辆（北 6 + 东 3）且不堵 ② 永不切换必因超时判负 ③ 全部 40 关回放可达成。
- 生成与验证结果：`SC.selfTest()` 3 项锚点全 PASS，40/40 关可达成。
