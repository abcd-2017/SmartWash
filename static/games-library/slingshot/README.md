# 弹弓风暴（gameKey：`slingshot`，category 建议：`puzzle`）

原创实现的弹弓物理闯关（玩法参考 `mini-browser-games/slingstorm.html` 的弹弓题材，代码全部自写）。

- 玩法：拖拽弹弓瞄准，虚线点阵实时预估弹道，松手发射抛物线弹丸；力度由拖拽距离决定（拉满约 100%），命中传递动量；木块 2 血、石块 5 血、目标 1 血，击毁全部红色目标即过关；弹丸落地反弹 3 次后消失；剩余弹丸每发 +300 奖励。
- 操作：按住画布前半场向后拖拽（弹弓跟随、皮筋绷紧、显示力度条与弹道预估），松手发射；短拖（<14px）取消；6 关难度递进（木墙 → 石卫 → 高塔 → 屋顶暗靶 → 双靶城堡），胜利解锁下一关并持久化；每关弹丸数有限，用尽未清场判负可重试。
- 说明：单文件自包含 H5；进度与最高分 localStorage（`slingshot-progress` / `slingshot-best`，读写均 try/catch）；物理基于固定子步长（≤8ms）积分 + AABB 成对解算，关卡内方块可被撞塌连锁；切后台自动暂停；主题按 D5 终版裁定由桥唯一控制（无 matchMedia 层与手动切换钮），canvas 全变量取色经 `__gOnTheme → palLoad()` 随推送实时重绘。**已接入游戏数据平台化**：存档经桥代理跟随账号（本地 + 账号双写，账号分数/解锁更优才覆盖本地）；关卡支持后台热更新（DB 下发 + 本地缓存 + 包内默认关兜底）；上报到达关卡进排行榜（desc，附剩余弹丸）。无桥环境自动降级为纯本地。

## 与原型的机制差异（复刻取舍）

原型 `slingstorm.html` 是 18 契约三章节战役（多种弹药技能 / 风向 / 风暴工坊升级 / 存档导入导出 / 星级挑战）。本作为单一标准弹丸：去掉弹药类型 / 风 / 工坊 / 章节与档案系统，保留「拖拽蓄力 + 弹道预估 + 抛物线 + 可破坏堡垒」核心手感，以 6 关线性解锁呈现难度递增。
