# 数回（gameKey：`slitherlink`，category 建议：`puzzle`）

- 玩法：在点阵间画一条不交叉、不分叉的闭合环线，使每个数字格四周被环线用掉的边数恰好等于该数字。
- 操作：触屏点两点之间的边（画线 → 打叉 → 清除）；键盘方向键移动边光标、空格/回车切换、Z 撤销、H 提示。
- 说明：单文件自包含 H5，canvas 自绘，零外链；48 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 48 关，每关结构为 `{name, r, c, clues[][]}`，`clues` 为 -1（无提示）或 0-4。
- 验证方式：游戏内嵌**独立穷举求解器** `slitherSolve`（边回溯 + 顶点度 0/2 传播 + 闭合环单环判定），统计解数上限 2；加载每关时复核，解数 ≠ 1 会告警；提示取该唯一解的边集。求解器已用 2×2 / 2×3 全枚举暴力交叉校验（400+120 组，0 不符）。
- 生成与验证结果：48/48 关唯一解（离线生成器以同一求解器复核，48 种不同提示盘面）。
