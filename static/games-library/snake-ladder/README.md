# 蛇梯棋（gameKey：`snake-ladder`，category 建议：`board`）

- 玩法：10×10 百格蛇梯棋，与 1-2 家电脑轮流掷骰竞走；落在梯底沿梯上爬、落在蛇头顺蛇滑下；需恰好走到 100，超出回弹；先到 100 者胜（高关卡掷 6 可再行一次）。
- 操作：点「掷骰」（或回车/空格）；R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关 = 确定性种子棋盘（每关布局不同，同种子同布局）× 电脑数 1-2 × 掷 6 再行变体，到达关卡经 GB 桥上报（desc）。切后台电脑回合作废、轮次归还玩家。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, seed(1-999), bots(1/2), six(0/1)}`；布局由种子确定性生成。
- 验证方式：游戏内嵌独立验证器 `selfTest`——① 40 关配置校验；② 同种子布局一致性（JSON 比对）；③ 逐关布局合法性：梯/蛇头尾均在 2-99、无格双角色、梯顶与蛇尾不得是任何梯底或蛇头（保证链式跳转有限）、梯顶不得为 100；④ 回弹公式；⑤ 3 局人机模拟对局：每步骰点 1-6、链式跳转受控、正常以恰好 100 终局。
- 生成与验证结果：9/9 项自检通过（含 3/3 局模拟对局、40/40 张棋盘布局校验）。
