# 推箱子（gameKey：`sokoban`，category 建议：`puzzle`）

- 玩法：12 关递进（最少推箱数 1→6），把箱子推到光圈上、全部放好即过关；一次只能推一个、不能拉，走错可无限撤销。
- 操作：棋盘上滑动单步移动 / 下方方向键盘（按住连走）/ 键盘方向键 WASD（Z 撤销）；「撤销」「重开」「选关」。
- 说明：单文件自包含 H5，零外链；12 关全部经 BFS 求解器验证可解且箱数=目标数；进度与已解锁关卡本地保存（`sw.sokoban.v1`），选关面板可回看已通关卡。
