# 速算竞速（gameKey：`speed-math`，category 建议：`other`）

- 玩法：120 秒限时连答四则运算（加减乘除），答对 +1 分、答错扣 5 秒并显示正确答案；难度随答对数五档递增（10 内加减 → 20 内 → 口诀乘法 → 整除除法 → 三位数加减 / 两位乘一位）；时间到结算，刷新纪录。
- 操作：触屏点选项；键盘 1-4 选答案、Enter 开始 / 确认、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；**分数驱动**（无关卡）：历史最佳分 localStorage + 账号存档双写（`sw.speedmath.v1` 的 `best` 字段）；结束经 GB 桥上报 `{metricValue: save.best, metricExtra: null}`——**口径：metricValue = 历史最佳单局答对题数（无连击加成），desc 越大越好**；题目动态生成（种子 = 局种子 + 题序），除法保证整除、选项唯一正确且非负；切后台自动暂停并把计时基点平移。

## 题面验证

- 出题器按难度档生成 `a op b`（op ∈ + − × ÷），减法保证结果为正、除法由「商 × 除数」反推保证整除；干扰项从 ±1/±2/±10/±5 池抽取并保证互异、非负、不等于正确值。
- 验证方式：游戏内嵌**独立验证器** `verifyQ`（独立求值器 `evalQ` 走 switch 分支，与生成器的构造路径不同）逐题断言答案与求值一致、选项互异 / 非负 / 无前导零、除法整除；生成后每题即时校验，失败自动换种子重出。
- 标准锚点用例（人工核对）：①12÷4 = 3 ②7×8 = 56 ③15−8 = 7 ④除法题选项口径 ⑤乘法题选项口径 ⑥重复选项检测（两 8 并列应被拒绝）⑦回归锚点：60 个固定种子覆盖全部难度档逐题过 `verifyQ`。启动时断言锚点，失败在消息区告警。
- 验证结果：锚点全通过，无告警。
