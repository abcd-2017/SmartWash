# 甩牌竞速（gameKey：`spit-race`，category 建议：`board`）

- 玩法：与 AI 竞速甩牌。双方各有 1 张明面牌 + 一叠暗牌队列（9→13 张随关卡递增），桌面 2 个「站台」各有 1 张站牌；面牌点数 = 任一站牌 ±1（K-A 环绕）即可甩上该站台并翻出下一张；双方都甩不出时自动「换站」（各翻队列 1 张上新站台）；比对手先甩空全部手牌即胜，卡死终局时余牌少者胜。
- 操作：点自己的面牌甩出（可甩时绿色描边提示）；键盘空格甩面牌、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关为配置型对局（队列长度 + AI 甩牌节奏 1750ms→650ms 递进）；**切后台自动暂停 AI**（visibilitychange 停表、恢复重启节奏）；存档键 `sw.spitrace.v1`，到达关卡经 GB 桥上报（desc）；无桥环境自动降级纯本地。

## 关卡验证

- 每关结构 `{name, n(队列张数 6..24), speed(AI 节奏 1..9), difficulty}`；发牌 = `mulberry32(关卡种子)` 洗 52 张，2 张面牌 + 2n 张队列 + 2 张初始站牌。
- 验证方式：游戏内嵌**独立无头模拟器** `spitSim`——加载时对每关以固定随机流自动对局 **150 局**（双方 AI：可甩即甩、随机选站台），逐局校验：对局必然终止、牌量守恒（甩出 + 换站×2 + 余牌 = 2n+2）、终局无「仍有牌可甩却终止」；任一局异常即淘汰该关。
- 生成与验证结果：40 关（n 9→13、speed 1→6）全部通过 150×40=6000 局模拟校验（**40/40**）；jsdom 无头冒烟测试实测整局进行到分出胜负（AI 先甩空、余牌 2:1）并正常重开 / 选关。
