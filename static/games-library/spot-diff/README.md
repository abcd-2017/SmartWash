# 找茬（gameKey：`spot-diff`，category 建议：`puzzle`）

- 玩法：左右两幅种子生成的场景图（气球 / 云 / 房子 / 树 / 星 / 船等特征随机布点）有若干处不同（换色 / 放大 / 移位 / 镜像 / 消失），限时点出全部不同点，点错只计数不扣时，切后台自动暂停。
- 操作：触屏直接点两图中的不同处；键盘 Tab 切换左右图、方向键移动探针、回车探测。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（差异 1 → 6 处、限时 60 → 40 秒递进），到达关卡经 GB 桥上报（desc，附加剩余秒数）；无桥自动降级 localStorage。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, seed, count, k, time, difficulty}`；`count` 为场景特征数，`k` 为差异数，差异目标经种子从场景中指派（两两间距 ≥0.22 防一点双解，变化类型 5 种）。
- 验证方式：页面内嵌**模拟回放验证器**——按种子重建特征场景（拒绝采样保证特征互不重叠）与差异指派，校验特征参数合法、差异目标数量与 K 一致、类型有效；渲染层按指派对右图应用变化，两图差异点数与 K 一致。加载时逐关复核，不符的关不进关卡表。
- 生成与验证结果：构建期按难度取特征数 / 差异数 / 限时随机产关，40/40 关通过包内验证器复核（场景可建 + 差异指派完整 + 类型有效）。
