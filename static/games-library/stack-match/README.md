# 叠叠消（gameKey：`stack-match`，category 建议：`puzzle`）

- 玩法：多张牌按层错位堆叠成牌场，只有没被上层牌压住（牌面矩形重叠 + 层高判定）的牌可点；点牌收入底部 7 格槽位，集齐 3 张同图案即消除；右侧盲堆从堆顶逐张翻出是第二牌源；场上牌与盲堆全部清空即过关（槽内/暂存区剩余不成套的散牌自动清出），槽满 7 张且凑不成三张即失败；每关配「撤回 / 移出 / 洗牌」三种道具各 1 次，按是否用道具评 1~3 星。
- 操作：直接点场上可点牌（亮边）或盲堆顶牌收进槽位；「撤回」把最后一张还在槽内的牌退回原处（已参与消除的撤不回）；「移出」把槽位前 3 张移入暂存区暂离（不再参与消除，腾出槽位）；「洗牌」把剩余牌按可解构造整体重排（场上布局与盲堆顺序都会重排，保证局面仍可通关）；「选关」跳转已解锁关卡，「重玩本关」重置。
- 说明：单文件自包含 H5，牌面与牌背全部 canvas 自绘（6 色板 × 6 形状，图案 = 颜色 + 形状双重区分适配色弱），零外链零素材。存档经桥代理跟随账号（本地 + 账号双写，结构 `{lv, cleared, stars}`）；关卡支持后台热更新（DB 下发 + 本地缓存 `sw.stack-match.v1.levels` + 包内 12 关兜底，任一条非法整批放弃）；过关上报到达关卡与累计星级。

## 规则细节

- **遮挡判定**：一张牌可点，当且仅当不存在层号更高的未消牌与其牌面矩形重叠（重叠面积 > 0）。被压住的牌置灰，点击会提示先拿上层。
- **槽位失败**：收入第 7 张后若没有立刻凑成三张同图案即失败；凑成三张会立刻自动消除腾位。
- **盲堆**：顺序在关卡生成时固定（`draw[0]` 为堆顶），玩家只能按序逐张翻出，但可自由选择翻取时机。
- **清尾**：场上与盲堆清空即判过关；此时槽位与暂存区里剩余的 0/3/6 张散牌（每图案 ≤2 张、永远凑不成套）自动清出，不影响星级之外的结算。
- **星级**：未用任何道具 3 星，用 1~2 个 2 星，3 个全用 1 星（取历史最高）。
- **洗牌可解性**：洗牌不是纯随机——把剩余牌（场上 + 盲堆 + 当前槽位，含暂存区缺口）用「逆向消除构造」从终局反向放回，新布局按构造逆序取牌必然存在一条全消路径；撤回记录随之失效。

## 关卡数据格式

```json
{ "name": "启程·第1关", "k": 3, "w": 12, "h": 10, "zl": 1, "tiles": [[7,5,0,2], …], "draw": [2,0,2] }
```

- `k`：图案种数 3–18，牌面图案 = 颜色（`p%6` → 6 色板）+ 形状（`⌊p/6⌋` → 圆/方/三角…）。
- `w`/`h`：牌场宽高（偶数半格单位），每张牌占 2×2 半格，坐标 `x∈[0,w-2]`、`y∈[0,h-2]`。
- `zl`：最大层号（0 单层），须与 `tiles` 中实际最大层号一致；同层牌不重叠，层号 >0 的牌必须与层号-1 的某张牌重叠（无悬空）。
- `tiles`：场上牌数组 `[x, y, z, p]`（半格坐标 / 层号 / 图案号）。
- `draw`：盲堆牌序，`draw[0]` 为堆顶（先被翻出）。
- 隐含约束：场上 + 盲堆总张数为 3 的倍数，每种图案张数为 3 的倍数且全部出现。可解性由生成管线「逆向消除构造 + 回放 + 独立求解器」三重保证（运行时解析只做结构校验，不做求解）。

## 关卡生成与验证

- 生成器：`docs/level-gen/tools/stack-match/generate.mjs`（110 关：三元组数 6→34（总牌 18→99）、图案 3→18 种、层 1→6、盲堆占比 15%→35% 递进）。每关用「逆向消除构造」从空局面反向放回全部牌（每步 un-eliminate/un-pick，新放的牌相对已放牌必须可见），正向按构造逆序取牌必然全清；再经构造解回放自检与不知晓构造解的独立求解器（DFS + Zobrist 记忆化）复核，任一环节不过换随机流重试。产出 `solutions.json`（构造解，供校验器与 e2e 独立回放）。
