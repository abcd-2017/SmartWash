# 层层叠（gameKey：`stack-up`，category 建议：`arcade`）

- 玩法：经典堆塔街机。一块板在塔顶上方左右往返移动，点按屏幕让它落下：与塔沿重叠的部分保留成新层，悬空部分被切割坠落（旋转掉落动画），塔宽变为重叠宽度；完全错开（重叠为 0）即塔倒失败。误差 ≤ 容差判定为「完美」——板自动对齐吸附、不切割，连击达到 `regainEvery` 次时塔宽居中回补 +8px（封顶初始宽），得分按连击数翻涨（封顶 ×10）。叠满关卡目标层数过关，星级按最终塔宽比例（≥60% 两星 / ≥80% 三星）或完美次数评定。
- 操作：全屏点按或空格键落块；全程单指。过关后「下一关」，失败后「再来一次」，切后台自动暂停。
- 说明：单文件自包含 H5，采用**全屏 canvas + 沉浸式 chrome**（`setChrome('immersive')`，同 jump-jump/breakout 先例）：堆塔的点按热区即整个屏幕、塔体与高度渐变背景铺满视口，卡片式容器会截断塔高与落块视野，故不设 `.wrap`。塔层颜色由主题 primary 色相环派生、背景随塔高渐变，深浅色由桥推送（`__gOnTheme` 重绘）。**已接入游戏数据平台化**：存档经桥代理跟随账号（本地 + 账号双写 `{lv,stars,best}`）；关卡支持后台热更新（DB 下发 `{name,layers,speed,width,perfectTol,regainEvery,seed}` + 本地缓存 `sw.stack-up.v1.levels` + 包内 10 关兜底，任一条非法整批放弃并回落包内默认）；移动方向序列由确定性种子生成（mulberry32），同 seed 复现一致。通关上报到达关卡（desc，附得分）。无桥环境自动降级纯本地。

## 关卡参数说明

| 字段 | 含义 | 取值域 |
|---|---|---|
| `layers` | 目标层数（成功落块次数） | 6–40 |
| `speed` | 板水平移动速度（逻辑 px/s，430 逻辑宽） | 60–400 |
| `width` | 塔初始宽度（逻辑 px） | 40–160 |
| `perfectTol` | 完美对齐容差（逻辑 px） | 1–14 且 2×tol < width |
| `regainEvery` | 触发塔宽回补的连击次数 | 1–6 |
| `seed` | 出场方向序列确定性种子 | 0–2³¹−1 |
