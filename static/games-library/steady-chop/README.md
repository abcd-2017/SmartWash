# 夹豆腐（gameKey：`steady-chop`，category 建议：`arcade`）

- 玩法：传送带上的滑行豆腐要用筷尖两端正好卡住夹起、送到盘中松开；移动过快抖动条涨满会脱手，失手一次扣 6 秒。限时夹满目标数过关，豆腐更滑、带速更快逐关递增，共 42 关（包内默认关，支持后台关卡下发）。
- 操作：触屏拖动移筷、双指张合调筷距、按钮夹取/松开；键盘方向键移动、ZX 调筷距、空格夹取/松开、P 暂停。
- 说明：单文件自包含 H5，零外链、canvas 自绘；42 关内嵌 JSON 经保守算术模型逐关验证可完成（最小时间余量 1.85×）；接 GB 桥存档/关卡/成绩上报，无桥降级 localStorage。
