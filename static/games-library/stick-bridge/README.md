# 木棍过桥（gameKey：`stick-bridge`，category 建议：`arcade`）

- 玩法：小人站在台柱右缘，前方是深涧；按住屏幕木棍从脚下匀速竖起伸长，松手放倒搭向对岸；棍长够到对岸即走过，停在台面中心±容差为完美（双倍分+拾取宝石），太短坠涧、太长越过对岸均失败；达标分或走完全程过关，按完美段数占比评 1~3 星，完美连击加分逐级翻倍（2/4/6/8/10 封顶）。
- 操作：按住屏幕任意处伸棍、松手放倒，时长即棍长；支持桌面空格键按住/松开；蓄力封顶有「力度已满」闪烁提示；重试/下一关走浮层按钮，切后台自动暂停。
- 说明：单文件自包含 H5，全屏 canvas 沉浸式（`setChrome('immersive')`），小人/木棍/台柱/远山/深涧/宝石全部 canvas 自绘，零外链零素材。自研确定性引擎：棍长 = 按压时长 × 伸长速度（固定速度、上下限截断），松手瞬间解析判定（峡谷宽/平台半宽/容差），帧率无关，同按压时长必同棍长；地形由种子确定性生成（`mulberry32`），同关跨端可复现。存档经桥代理跟随账号（`{lv, stars, best, gems}`），关卡支持后台热更新（DB 下发 + 本地缓存 `sw.stick-bridge.v1.levels` + 包内 12 关兜底，任一条非法整批放弃），过关上报到达关卡与得分。

## 关卡数据格式

```json
{ "name": "启程·第1关", "seed": 331200528, "count": 6, "speed": 280, "target": 15, "gapRange": [26, 46], "platRange": [64, 110] }
```

- `seed`：确定性 PRNG 种子（正 int32），`mulberry32` 依次抽取各段峡谷宽与平台宽（首台从 x=0 起），同一关跨端可复现。
- `count`：平台数 6–16（走 count−1 段到关底）。
- `speed`：木棍伸长速度 px/s（180–800），越高同按压时长的棍长误差越大。
- `gapRange` / `platRange`：各段峡谷宽与平台宽的取值区间（px）。
- `target`：目标分；达标分**或走完全程**即过关，目标分锚定模拟分数分布 P35 并夹取理论分 18%~82%。

## 计分与星级

- 判定：棍长 L 自本台右缘起算，L < 峡谷宽 = 太短（坠涧）、L > 峡谷宽 + 平台宽 = 太长（越过对岸坠落）；命中台心 ± 容差为 perfect，容差 = max(5, min(平台宽×0.2, 伸长速度×0.12)) px。
- 计分：perfect 得 `2×min(连击数, 5)`（首段 2 分，连击逐级翻倍至 10 封顶），普通通过 +1 并断连；perfect 沿途拾取台心宝石（存档累计）。
- 过关：得分 ≥ target 或走完全部段；星级按完美段数占比（过关 1 星、≥35% 得 2 星、≥65% 得 3 星）。

## 关卡生成与验证

- 生成器：`docs/level-gen/tools/stick-bridge/generate.mjs`（110 关：伸长速度 280→500、平台宽 [64,110]→[38,62]、峡谷宽 [26,46]→[72,140]、平台数 6→13、按压误差 σ 48→26ms 五维递进）。每关先逐段几何可达校验（瞄准台心的按压时长落在 [110,1300]ms 操作区间、峡谷可见），再用「策略玩家模拟」（解析反解瞄准台心的按压时长 + 高斯按压误差，判定/计分与线上引擎逐字同构）统计分数分布，目标锚定 P35（按分通过率约 65%）并夹取理论分 18%~82%，要求按分通过率 ≥35% 且综合通过率 ≥50%，不达标换种子重生成。
- 独立校验器：`docs/level-gen/tools/stick-bridge/validate.mjs`（信封契约 / 字段取值域 / 地形重建复核（峡谷与平台宽落在声明区间、x 前进、逐段可达）/ 目标分比例 / 不同种子独立模拟复验（按分 ≥30% 且综合 ≥45%）/ 唯一性 / difficulty 单调 / 数量字节 / DEFAULT_LEVELS 一致性）。110/110 通过，综合通过率最低 51.5%、按分通过率最低 49.5%。
- 引擎白盒单测：`engine-test.mjs`（84 项：PRNG 确定性、地形契约、按压→棍长映射截断与单调、反解往返一致、容差域、四类判定边界、连击计分、理论上限、星级边界、可达正反例、平移不变、全库 1005 段「瞄准中心必 perfect」整卡复核）。
- 解析单测：`parse-test.mjs`（66 项：从 index.html 抽取真实 parseStickBridgeLevels/applyLevels，含字段域越界、几何不可达、夹带非法、levelNo 重复等非法输入整批放弃，缓存持久化）。
- 浏览器 e2e：`browser-test.mjs`（375px 无头 Chrome 实开 25 项：反解按压时长真实按住-松手 5 段完美过关 + 成绩上报 + 进度持久化 + 超短按失败结算 + 深色主题推送下游玩全程无错 + 非法 DB 批次整批放弃并回落包内默认关）。
