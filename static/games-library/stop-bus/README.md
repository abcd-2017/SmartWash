# 到站收骰（gameKey：`stop-bus`，category 建议：`board`）

- 玩法：与 AI 的掷骰收集博弈。每回合掷 5 颗骰，1 点是「过站废骰」不可收；点选 2-6 的同点骰全部收进本轮（每个点值本轮只能收一次），收完后自行权衡：「再掷」用剩余骰继续追（重掷后没有可收点即「炸站」，本轮所收全部丢失）或「收站」把本轮骰子计入站台进度；站台 2~6 各需 3~7 颗（随关卡加码），集满即收下该站，先收满 3 个站台者胜。
- 操作：点骰子收点、点「再掷」/「收站」；键盘 2-6 收对应点数、空格再掷、回车收站、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关为配置型对局（站台基准量 3→5、AI 风险阈值 0.50→0.15 递进）；AI 采用期望策略（炸站概率超阈值即收站）；切后台自动暂停 AI 回合（visibilitychange）；存档键 `sw.stopbus.v1`，到达关卡经 GB 桥上报（desc）；无桥环境自动降级纯本地。

## 关卡验证

- 每关结构 `{name, needBase(3..5 站台基准量), ai(0..5 风险阈值档), difficulty}`；站台 need(2..6) = needBase..needBase+4。
- 验证方式：
  ① **炸站概率闭式校验**：抽样 (重掷颗数 m, 已收点值数 k) 对照闭式解 ((1+k)/6)^m 的锚点（k=0,m=1 → 1/6；k=0,m=2 → 1/36；k=5 → 恒为 1），不一致即淘汰；
  ② **无头 AI vs AI 模拟器**：每关自动对局 **200 局**，全部对局必须终止（回合上界 800）且恰有胜者（收满 3 站），任一局异常即淘汰该关。
- 生成与验证结果：40 关（needBase 3→5、ai 档 0→5）全部通过锚点校验与 200×40=8000 局模拟（**40/40**）；jsdom 无头冒烟测试实测完整对局到收满站台分出胜负、键盘开局与选关流转正常。
- 验证过程中修复的关键缺陷：`rndFor` 曾误返回随机流函数本身（导致 NaN），已修正为返回随机数。
