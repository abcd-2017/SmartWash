# 笔画竞猜（gameKey：`stroke-count`，category 建议：`word`）

- 玩法：每关 4 题，每题限时 8 秒，同时给出两个汉字，选出笔画更多的那个；答错或超时计失误并立即揭示答案，失误 2 次本关重开；4 题答完过关。
- 操作：触屏点大字卡；键盘 1 / 2 选左/右字；选关面板逐关解锁；切后台自动暂停（计时基点平移，回来接着数）。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌 160 题；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每题结构为 `[字A, 笔画A, 字B, 笔画B]`；正确答案由笔画数在运行时唯一推出。
- 内嵌独立验证器逐关复核：① 结构完整（均为单字、笔画数 1-36 整数、关内字对不重复）；② **答案唯一性**——同题笔画数不相等（禁平局）且差值 ≥2，保证「比大小」结果肉眼可辨、无争议；③ 可通关性显然（限时内任选其一即可判）。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核，异常关会在消息区告警）。
- 内容口径：笔画数按《通用规范汉字表》通行笔顺规则逐字人工核定（如 黑 12 画、跑 13 画、嘴 16 画）；全库避开多音字与新旧字形争议字，用字均为常用字，配对刻意拉大笔画差以消除边界争议。
