# 笔顺补笔（gameKey：`stroke-fill`，category 建议：`word`）

- 玩法：每关一个常用字，按标准笔顺逐笔从 4 个笔画名选项（横/竖/撇/捺/点/提/各类折钩等）中选出「下一笔」，选对该笔计入笔顺胶囊列表，选错计失误；全部笔画补完过关，40 字按笔画数递增排列。
- 操作：触屏点笔画卡片；键盘 1-4 选笔画、R 重开；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；以「笔顺胶囊列表逐笔揭示」的方式呈现补笔过程（文字笔顺游戏，不绘制真实笔画轨迹）；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, zi(单字), strokes(完整笔顺序列)}`；字库为一～竹共 40 个笔顺无争议常用字（笔画数 1-8 递增）。
- 内嵌独立验证器逐关复核：① 结构完整（zi 单字且跨关唯一、strokes 1-9 项、每项必须在固定笔画名集合中——横/竖/撇/捺/点/提/横折/横折钩/竖钩/横折弯钩/竖折/撇折/卧钩/横撇/竖弯钩/横折提）；② 可通关性由构造保证（正确项必在 4 选项中，选错可继续）。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核，异常关会在消息区告警）。
- 内容口径：笔顺序列为**自撰数据**，按《现代汉语通用字笔顺规范》通行规则逐字人工核定（如 王=横横竖横、水=竖钩撇撇捺、雨=横竖横折钩竖点点点点）；全库避开笔顺有争议或新旧字形差异字。
