# 合成大西瓜（gameKey：`suika`，category 建议：`arcade`）

- 玩法：在容器上方拖动选择落点、松手投放水果；同级水果相碰即合成为下一级更大水果（樱桃→草莓→葡萄→橘子→柠檬→猕猴桃→番茄→西瓜），两个西瓜相撞会消除并给大奖。步数用完前达到目标分即过关；水果堆越过警戒线太久则失败。
- 操作：按住画布左右拖动瞄准（虚线为落点参考线），松手投放；也支持键盘 ←/→ 移动、空格/回车投放。右上角「下一个」预览下一颗水果。
- 说明：单文件自包含 H5，零外链零素材文件（水果全部 Canvas 自绘）。自研简化 2D 圆物理（圆-圆弹性碰撞 + 重力 + 容器壁 + 合成事件），固定步长积分，同种子可复现。关卡由包内 DEFAULT_LEVELS（12 关）与 DB 下发共同驱动，进度自动保存。

## 物理与合成判定

- 世界为 360×520 逻辑坐标，等比缩放居中渲染；物理按固定步长 1/60s 推进。
- 每步：重力加速 → 半隐式欧拉积分 → 容器壁反弹（恢复系数 0.22）→ 圆-圆碰撞（位置修正 + 法向冲量 + 少量切向摩擦）。
- 两个**同级**水果圆心距 ≤ 半径和 + 1（接触即合成）时合并为下一级，新果出现在二者中点并继承部分速度；西瓜 + 西瓜直接消除并 +100 分。
- 发牌序列由 mulberry32 种子随机数驱动（关卡 seed），与物理一致，同一投放序列必然复现同一结果。
- 判负：水果（投放 1.2s 宽限后）持续 2.5s 顶部高出警戒线；或步数用尽未达目标分。

## 关卡数据

`.levels.json` 顶层数组，每项信封 `{"levelNo":N,"name":"…","difficulty":D,"data":{…}}`；`data` 字段：

| 字段 | 含义 |
|---|---|
| `name` | 关卡名（≤32 字） |
| `target` | 目标分（达标即过关） |
| `moves` | 可用投放步数 |
| `seed` | 确定性种子（0..2³¹-1） |
| `fruitSet` | 投放水果等级范围 `[lo,hi]`（0=樱桃 … 7=西瓜） |

共 120 关：目标分 18→336 单调不减，步数 13→47 递进，水果范围 `[0,2]`→`[0,5]` 逐带扩展，组合四元组唯一。

## 生成与验证工具（docs/level-gen/tools/suika/）

- `generate.mjs`：按 10 个难度带生成 120 关；用与线上引擎逐字同构的求解器求限定步数内最高可达分，取目标分 = 最优分 × 难度系数（含单调与唯一约束），并回放验证确有一条达标路径。
- `solver.mjs`：从 index.html 抽取 SK 引擎块 + 贪心/确定性重启求解 + 序列重放。
- `verify.mjs`：独立校验（信封/参数/唯一性/单调性/可通关回放/确定性复现/默认关一致性）。
- `parse-test.mjs`：`syncLevelsFromServer` 解析逻辑单测（非法输入整批放弃）。
- `smoke.mjs`：最小 DOM 桩端到端冒烟（启动→开始→按解路径通关→胜利面板）。
