# 冲浪切浪（gameKey：`surf-wave`，category 建议：`arcade`）

- 玩法：浪面为双正弦叠加的起伏地形，按住卡浪上爬蓄势（浪势环），在陡坡松手起跳腾空，空中每点一次转体半圈，落回浪面按连击倍数结算技巧分；落点太平（浪谷）或冲过陡坡即落水，三次落水结束；浪高与频率随里程递增。
- 操作：触屏按住=蓄势、松手=起跳、空中点按=转体；键盘空格 / ↑ 同三作用（按下蓄势、松开起跳、空中敲击转体）；「开始 / 暂停 / 继续 / 重新开始」同一按钮切换；切后台自动暂停。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；最高分 localStorage + 账号双写（裸最高分，snake 先例），结束上报最高分（desc）；分数 = 里程 m + 技巧分（转体圈数×80×连击倍数）；合集内唯一的水面地形滑行玩法；WebAudio 未接入。
