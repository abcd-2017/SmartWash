# 三段论（gameKey：`syllogism-judge`，category 建议：`other`）

- 玩法：给出大前提 / 小前提 / 结论（词项取自日常名词池，如「所有金鱼都不是猫」「有些厨师是诗人」），判断结论能否从两个前提**必然**推出；必然 / 不必然题各占一半，答错扣 8 秒，错满 3 题失败。
- 操作：触屏点「必然成立」/「不必然成立」；键盘 1 / 2 对应两个判断、R 重开、L 选关。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（种子生成，6→10 题、90→80 秒），到达关卡经 GB 桥上报（desc，metricValue=过关关号，metricExtra=剩余秒数）；**语义口径为现代一阶逻辑**：全称命题允许主项为空（空真），特称命题要求存在；判定完全由 4 个体 × 3 词项的模型枚举给出，不依赖经典词项逻辑的存在预设；切后台自动暂停并把计时基点平移。

## 关卡验证

- 关卡结构 `{dc:{q,time},qs[]}`：每题 `{q1,q2,q3,terms[],valid}`，命题 `[type,subjSlot,predSlot]`（type 0=A 全肯 1=E 全否 2=I 特肯 3=O 特否；槽 0=S / 1=P / 2=M），terms 为 3 个词项池下标（互异），valid 为枚举判定的必然性。
- 生成算法：必然题从**经典有效式表**（现代语义 15 式：AAA-1、EAE-1、AII-1、EIO-1、EAE-2、AEE-2、EIO-2、AOO-2、AII-3、EIO-3、IAI-3、OAO-3、AEE-4、EIO-4、IAI-4；条件式 Darapti 等因存在预设被排除）随机选式构造并经枚举器复核；不必然题随机构造后过滤掉碰巧必然的。
- 验证方式：游戏内嵌**独立验证器** `verifyLevelData`（递归赋值枚举 `evalVer`，与生成器的位掩码遍历 `evalGen` 为两条不同实现路径）逐题复核真值一致性、前提可满足（排除矛盾前提的空真怪题）、词项互异与三段论角色（大前提连 M/P、小前提连 S/M、结论连 S/P）。
- 标准锚点用例（人工核对经典逻辑）：①Barbara AAA-1 必然 ②Celarent EAE-1 必然 ③Darii AII-1 必然 ④AAA-2 不必然 ⑤「E(M,P)+O(S,M) → I(S,P)」不必然 ⑥两实现对拍（真值与模型数均一致）。启动时逐关复核 40 关 + 锚点断言，验证失败在消息区告警。
- 生成与验证结果：40/40 关通过（必然题 162/324 恰半），无告警。
