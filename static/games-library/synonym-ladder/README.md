# 近义天梯（gameKey：`synonym-ladder`，category 建议：`word`）

- 玩法：每关一座五级天梯——起点词与终点词已固定，中间三级需从 4 张词卡（3 张路径词 + 1 张陷阱词，已打乱）中按近义渐变次序逐级选词登梯；选错（含踩到陷阱词）计失误并抖动提示，三级登完过关。
- 操作：触屏点词卡；键盘 1-4 选词、R 重开；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；天梯视觉自下而上呈现（起点绿、终点蓝）；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, from(起点), path(中间三级近义路径), to(终点), trap(陷阱词)}`；词库为 40 组自撰近义渐变链（高兴→喜悦、安静→寂静、节约→朴素等）。
- 内嵌独立验证器逐关复核：① 结构完整（from/to/trap 与 path 全部词互不相同、词长 1-3）；② **陷阱互斥**——trap 不在路径上，且全部为该语义域外的词（人工校对）；③ 可通关性由构造保证（正确项必在卡中，选错可继续）。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核，异常关会在消息区告警）。
- 内容口径：路径词为同义/近义词的**语义强度渐变序列**，相邻词近义程度较高，逐组人工校对排序合理性；陷阱词取其反义词或邻近域词汇（如「高兴」链的陷阱「生气」）。
