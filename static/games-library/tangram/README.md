# 七巧板（gameKey：`tangram`，category 建议：`puzzle`）

- 玩法：经典七巧板拼图，七块板（2 大三角、1 中三角、2 小三角、1 正方、1 平行四边形）拖入剪影轮廓，全部放满且互不重叠即过关；共 144 关，涵盖经典方、大三角、帆船、净瓶、琵琶、灵蛇等 19 种造型，难度 1-6 分层递进。
- 操作：手指拖动板块，松手时靠近正确位置自动吸附；点选板块后用「旋转 45°」「翻转」（仅平行四边形）调整朝向；碰界或重叠的板块会显示红色警示。
- 说明：单文件自包含 H5，Canvas 自绘零外链；关卡支持服务端下发（包内默认 10 关兜底），进度、星级与最短用时自动保存并上报。

## 关卡数据

- `.levels.json`：144 关，信封 `{"levelNo","name","difficulty","data":{"name","sil"}}`；`sil` 为剪影多边形顶点（整数、逆时针），并集面积恒为 64（8×8 基准，七块面积 16/16/8/4/4/8/8）。
- 全部造型由「块堆叠生成器 + DFS 精确覆盖求解器」构造保证可解，并经独立校验器复验（两两交面积 = 0、并集面积 = 64、闭合简单多边形）。
