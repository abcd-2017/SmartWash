# 鱼缸生态（gameKey：`tank-eco`，category 建议：`other`）

- 玩法：一缸鱼要活过整段值班时间——加热器乒乓控温把水温留在舒适绿区（室温偏低会持续降温），饿过半要喂料（浮料太久坏水），水质见差要换水（次数有限），任何一条失控都会掉血，血尽即失败。
- 操作：触屏点「加热器 开/关」「喂料」「换水」「暂停」；键盘 H 加热器、F 喂料、W 换水、空格 暂停/继续、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，难度沿舒适带宽度/室温/需食量/水质恶化速率递增。

## 关卡验证

- 内嵌 40 关，每关结构 `{name,time,fish,lo,hi,roomT,hRate,wasteK,food,water,difficulty}`；`food`/`water` 预算由参考策略实测用量 + 余量得出。
- 验证方式：游戏内嵌**确定性模拟器** `TE.tick`（0.25s 固定步长纯函数：温度热平衡、饥饿-进食-残饵坏水、三因子掉血/回血）+ **参考策略回放** `TE.runPolicy`（温度中值乒乓、饿过半喂、差水换），生成期逐关断言策略回放全存活且最低血量 ≥25，`TE.validate` 复核结构+可解性。
- 锚点用例（`window.__validateLevels()` 共 7 条，node 抽取 XC-CORE 复现）：带内室温无热源恒温 24.0（精确不变）、换水 +35 后 84.955（同拍衰减可复核）、失温单步扣血 0.55（2.2×0.25 精确）、喂料 池+1/料-1、濒死一拍判定 dead、40 关策略回放全部存活、生成逐字节确定。
- 生成与验证结果：40/40 关参考策略回放全部存活（fail 空），策略最低血量 ~79（余量充足，玩家可容忍适度失误）。
