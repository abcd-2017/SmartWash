# 靶心速射（gameKey：`target-rush`，category 建议：`arcade`）

- 玩法：60 秒限时点射不断出现/平移/缩放的标靶：环心 10 环 100 分、8 环 60、5 环 30，连击不脱靶叠最高 ×3 倍率；金色速靶 +300，打中炸药 -200 并清空连击。命中率与最高连击入结算，分数驱动冲最高分。
- 操作：触屏点哪打哪；键盘方向键移动准星、空格射击，P 暂停、R 重开。
- 说明：单文件自包含 H5，零外链、canvas 自绘；--g-* 主题 token 双主题；接 GB 桥最高分存档与成绩上报，无桥自动降级 localStorage。
