# 三张猜牌（gameKey：`three-card-monte`，category 建议：`board`）

- 玩法：三张牌中一张是 ★ 目标牌，先明置展示；按「开始换位」后牌面盖下，按确定性交换序列执行 4→24 次两两换位动画（速度随关卡加快），换位结束后凭轨迹记忆点出 ★ 现在所在的牌位，猜对过关。
- 操作：回车开始换位；换位结束后点牌位或按 1/2/3 猜测；R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关为配置型关卡（换位次数 4→24、速度档 1→6 递进）；换位序列由种子确定性生成、**动画与判定共用同一序列**；切后台自动暂停换位动画（visibilitychange，恢复后继续剩余序列）；存档键 `sw.threecardmonte.v1`，到达关卡经 GB 桥上报（desc，附连胜数）；无桥环境自动降级纯本地。

## 关卡验证

- 每关结构 `{name, swaps(2..60 次换位), tier(1..9 速度档), difficulty}`；每局的交换序列 = `genSwaps(种子, swaps)`（LCG 确定性生成，每步为 3 位中两个不同位的交换对），同一关重试序列会随局数轮换。
- 验证方式：游戏内嵌**独立双实现回放验证器**——对每关 20 个独立局种子：① 校验生成序列良构（每步两位不同且在 0..2 内）；② 用两套相互独立的跟踪器（A：目标下标直接映射；B：槽位数组物理交换后查找）分别回放整段序列，两者终局判定必须一致且合法。加载时同步复核全部关卡（毫秒级），坏关不进关卡表。
- 生成与验证结果：40 关（swaps 4→24、tier 1→6）全部通过 20×40=800 轮双跟踪器交叉验证（**40/40**）；jsdom 无头冒烟测试实测换位动画走完进入猜测阶段、揭示浮层与重开流转正常。
