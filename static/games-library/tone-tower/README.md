# 四声塔（gameKey：`tone-tower`，category 建议：`word`）

- 玩法：每关 4 个声调各不相同（恰为一二三四声）的汉字，按声调从低到高依次点选叠塔，放错层会抖动并计失误，四层全对即过关。
- 操作：触屏点候选字卡上塔；键盘 1-4 选字、R 重摆；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，前 20 关带拼音提示、后 20 关只显汉字凭读音判断；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, ch[4], py[4], tn[4], difficulty}`；`tn` 恰为 1/2/3/4 各一 → 按声调排序答案唯一，可通关性由构造保证。
- 内嵌独立验证器逐关复核：① 结构完整（四字段长度=4、字形关内唯一）；② **内容正确性**——用「拼音声调符号 → 调值映射表」复核 `py` 的调号与 `tn` 一致（如 好 hǎo ↔ 3）；③ 调值集合恰为 {1,2,3,4}。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核，异常关会在消息区告警）。
- 内容口径：字表自撰常用字，声调以普通话审定音为准，全部避开多音字与轻声、儿化争议字。
