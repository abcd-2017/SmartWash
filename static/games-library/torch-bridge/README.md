# 手电过桥（gameKey：`torch-bridge`，category 建议：`puzzle`）

- 玩法：数人不同速过桥，每次最多两人同行且必须带走手电，同行耗时按较慢者计；在限时内让全部人过桥。
- 操作：触屏点选 1-2 人同行，再点「过桥」；键盘 1-5 选人、空格过桥、Z 撤销、H 提示。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；46 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 46 关，每关结构为 `{name, people[], limit, par, difficulty}`；`people` 为每人过桥耗时（秒），`limit` 为限时。
- 验证方式：游戏内嵌**独立 Dijkstra 求解器** `torchDijkstra`（状态=左岸人员掩码×手电侧，边权=同行耗时），加载每关时复核可解性并计算最短总耗时；超时或不可达会在消息区告警，提示取最短路首跳。
- 生成与验证结果：46/46 关可过桥，Dijkstra 实测最短耗时与关卡 `par` 一致（17s 递进）。
