# 塔台放行（gameKey：`tower-control`，category 建议：`other`）

- 玩法：飞机陆续进入等待区，各有燃油倒计时；跑道空闲时点候机卡放行着陆、或放起飞队列的飞机起飞。跑道占用时强放记冲突，燃油耗尽备降、等待区溢出都会记事故，满 3 次停止运行。
- 操作：触屏点候机卡片放行、点「放一架起飞」放起飞；键盘 1-6 放行对应候机、Q 放起飞、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc），metricExtra 为累计放行架次。

## 关卡验证

- 内嵌 40 关（第 1 关为手工锚点关，其余由种子确定性生成航班后冻结为 `traffic[{t,kind,fuel}]`），结构 `{name, ticks, target, landT 单次占用, holdMax 等待区上限, fuel 燃油, span 到港间隔, traffic}`。
- 验证方式：内嵌**EDF 策略回放验证器**（先落油最少的候机、无候机则放起飞），逐关回放须 `win` 且零事故；DB 下发关卡同样整表回放通过才接受。收敛链：加燃油→降目标→加班次时长（坏关不进表）。
- 锚点用例：① 第 1 关 EDF 放行 ≥12 架且零事故 ② 合成「4 机同刻同燃油、单跑道」其余 3 架备降满 3 次判负 ③ 全部 40 关回放可达成。
- 生成与验证结果：`TC2.selfTest()` 3 项锚点全 PASS，40/40 关可达成。
