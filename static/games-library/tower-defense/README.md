# 塔防路线（gameKey：`tower-defense`，category 建议：`arcade`）

- 玩法：固定路径塔防：S / U / 折返 / 绕圈四种路线轮转，路旁预置塔位；金币建箭塔 / 冰塔（减速）/ 炮塔（溅射）并逐级升到 Lv3（伤害 ×2.25、射程 +16%），抵御普通 / 快速 / 坦克混编波次，敌人抵达基地扣生命，清完全部波次过关。
- 操作：点塔卡（或键盘 1-3）选中，点方格塔位建塔；点已建塔直接升级（升满提示）；键盘 ←→ 切换塔位光标、回车 / 空格建或升；「重试 / 选关 / 下一关」按状态切换。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）。40 关由种子生成器确定性生成（波数 3→8、每波 4→14 只、坦克波出怪间隔 ×1.5、血量 13→99 递增），出怪时间表由种子驱动。**可通关性验证 = 贪心建塔升级策略确定性模拟**（按路覆盖度排序塔位、全计划扫描首个可负担动作，与游戏共用同一套沿路推进 / 索敌 / 结算核心），40/40 全胜；调试入口 `window.__validateLevels()` 复现（node 抽取 XC-CORE 段独立运行）。关卡缓存 `sw.towerdefense.v1.levels`，DB 下发整批替换（模拟不过整批放弃）；存档 `sw.towerdefense.v1` 双写，过关上报到达关卡（desc，附剩余生命）。

## 关卡与验证

- 关卡数据：`{name, tpl(路径模板 0-3), waves:[{n, kind:0-2, hp, spd, gap, delay}], gold0, lives, seed}`。
- 可通关性：贪心策略确定性模拟 40/40 全胜（贪心近似最优经济运营，人类玩家延迟升级时会承压，难度由血量 / 波数递增承载）。
