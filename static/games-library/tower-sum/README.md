# 数字塔（gameKey：`tower-sum`，category 建议：`puzzle`）

- 玩法：底层一行数字，相邻两数求和向上堆出整座塔（每格等于脚下两格之和）；部分格被挖空，要填回全部空格，后期底层也被挖空、需要从塔顶与中层反推。
- 操作：触屏点虚线空格，再用 -10/-1/+1/+10 调数值、清除归空；键盘 ←/→ 切空格、↑/↓ 调数值、Enter 提交、Backspace 清除、H 提示、R 重开、L 选关。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（种子生成，4 层递进到 6 层，空格 3-7 个），到达关卡经 GB 桥上报（desc，metricValue=过关关号，metricExtra=失误次数）；提交错误标红错格并扣一次机会，3 次内全对过关；不限时（纯事件驱动，切后台无需暂停）。

## 关卡验证

- 关卡结构 `{n,grid,sol}`：n=4..6，grid[r] 为第 r 层（层 0 是塔顶、层 n-1 是底层），null 表示空格；sol 为完整塔。塔结构约束：sol[r][c] = sol[r+1][c] + sol[r+1][c+1]。
- 生成算法：底层随机 1-9 → 帕斯卡正推整塔 → 挖空（底层 0-1 格 + 非底层 3-6 格）→ 唯一性校验（底层空格组合枚举，多解时逐个恢复非底层空格增加约束，仍多解换种子重试）。
- 验证方式：游戏内嵌**独立验证器** `verifyLevelData`（结构校验 + 解的帕斯卡自洽 + **递归 DFS** 枚举底层空格后自底向上正推计数），要求满足全部约束的解恰为 1；生成器用**迭代枚举** `countSolIter`（与 DFS 不同实现路径）互为对拍。
- 标准锚点用例（人工核对）：①n=2 顶层挖空 → 唯一解 5 ②n=3 中层全给定反推底层 → 唯一 ③n=2 只给顶 10、底层全挖 → a+b=10 有 9 解（非唯一检测，计数器到 2 早退应返回 2）④n=4 全路径唯一谜题（底 [1,2,3,4] 挖 b=1 与顶层，中层 [8,12]/[3,5,7] 全给定）。启动时逐关复核 40 关 + 锚点断言，坏关自动换种子重试，验证失败在消息区告警。
- 生成与验证结果：40/40 关唯一解通过（空格 3-7 个），无告警。
