# 藏宝坐标（gameKey：`treasure-grid`，category 建议：`puzzle`）

- 玩法：7×7 至 9×9 海图上藏宝——每行恰好 1 个宝藏，宝藏八向（含斜向）互不相邻；用列计数、区块计数、对角线计数三重线索推理出全部宝藏位置。
- 操作：触屏点格循环「空格 → 宝藏 → 排除 ×」；键盘方向键移动、Enter 循环标记、Z 撤销、H 提示。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, n, cols(列计数线索), regs(两条区域分割线), regc(四区块线索), diagc(两条对角线线索), sol, difficulty}`；总宝藏数 = n（每行 1 个）。
- 验证方式：游戏内嵌**独立验证器** `tgCount`（与交互逻辑分离的回溯计数器）：在「每行 1 个 + 八向不相邻 + 列/区块/对角三重计数线索」约束下枚举全部布局，要求解数 ≥ 1（40/40 关实际唯一解）；后台分片逐关复核，验证失败的关在选关面板禁用。
- 生成与验证结果：40/40 关可解且唯一（构建期与运行时双重回溯复核；生成器逐实例重试直至唯一签名）。
