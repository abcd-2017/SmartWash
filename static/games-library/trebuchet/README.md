# 投石攻城（gameKey：`trebuchet`，category 建议：`arcade`）

- 玩法：调配投石机的发射角度与配重（配重决定初速），把石弹砸到城墙底部的城门上；注意风向与悬浮盾牌，每关 3 发炮弹。
- 操作：触屏点「角度±」「配重±」与「发射」；键盘 ◀▶ 调角度、▲▼ 调配重、空格发射、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc），metricExtra 为破门后剩余炮弹数。

## 关卡验证

- 内嵌 40 关（第 1 关为手工锚点关，其余公式化确定性生成 + 收敛回退链：去盾→压低城墙→加大城门→保底参数），结构 `{name, wx 墙位, wh 墙高, gh 门高, wind 风加速度, shields[] 盾, ammo 炮弹数}`。
- 验证方式：内嵌**独立参数扫描验证器**——角度 10°..80° × 配重 20..100 全组合逐个确定性抛体模拟（固定步长 1/120s，风/墙/盾/落地判定），存在命中城门的组合即判可解；DB 下发关卡同样整表扫描通过才接受。
- 锚点用例：① 第 1 关 45°/配重 66 砸开城门（手工推演：v0=291.6，下落段在墙面处 y≈283~296 ∈ 城门带 [250,300]）② 合成「城门被盾封死」关扫描判定无解 ③ 全部 40 关扫描有解。
- 生成与验证结果：`TB.selfTest()` 3 项锚点全 PASS，40/40 关可解（扫描耗时 <200ms）。
