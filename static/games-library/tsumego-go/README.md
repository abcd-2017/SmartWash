# 围棋吃子（gameKey：`tsumego-go`，category 建议：`board`）

- 玩法：围棋吃子手筋题库。黑只此一手：前 20 题找一手提掉白棋，后 20 题找一手让两块相邻白棋同时只剩 1 气（双叫）；自杀手不合法，走错自动收回并计失误。
- 操作：触屏点交叉点落子；键盘方向键移光标、Enter 落子、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；5×5→7×7 棋盘 40 题内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 每题结构为 `{name, size, rows[], goal, par, sol[], difficulty}`；`rows` 为棋盘字符行（`.` 空 / `b` 黑 / `w` 白），`goal` 为 `cap`（提子）或 `dbl`（双叫，口径：与新落子相邻且落子后恰 1 气的白棋链 ≥2），`sol` 为正解点列表。
- 验证方式：**独立验证器**（栈式泛洪求棋链与气、全空点枚举落子效果，占位/自杀剪枝）在加载时逐题复核正解存在并重算正解数；**对弈判定**（递归泛洪独立实现）负责交互落子判定。双实现互不引用。
- 生成与验证结果：40/40 题有正解（37 题唯一解、3 题 2 处正解），生成期已剔除盘面无气死子；DB 下发题目逐题过滤，无正解题不进关卡表。
