# 波路牌（gameKey：`tsuro-path`，category 建议：`board`）

- 玩法：Tsuro 类铺路生存——把手中路径牌放到自己棋子正前方，棋子沿牌面路径滑行（双方棋子都会被路推着走）；滑出棋盘即淘汰，最后存活者胜；两条路撞进同一段双双出局，落牌方判负。
- 操作：触屏点手牌选牌（再点同张=旋转 90°）→ 点「落牌」；键盘 ←→ 切手牌、↑ 旋转、Enter 落牌、U 悔棋、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关 = 棋盘 5/6/7 路 × 手牌 3-5 × 电脑段位 1-3 × 起始行组合，AI 为手牌×旋转全枚举模拟滑行 + 距边启发，到达关卡经 GB 桥上报（desc）。切后台 AI 思考作废、轮次归还玩家。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, size(5-7), hand(3-5), skill(1-3), rowP, rowA}`；牌库为确定性种子生成的 36 张跨侧对合牌（无同侧 U 形配对）。
- 验证方式：游戏内嵌独立验证器 `selfTest`——① 40 关配置校验；② **标准锚点用例**：跨格映射自反性（cross[k]=j ⟺ cross[j]=k，手推 8 端点）、直通牌 8 旋转均连对面（手推）、旋转公式一致性（rotated 后 effPartner 与直接旋转等价）、直通两连停 (r,1) / 三连整行滑出界（手推）；③ 牌库结构：36 张、全为跨侧对合；④ 3 局 AI 自战对拍：落牌全部来自手牌枚举、必有终局（淘汰/和局）。
- 生成与验证结果：20/20 项自检通过（含 3/3 局 AI 对拍）。**开发期锚点曾抓出「DECK 去重键用旋转规范形导致可产牌数不足死循环」与「锚点⑥把牌库数组当卡牌对象」两处缺陷。**
