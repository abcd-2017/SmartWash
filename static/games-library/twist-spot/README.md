# 绕口找茬（gameKey：`twist-spot`，category 建议：`word`）

- 玩法：每关一句绕口令短句，其中混入 2 个近音/近形错字；点出全部错字即纠正过关，点错字算失误；提示按钮有限 2 次，会指出一个未纠错字并给出正确写法。
- 操作：触屏点字块纠错；键盘 ←→ 移动游标、Enter/空格 纠错、H 提示、R 重开；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, text(句面), wrong:[{a:错字,b:正字,n:正字第几次出现}], difficulty}`；错位以**替换对**描述，加载时在句面中解析出具体位置。
- 内嵌独立验证器逐关复核：① 结构完整（句长 6-44、错位 1-4 处、a/b 均为单字且 a≠b）；② **替换一致性**——正字 b 必须在句面中按第 n 次真实出现，且该位置原字恰为 b（保证「正字被换成错字」语义成立）；③ 同一字不可被两处替换、同一错字不重复使用；④ 可通关性显然（错位位置已解析，玩家点选即判）。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核，异常关会在消息区告警）。
- 内容口径：绕口令短句为**自撰与民间口诀**（「四是四，十是十」「吃葡萄不吐葡萄皮」等通行句式 + 自撰变体），不含版权素材；错字均为同音/近音/近形字（如 十→时、凰→皇、烙→路），逐句人工校对替换后读不通。
