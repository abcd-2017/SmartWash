# 打字竞速（gameKey：`typing-race`，category 建议：`word`）

- 玩法：60 秒中英混打速度赛，照目标句逐字输入（绿色=已对齐，红色=错位需退格），打对字符即计分、整句完成额外 +10 并自动换句；时间到结算。
- 操作：触屏点输入框唤起系统键盘输入；物理键盘直接开打；空格（暂停时）继续；切后台自动暂停（计时基点平移）。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；分数驱动款：结束上报本局最高分（desc，metricValue=本局分数，metricExtra=完成句数），历史最高分 localStorage + 账号存档双写（`sw.typingrace.v1`），无桥自动降级。

## 上报口径

- `reportScore("typing-race", {metricValue: 本局最终分数, metricExtra: 完成句数})`，desc 语义（越大越好）。
- 分数规则：每打对 1 个字符 +1（英文不区分大小写，中文/标点/空格均按 1 字符计）；整句完成额外 +10；退格修正不扣分（同一字符不重复计分）。

## 内容口径

- 内嵌 30 条自撰中英混合短句（中文日常句 + 常用英文词嵌入），无版权素材；判定为顺序前缀匹配，错位字符标红提示退格。

## 自查清单

- [x] 无外部请求：CSS/JS 全内联，零 CDN / 字体 / 图片
- [x] 单文件 ≤10MB；颜色全部走 `--g-*` token，深浅双主题由桥推送
- [x] 触屏 + 键盘双操作（input 唤起键盘 / 物理键盘直打）；切后台自动暂停
- [x] 分数驱动：60 秒限时，最高分双写，结束上报（desc）
- [x] audit-gates 通过（0 违规）；theme-gates 全绿
