# 错字围剿（gameKey：`typo-hunt`，category 建议：`word`）

- 玩法：每关一段 2-3 句自撰短文（30-70 字），其中混入 1-2 个同音/近形错别字，30 秒限时内点出全部错字；点错计失误，超时本关重试；纠出的字恢复为正字并标绿。
- 操作：触屏点字纠错；键盘 ←→ 移动游标、Enter 纠错、R 重开；开始按钮启动计时，切后台自动暂停（计时基点平移）；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, text(病句原文，错字已混入), wrong:[{a:错字,b:正字,n:错字在短文中第几次出现}]}`；渲染时错位处显示错字，纠出后覆盖为正字。
- 内嵌独立验证器逐关复核：① 结构完整（短文 10-80 字、错位 1-3 处、a/b 单字且 a≠b）；② **替换一致性**——错字 a 必须在短文中按第 n 次真实出现（错位位置由错字出现次序解析）；同一位置不可被两处替换、同一错字不重复使用；③ 可通关性显然（错位位置已解析，点选即判）。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核，异常关会在消息区告警）。个别错字在短文中出现多次的条目，第 n 次出现位即唯一的错误用法位，已逐条人工复核（如「工做→工作」与「做得」并存取首现位）。
- 内容口径：短文全部自撰（生活场景日记体），错字均为同音/近音/近形易混字（天汽→天气、运汇→运会、表章→表彰、辛福→幸福、做业→作业等），逐段人工校对替换后读不通；不含版权素材。
