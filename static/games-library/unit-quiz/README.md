# 单位换算（gameKey：`unit-quiz`，category 建议：`other`）

- 玩法：限时完成长度（km/m/dm/cm/mm）、重量（t/kg/g）、时间（h/min/s）换算四选一，后期三域混合、跨度加大；答错扣 5 秒，错满 3 题失败，限时答完即过关。
- 操作：触屏点选项；键盘 1-4 选答案、R 重开、L 选关。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌（种子生成，6→10 题、75→60 秒），到达关卡经 GB 桥上报（desc，metricValue=过关关号，metricExtra=剩余秒数）；换算全部整数结果（比率分子/分母有理数运算），干扰项为 10/100/1000 倍缩放错值；切后台自动暂停并把计时基点平移。

## 关卡验证

- 关卡结构 `{dc:{q,time,doms},qs[]}`：每题 `{dom,v,u1,u2,opts[],ans}`，v 为十进制数字符串，opts 为 4 个数字字符串，ans 为正确项下标。
- 生成算法：同量纲随机单位对，候选值集测试整除（v×n1×d2 能被 d1×n2 整除且结果 ≤999000），干扰从 ×10/×100/×1000/÷10/÷100/÷1000 池抽取并保证与正确值互异。
- 验证方式：游戏内嵌**独立验证器** `verifyLevelData`（十进制串→分数解析，交叉相乘逐选项比对，断言唯一正确 + 答案标记一致 + 选项互异），与生成器的约分路径不同。
- 标准锚点用例（人工核对）：①3.5 km = 3500 m ②2.5 t = 2500 kg ③1.5 h = 90 min ④250 cm = 2.5 m。启动时逐关复核 40 关 + 锚点断言，坏关自动换种子重试，验证失败在消息区告警。
- 生成与验证结果：40/40 关通过，无告警。
