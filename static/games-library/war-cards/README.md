# 战争比点（gameKey：`war-cards`，category 建议：`board`）

- 玩法：与 AI 轮流对战。一副同点数对称的牌对半分给双方（牌量 16→52 随关卡递增），双方各持 3 张手牌 + 牌堆；每战双方各出 1 张（你从 3 张里选），点数大者吃走两张计入得分，平局两张烧掉；手牌不足自动从牌堆补足，牌全部打完后得分高者过关。
- 操作：点手牌中的 1 张出战；键盘 1/2/3 出对应手牌、Tab+回车出牌、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关为配置型对局（牌量 + AI 记牌强度 0→5 递进：AI 会以递增概率记住你上一张的点数并反制）；存档键 `sw.warcards.v1`，到达关卡经 GB 桥上报（desc，附得分）；无桥环境自动降级纯本地。

## 关卡验证

- 每关结构 `{name, deck(偶数,12..104), ai(0..5 记牌强度), difficulty}`：双方各得 deck/2 张，且点数集合完全对称（各含每种点数 2 张）保证战局公平。
- 验证方式：游戏内嵌**独立无头对局模拟器** `warSimulate`——加载时对每关以固定随机流自动对局 **150 局**（双方随机出牌），逐局校验：对局必然终止、牌量守恒（得分 + 烧牌 = 总张数）；任一局异常即淘汰该关。
- 生成与验证结果：40 关（deck 16→52、AI 强度 0→5）全部通过 150×40=6000 局模拟校验（**40/40**）；jsdom 无头冒烟测试完整打完一局并正常流转到下一关 / 选关。
