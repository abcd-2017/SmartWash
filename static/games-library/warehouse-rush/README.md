# 仓库高峰（gameKey：`warehouse-rush`，category 建议：`other`）

- 玩法：限时交班分拣——货件按到货时刻表从左侧出货口排队出现（蓝/绿/橙三类），点输送带自动取队首货，再点同色货架位放下；叉车移动 0.45s/格、取放各 0.8s，货件等过耐心时限即记错漏，班次结束入库达标且错漏不超限过关。
- 操作：触屏点目标格 BFS 自动寻路（再点取消意图外可继续点）；键盘方向键逐格移动，走到出货口自动取货、走到匹配货位自动放货、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到货节奏与耐心随班次收紧。

## 关卡验证

- 内嵌 40 关，每关结构 `{name,W,H,shelves[12],arrivals[[t,cat]],patience,targetK,maxL,difficulty}`；时间模型：叉车 0.45s/格、取放 0.8s，与实机运行完全一致。
- 验证方式：游戏内嵌**贪婪基准回放器** `WR.sim`（先到先取 FIFO、放到最近匹配空位、超耐心记错漏），生成期以基准结果定标（targetK=基准入库−1、maxL=基准错漏数下限 1），`WR.validate` 复核结构与基准可达标；玩家需接近基准路线效率才能达标。
- 锚点用例（`window.__validateLevels()` 共 6 条，node 抽取 XC-CORE 复现）：三单顺序入库 stored=3/comp=0（精确）、超短耐心必错漏 comp=1（精确）、最远架(0,0)→(6,3) 9 步（精确）、单箱必达 stored=1、40 关基准可达标、生成逐字节确定。
- 生成与验证结果：40/40 关基准可达标（fail 空）。
