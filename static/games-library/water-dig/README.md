# 引水入渠（gameKey：`water-dig`，category 建议：`puzzle`）

- 玩法：地形图上每个格子有高度（0-3），水从「源」出发只流向不高于当前水位的格子；在挖掘预算内点格挖土（高度 -1），造出一条高度不升的沟渠把水引到「田」，按「放水」观看水流是否贯通。
- 操作：触屏点格挖土、按「放水」试流；键盘方向键移动光标、Enter 挖土、Space 放水、Z 撤销、H 提示。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, w, h, hgt(高度数组 0-3), src(源), tgt(田), budget(挖掘预算 1-3), difficulty}`；棋盘 5×5 至 7×7。
- 验证方式：游戏内嵌**独立验证器**（与放水模拟分离）：① 状态图 Dijkstra（状态=格子×水位，挖深即转移成本）计算最小挖掘数，要求恰等于 `budget` 且 ≤ 预算；② 零挖掘水流可达集检查，要求田地初始不可达（必须先挖才有趣）。后台分片逐关复核，验证失败的关在选关面板禁用。
- 生成与验证结果：40/40 关需挖掘方可通水（预算 = 最优挖掘数，构建期与运行时双重复核）。
