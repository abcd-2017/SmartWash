# 量水定容（gameKey：`water-jug`，category 建议：`puzzle`）

- 玩法：用两只容量不同的壶，通过装满 / 倒空 / 互倒，使任一壶恰好量出目标升数。
- 操作：触屏点六个操作按钮；键盘 1-6 对应六个操作、Z 撤销、H 提示、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；48 关内嵌，到达关卡经 GB 桥上报（desc）。

## 关卡验证

- 内嵌 48 关，每关结构为 `{name, a, b, target, par, difficulty}`；`a`/`b` 为两壶容量，`target` 为目标升数。
- 验证方式：游戏内嵌**独立 BFS 求解器** `jugBFS`（状态=两壶当前水量，六种操作，首达目标即最优），加载每关时复核可解性并计算最少步数；不可达会在消息区告警，提示取 BFS 首步。
- 生成与验证结果：48/48 关可量出，BFS 实测最优与关卡 `par` 一致（4 步递进）。
