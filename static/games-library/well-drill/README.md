# 打井取水（gameKey：`well-drill`，category 建议：`other`）

- 玩法：地质剖面 10×10，土层/黏土/岩层硬度递增、越深越贵（钻孔费=1+硬度+深度），移机 2/格；找到含水层水囊一钻全收，用有限经费凑够村庄目标水量——钻哪几口井、钻多深，是道选点背包题。
- 操作：触屏点「◀/▶ 移动」「▼ 钻进」，点剖面下半区直接钻进；键盘 ←/→ 移动井架、空格/↓ 钻进、R 重开。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关内嵌，经费=最优方案费用×(1.3→1.15)+8，纯事件驱动无实时压力。

## 关卡验证

- 内嵌 40 关，每关结构 `{name,w,d,cells[0土/1黏土/2岩/3水],budget,target,difficulty}`；水囊=4 邻连通含水层，尺寸 1-3。
- 验证方式：游戏内嵌**独立 DP 求解器** `WD.solve`（每列枚举「钻到第 k 个水囊」的费用/水量前缀方案，列自左向右访问 + 移机费 DP，best[y]=拿到 y 水的最小总费用），生成期 target=极限水量×(0.8→0.92)、budget=最小费用×比例+8，`WD.validate` 复核结构与可解+预算达标。
- 锚点用例（`window.__validateLevels()` 共 6 条，node 抽取 XC-CORE 复现）：岩层深度 3 单钻 8（1+4+3 精确）、两格水囊 flood fill 尺寸 2（精确）、列计划前缀 cost=9/yield=1（精确）、微型图求解最小费用 11（移机 2+钻费 9，精确）、40 关结构+可解+预算校验、生成逐字节确定。
