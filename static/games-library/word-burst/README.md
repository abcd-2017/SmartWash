# 词泡泡（gameKey：`word-burst`，category 建议：`word`）

- 玩法：60 秒限时赛，每轮给一个目标词（成语或常用词），屏幕上 12 个字泡泡（目标字 + 干扰字），按顺序点中目标词的字即消除；点错断连击；整词消除获得词长加成，随即出新词。
- 操作：触屏点泡泡；键盘 1-9 / 0 / Q / W 按位置点泡泡、空格暂停；切后台自动暂停（计时基点平移）。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；分数驱动款：结束上报本局最高分（desc，metricValue=本局分数，metricExtra=最大连击），历史最高分 localStorage + 账号存档双写（`sw.wordburst.v1`），无桥自动降级。

## 上报口径

- `reportScore("word-burst", {metricValue: 本局最终分数, metricExtra: 最大连击})`，desc 语义（越大越好）。
- 分数规则：点中一字 +10 + 连击加成（combo ≤20 时每连击 +2）；整词消除 + 词长 ×20 + 连击加成 ×5；点错清零连击、不扣分。
