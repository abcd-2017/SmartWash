# 连词成串（gameKey：`word-link`，category 建议：`word`）

- 玩法：每关 5 张打乱的双字词卡，相邻词首尾共用一字（如 水田→田地→地图→图画→画像），按衔接顺序把词卡逐张排入链槽；接错算失误并提示上一词尾字，5 词全入链过关。
- 操作：触屏点词卡入链；键盘 1-5 选词卡、U 撤销、R 重开；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；运行时把链卡随机打乱且保证乱序不等于原序；槽位中以绿字标出与前词共享的衔接字；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每关结构为 `{name, chain:[5 个双字词]}`；词库为 40 条自撰组词链（共 200 个常用词）。
- 内嵌独立验证器逐关复核：① 结构完整（恰为双字词、关内词唯一、链长 4-7）；② **首尾衔接**——相邻两词前词尾字必须等于后词首字（`chain[i-1][1]===chain[i][0]`），保证链唯一可排；③ 可通关性由构造保证（每一步必有一张卡可接，接错可撤销重来）。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核，异常关会在消息区告警）。
- 内容口径：链上词均为常用双字词，逐条人工校对相邻衔接与词语规范性；跨关允许词复用（关内唯一由验证器保证）。
