# 单词搜索（gameKey：`word-search`，category 建议：`word`）

- 玩法：在 size×size 的汉字（或少量英文）字符阵中，按提示圈出本关列出的全部词语。词语横、竖、斜藏，方向随关卡推进逐步解锁；找齐即过关，每关有 3 次提示。
- 操作：按住从首字拖到末字圈选，或先点首字再点末字（支持八个方向自动吸附）；点击下方词语卡片也可标记该词位置，重复点击已找到的词不会消耗提示。
- 说明：单文件自包含 H5，零外链；棋盘 Canvas 自绘、DOM 卡片式布局。进度与每关提示余量经游戏桥存账号（本地 + 账号双写），到达关卡数上报排行榜；关卡列表支持后台热更新（DB 下发优先，本地缓存兜底，包内 10 关默认）。

## 关卡数据设计

DB 下发的 `dataJson`（同时用于 `.levels.json` 的 `data`）：

```json
{ "name": "成语·初识", "size": 6,
  "words": [["塞翁失马", "坏事有时可变好事", "E", 0, 3]],
  "grid": "老并间命对狐把处进余牛假没夫想自弹虎塞翁失马琴威做再惊弓之鸟与得望笑或花" }
```

- `words[]` 每项为 `[词, 提示, 方向, x, y]`：`x` 为列、`y`为行；方向码 `E/S/W/N/SE/SW/NE/NW` 共 8 个（横竖 + 四斜）。
- `grid` 为 `size*size` 行优先字符画，**必须与 words 的位置/方向逐字一致**（引擎解析时回读校验）。
- 构造法生成：先按词长降序随机摆放（允许同字交叉，不允许异字冲突），失败换种子重试，再从常用汉字池填充空格；确定性种子保证可复现。
- 提示不泄底：新关卡要求提示中不得出现答案词里的任何汉字（生成器与校验器双重检查）。

## 难度递进（100 关）

| 关卡 | 尺寸 | 词数 | 允许方向 |
|---|---|---|---|
| 1–10 | 6×6 | 4 | E/S |
| 11–20 | 7×7 | 5 | +W/N |
| 21–30 | 8×8 | 6 | 4 向 |
| 31–40 | 9×9 | 7 | +两斜向（6 向） |
| 41–70 | 10→12 | 7–8 | 8 向 |
| 71–100 | 12×12 | 9–10 | 8 向 |

主题按带划分：成语、校园、动物、自然、生活、科技、运动、职业、美食、音乐，共 730 个互不重复的词条。
