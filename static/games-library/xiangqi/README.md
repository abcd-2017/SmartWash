# 中国象棋（gameKey：`xiangqi`，category 建议：`board`）

- 玩法：完整中国象棋规则的人机对弈。玩家执红先行或执黑后行，与 AI 轮流走子；将死、困毙或认输判负，60 回合无吃子判和。关卡由后端下发，共 120 关，难度由 AI 搜索深度、让子数、先后手与 AI 随机性组合递进。
- 操作：点选己方棋子（高亮并显示可走交叉点），再点目标交叉点走子；空位为实心圆点、可吃子为红圈。底部按钮：上一关 / 悔棋 / 重开 / 下一关 / 认输。
- 说明：单文件自包含 H5，棋盘与棋子全部 Canvas 自绘，零外链零素材文件。自研 minimax + α-β 剪枝 + 吃子静态搜索 AI，子力价值与位置表评估。包内内置 12 关默认关卡，DB 下发优先，本地缓存兜底。

## 规则实现要点

- 将/帅：九宫内直走一步；将帅不照面（同线无子即被攻击）。
- 士/仕：九宫内斜走一步。象/相：田字斜走、塞象眼、不过河。
- 马：日字走法、蹩马腿。车：直线任意距离。炮：移动如车，吃子必须隔恰好一子。
- 兵/卒：向前一步，过河后可左右横行，永不后退。
- 终局：无合法走子时，被将军为将死、未被将军为困毙，均判负；支持认输与 60 回合无吃子和棋。

## 关卡数据格式

`.levels.json` 顶层为信封数组，每项 `{levelNo,name,difficulty,data}`；`data = {name,depth,handicap,first,rand}`：

| 字段 | 含义 |
|---|---|
| `depth` | AI 搜索深度，1-4 |
| `handicap` | 让子数，0-4（依次去掉 AI 的左炮、右炮、左马、右马） |
| `first` | `true` 玩家执红先行，`false` 玩家执黑后行 |
| `rand` | AI 随机性，0-2（越大越容易失误） |

难度度量 `depth*3 + (4-handicap)*2 + (first?0:1) + (2-rand)`，单调映射到 `difficulty` 1-10；120 关组合唯一。
