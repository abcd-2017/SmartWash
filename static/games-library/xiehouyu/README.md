# 歇后语接（gameKey：`xiehouyu`，category 建议：`word`）

- 玩法：每关 3 题，给出歇后语的半句（多为前半，也有给后半接前半的反向题），从 3-4 个候选中接上正确的另一半；选错即划掉可再选，三题答完过关，前 20 关 3 候选、后 20 关 4 候选。
- 操作：触屏点候选；键盘 1-3 / 1-4 选择、R 重开；选关面板逐关解锁。
- 说明：单文件自包含 H5，卡片式布局（标题由 App 原生页头承载）；40 关由固定种子生成器产关（100 条题库正向覆盖 + 前 20 条反向复用 = 120 题位，同关内不重复）；到达关卡经 GB 桥上报（desc，metricValue=到达关卡，metricExtra=失误次数）。

## 关卡验证

- 内嵌 40 关，每题结构为 `{stem(题干半句), dir(A=接后半/B=接前半), ok(正确项下标), opts[候选]}`；题库为内嵌 100 条**常见无争议歇后语**（如「芝麻开花——节节高」「外甥打灯笼——照旧（照舅）」），干扰项由固定种子从其他条目的对应半句抽取。
- 内嵌独立验证器逐关复核：① 结构完整（opts 3-5 条、无重复、ok 下标有效、候选≠题干）；② **题库一致性**——每题的「题干+正确项」必须能在歇后语库中以正向或反向命中，否则该关告警；③ 可通关性显然（正确项必在候选中，选错可重选）。
- 验证结论：40/40 关全部通过（启动时 `auditAll` 全量复核）。
- 内容口径：条目均为广泛流传的歇后语，逐条人工校对；谐音类在候选文本内以括号注音（照旧（照舅）、无（吴）用等），前后半与通行版本一致。
